\section{Related Work --- 선점 지도}
\label{sec:related}

\begin{itemize}
  \item Astra로 로봇: AGP~\cite{agp2026}, RoboDojo~\cite{robodojo2026} 등(모두 미심사). Harness VLA~\cite{harnessvla2026}도 Astra 계획기 사용
  \item 스텝마다 LLM이 이산 행동: Show-Harness~\cite{showharness2026} $\rightarrow$ M3 직접 선행, 반드시 인용
  \item 스킬 하네스(스타 상위): PhyAgentOS~\cite{phyagentos2026}, Zetta~\cite{zetta2026}, Harness VLA, CaP-X~\cite{fu2026capx}
  \item 주기 대 이벤트 호출: CheckVLA~\cite{checkvla2026}, Event-triggered~\cite{eventtrig2026} 등
  \item 비동기 실행: RTC~\cite{black2025rtc}, SmolVLA~\cite{shukor2025smolvla}, VLASH~\cite{vlash2025}, A2C2~\cite{a2c2}
  \item 안 멈추는 느린 모델 호출: Slow Brain~\cite{slowbrain2026}(겹침 요청 + 최신 답 감쇠 융합)
  \item 합의 → 앞 구간 확정: A3(VLA 청크, 같은 시각 샘플 합의, 실행 뒤 확인 없음) $\rightarrow$ 우리 M4는 시간차 호출 합의 + 실행 뒤 예상 대 측정 둘 다
  \item 환경 변화에서 LLM 대 VLA: RoboDawn(깨끗한 장면 학습 $\pi_{0.5}$ 46.0\% 대 Astra 무학습 53.2\%) $\rightarrow$ 사용자 주장의 두 번째 근거. 우리 빈칸은 ``같은 인식 위에서 결정 층만 바꾼 비교''
  \item Jev를 로봇에 쓴 논문은 아직 없음. 저장소 데모만(Jev-as-Policy: 요청 하나 + 직전 행동 유지, 감시 중)
\end{itemize}
