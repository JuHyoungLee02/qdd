\begin{abstract}
GPT-6 Astra 같은 API 기반 대형 모델로 로봇을 명령 기반으로 제어하는 연구가 늘고 있다. 이 방식은 학습한 VLA보다 좋은 성능을 보이기도 하지만, 호출 한 번에 수 초에서 수십 초가 걸린다. 물체를 보고 스킬을 생성해 잡는 기존 방법들도 실패하는 경우가 있다. 우리는 느린 Astra를 상위 계획기로, 텍스트 전용 typed 객관식 모델 Jev를 하위 결정기로 두는 계층 시스템 Harvest를 제안한다. Harvest에서 로봇은 멈추지 않고, 실패가 판정될 때마다 Astra가 비동기로 개입한다. Jev는 1초에 3번 정도 계단식으로 겹쳐 호출되며, 스킬 안에서 코드가 만든 보기 중 하나를 고른다. 핵심 구성 요소는 겹쳐 부른 호출들 사이의 합의에 더해, 실행 뒤 코드가 예상한 상태와 실제로 측정한 상태를 함께 확인하는 확정 규칙이다. 이 규칙은 전제가 깨진 결정을 무효화하고 유지·교체·수리 중 하나를 고른다. 평가에서는 같은 인식 앞단 위에서 결정 층만 바꾸어, 과제 데이터로 미세조정한 학습 정책(VLA 포함)과 학습 없는 LLM 결정 층이 깨끗한 장면에서 바뀐 환경으로 갈 때 얼마나 떨어지는지 짝지어 비교하는 프로토콜을 설계한다. 공개 원자료로 계산한 예비 분석에서 RoboDojo의 환경 변화에 따른 상대 하락은 Astra $-$11.1\%, $\pi_{0.5}$ $-$72.2\%였다. 다만 두 조건의 인식 입력이 같지 않아 예비 결과로만 본다.
\end{abstract}
