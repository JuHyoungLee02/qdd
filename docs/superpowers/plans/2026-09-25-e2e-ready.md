**목표:** 엔드투엔드(단계 B: Qwen3-VL-4B 백본 + action expert, §51·§52) 학습을 **돌리기 직전 상태**까지 전 파이프라인을 만들고 검증한다. 본 E2E 학습은 하지 않는다.

**완료 정의(모두 충족):**
1. 데이터: (§58 개정) 이미지 입력 + 특권 시뮬 기하를 보조·확인 헤드 정답으로(M1 추정 상태는 모듈형 기준선용), 여러 과제·물체, 학습용 DR, 행동(관절) 기록, 결과 기반·관측 정의 라벨이 한 형식(LeRobot 호환 + 우리 스냅샷)으로 대량 생성된다 — 생성기·검증기·소규모 샘플 통과.
2. 모델: 단계 A(결정 토큰, 다중 이미지 = 머리 + 활성 손목, D27 배치)와 단계 B(같은 백본 + flow-matching expert, expert→백본 기울기 차단) 학습 코드가 테스트 + 소규모 스모크(손실 감소·저장·재적재·서빙)를 통과한다.
3. 폐루프: 학습된 모델을 넣어 돌릴 실행 계층(Astra 하트비트 → Jev-L DecCall → M4 확정 → 스킬 S + 잔차 R 훅, simlat 시계)이 Inspect Robots `aiworker` 몸체 위에서 한 판 끝까지 돈다.
4. 평가: E0.5 재생·RD(standard/random) 평가·보정(CAL 온도·J5) 스크립트가 학습 산출물을 받아 한 명령으로 돈다.
5. 운영: 학습 처리량(묶음 처리)·파드 경로(/data/harvest)·재현 판본 고정·문서.

**원칙:** 각 항목은 사전 등록한 검증(테스트/스모크/프레임 확인)으로만 "완료". 소규모 시험 수치는 결과로 쓰지 않는다(§56). 방향 질문 6개는 관문마다.
