# JCR 1단계 부품 구현 계획

> 실행: 이 에이전트가 직접 구현한다(executing-plans). 스펙 = `docs/stage3/jcr_design.md`(§0-2가 우선), 등록 = `docs/stage3/prereg_jcr1.md`(변경 1).

**목표**: JCR1-0 기초 데이터를 SoloWorld mug_tray에서 생성하고, 학습 머리와 OJ 실행기로 첫 판을 돌릴 수 있게 한다.

**구조**:
- 순수 모듈(numpy, 단위 시험): `harvest/jcr/truth.py`, `upper.py`, `disturb.py`(스케줄만), `labels.py`.
- Isaac 모듈: `harvest/jcr/record.py`. PtEpisode 하위 클래스로, 명령원 = 참값/상위 흉내, 실행기 = TruthExec. 20 Hz 틱마다 기록한다.
- 학습·서빙·OJ 실행기는 데이터 형식이 확정된 뒤 만든다.

## 공통 제약
- 관절 걸음 ≤ 0.04 rad/틱은 월드 IK가 강제한다. 참값 청크는 v ≤ 0.08 m/s, a ≤ 0.32 m/s²다.
- 평가 DEV 0–19, CAL·TEST는 생성하지 않는다. 시드는 R2_TRAIN(10000–59999)만 쓴다.
- 교란은 P0–P2 범위의 새 외란만 쓴다. P3·P4 코드는 쓰지 않는다.
- 렌더는 7a2a 0·1·3 / x2 GPU1만 쓰고, `/data/harvest/out/l9/GPU_WANTED`가 생기면 편 경계에서 나간다.
- 코드는 `git archive` 사본으로 배포하고, 실행 중에는 수정하지 않는다.

## 작업
1. **truth.py**
   - `project_ball(p_true, goal, r) -> (c*, mismatch: bool)`
   - `smooth_chunk(p_cmd, v_prev, c*, H=10, dt=0.05, v_max=0.08, a_max=0.32) -> (P[H,3], v_last)`: 가속 한도 안에서 c*로 가고 넘치지 않는다.
   - `grip_event(allow, tcp, c*, reach_m) -> keep|close|open`
   - `anomaly(...)`: 틱의 anomaly 종류 집합
   - 시험: 범위 안·밖 투영, 청크 매끄러움·도착·정지, 가속 한도, 넘침 없음.
2. **upper.py**
   - `load_dist(path)`, `sample_cmd_noise(rng, dist, height, grip) -> {dxyz, intent_err, delay_s, swap}`
   - `tools/jcr/upper_err_dist.py`: main35 eval → `upper_err_dist.json`
   - 시험: 분포 로드·표본 재현성(같은 시드 같은 값).
3. **disturb.py**
   - `plan_episode(seed) -> {normal: bool, events: [...]}`: 정상 ≥ 50 %, 커리큘럼 스케일 인자.
   - 외란 종류: push·shake·obstacle·slip + 명령 swap·delay·pre-issue.
   - 시험: 정상 비율, 재현성.
4. **record.py**: `TruthExec`(pos 모드, 0.2 s마다 참값 청크, 도착·그리퍼·stop)와 `JcrRecEpisode`(PtEpisode 하위: 명령 주입·외란 적용·틱 기록).
   - 출력: `ticks.jsonl`(틱마다 상태·명령·접촉·anomaly·단계), `samples.jsonl`(0.2 s마다 라벨 청크·그리퍼 사건·접촉·anomaly·stop), `frames/`(10 Hz 머리 | 손목 jpg), `ep.json`(결과·실패 원인·외란 목록·G-br 통계).
   - 파드 스모크: 5편 + 영상 확인.
5. **생성 레인**: `tools/jcr/lane.sh`(GPU_WANTED 양보, 편 claim).
   - 첫 생성: x2 GPU1(비어 있을 때).
   - 데이터 관문 D0 도구: `tools/jcr/data_gate.py`.
6. **학습 머리**: stageb 기반. 조건은 연속 조이스틱·범위·나이·proprio, 출력은 Δxyz 청크·사건(keep/close/open/stop)·접촉·anomaly.
7. **OJ 실행기 + 서버**: `harvest/couple_joy/jcr_exec.py` + `--arms oj,oje`.
