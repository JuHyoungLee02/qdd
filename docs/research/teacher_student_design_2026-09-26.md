### 3.2 고리 (DAgger식, 시뮬, 동기)
1. **학생 LLM이 몬다**: `astra-solo@v2` 인터페이스(동기·eef 절대 목표·격자·측정 이력)로 학생이 R2 **TRAIN 시드**에서 과제를 수행(DEV는 평가 전용). 흐름 교정 형식 `astra-couple@v2`(구간 계획·계속/수정/정지)는 같은 고리의 결합 판(3.6).
2. **학생의 매 호출 = 방문 상태**: 같은 요청(영상·이력·프롬프트 바이트)을 선생에게도 보낸다(학생 답은 실행, 선생 답은 라벨 — β = 0; 선택: 학생이 3회 연속 막힘·반복이면 그 편만 선생 답을 실행해 뒤 구간 상태도 모음, HG-DAgger식).
3. **라벨 두 종**: (a) 참값 모델 답(무료·정확, 명령만 — 평가 문장은 고정값), (b) Astra 답(유료, 명령 + 평가·이유 문장). 둘 다 같은 JSON 형식이라 학생 출력과 1:1.
4. **모아서 SFT**: 매 반복 **기준 체크포인트에서 다시 LoRA 미세조정**(RECAP), 배치에 이전 반복 데이터 누적. 뒤에 선호·RL(성공 결과 조건)은 새 등록.
5. **잰다**: DEV 짝 시드 폐루프 성공(3.5).

### 3.3 참값 모델 대조가 반드시 필요한 이유
시뮬에는 Astra 형식으로 답하는 **참값 모델**(`harvest/astra_solo/truth.py`, S0 6/6)이 있어 학생이 간 모든 상태에 공짜·정확한 명령 라벨을 붙일 수 있다. 명령 정확도만 보면 참값 ≥ Astra(Astra 접근 목표 xy 오차 중앙 14.1 mm). 그러므로 시뮬 안에서 'Astra 라벨이 낫다'고 가정할 수 없다. 팔:

| 팔 | 학생 SFT 데이터 | 비용 |
|---|---|---|
| L-T | 학생 상태 × 참값 명령 | GPU만 |
| L-A | 학생 상태 × Astra 답 | 단계 상한 |
| L-TA | 참값 명령 + Astra 평가·이유 문장(명령이 어긋나면 참값 명령) | 단계 상한 |

- 참값에 없는 Astra만의 것 = 영상에서 빗나감을 알아채는 **평가·이유**(dr 0에서 빈손 닫힘을 패드 간격으로 알아채고 복구), 실물에서 쓸 수 있는 형식. 실물에는 참값이 없으므로 **최종 대체 대상은 실물에서 Astra의 판단**이고, 시뮬 결과(L-T 대 L-A)는 '참값 없이 Astra 라벨만으로 얼마나 가나'의 자격 근거가 된다.

### 3.4 단계·데이터 양·비용 (단계마다 ≤ 8,000원)
Astra 호출 53.8원 → 8,000원 ≈ **148호출 ≈ Astra 편 13개**(편당 11호출). qdd 유료 한도 10만 원, 누적 확정 약 1.9만 원(`05-costs.md`) 뒤 → 남은 예산으로 Astra 라벨은 전체 **약 1,400호출이 상한**. 학습에 필요한 양(형식 + 격자 읽기, LoRA)은 수천 행으로 추정 [추정] → **양은 참값(무료)으로, Astra는 비싼 핵심 상태에만** 쓴다.

### 3.5 성공 기준·판정 규칙 (사전 등록에서 고정할 초안)
- **REPLACE**: 학생 성공 ≥ Astra 단독 − 3/40(DEV 40 짝, 비열등 여유 7.5 %p) **그리고** 학생 지연 p50 ≤ Astra p50의 1/3(≤ 약 2.3 s) **그리고** API 0원 → 학생이 Astra-solo 자리 대체 후보(흐름 교정 자리는 3.6).
- **PARTIAL**: 학생 ≥ 영점 + 10/40 이지만 REPLACE 미달 → 다음 반복(L3 추가) 또는 더 큰 후보(122B-A10B).
- **L-A 대 L-T**: L-A ≥ L-T − 2/40 이면 Astra 라벨만으로도 참값 급 → 실물(참값 없음)에서 증류 가능 근거. L-A < L-T − 4/40 이면 실물 증류 전에 라벨 거르기(두 답 합의·측정 이력 확인) 설계를 먼저.
- 해석 한계: 과제 하나(mug_tray), 시뮬, 40편 — '대체 가능한가'의 1차 판정만; 새 과제·실물 일반화는 따로.

### 3.6 흐름 교정 자리(astra-couple)의 대체
결합(§92)에서 Astra는 흐름으로 평가·수정·구간 계획을 낸다. 같은 방식으로 **학생 LLM에 `astra-couple@v2` 답**을 증류한다: 결합 폐루프(무료 사전 실행 틀 `tools/couple_dry/`)의 요청마다 Astra 답(라벨) + 오라클 정답(E-ACC 채점 규칙: 어긋남 알아채기·수정 방향·구간 계획)을 붙여 SFT. 판정은 E-ACC와 같은 표본·규칙으로 '학생 ≥ Astra'인가. 이것은 L4 뒤, E-Couple 선행 조건(B5·멈춤 고리)이 풀린 뒤 차례.

## 4. 보조 트랙 V — VLA DAgger (E-TEACH-V, 이전 초판의 A안)

- **선행 조건(하드)**: 런타임 멈춤 고리(VLA 단독 0/12 중 8편: T1 모순 → hold → 결정 비움 → 청크 버림) 수정. 안 고치면 라벨이 런타임 버그에 낭비된다. 담당 = **결합 통제자**(수정: hold 중 T1을 되돌리는 청크 허용·hold 상한·열림 문턱 80.5 mm) + **E-VLA-solo 에이전트**(Q3 판정·수정 판 12편 재측정, 영구 hold ≤ 1/12). 학생 체크포인트는 ser-A-min-3 재학습판(그리퍼 질문·구간 줄) — 메인.
- **고리**: 학생 VLA가 R2 TRAIN 시드 폐루프 → 트리거에서 시뮬 멈춤 → 선생 라벨 → 기준 체크포인트에서 다시 학습(본학습 자리만) → DEV 40편 짝.
- **트리거**: T-k(k 스텝마다), T-stall(1 cm/2 s 미만 진전·hold 시작·방향 뒤집힘), T-conf는 **기록만**(§95 보충 1).
- **라벨 사상**(기존 어휘): 선생 `eef` 목표 − TCP(또는 `edit` 델타) → `labels_v2.dir_xy_label/dir_z_label/mag_label`(불감대 1 cm), `gripper` → §87 보기, 목표 물체 → `target`, close·open·stop → `phase` next(그 밖 continue), `segment{now,do,next}` → `intent.PLAN_TO_LINE`/`SEGMENT_PLAN`, 청크 목표 = 계획기 스킬 직선 0.5 s(결정·청크 같은 뜻, E-SR1b).
- **팔**: C-cont(같은 계산량 계속 학습) / D-O(학생 상태 × 시뮬 오라클, 무료) / D-T(학생 상태 × 선생 라벨). D-O − C-cont로 공변량 이동 가설, D-T − D-O로 선생 라벨 품질. 선생은 **주 트랙의 증류된 학생 LLM이 자격을 얻으면 그것**(무료)이 우선 — Astra로 VLA 라벨 수천 개는 예산 초과.
- **판정 초안**: D-O − C-cont ≥ +4/40(짝 부호 검정 p < 0.05)이면 '학생 상태 집계' 칸 채택; D-T < C-cont면 정지(APO).

## 5. E-TEACH-R — 실제 로봇 경로 (추가학습 자리)
- **지금 상태**: 실물 접근 **없음**(`molmoact_real_readiness.md` 4.6 "실물 로봇 사용 가능 시기·안전 절차 [결정 필요: 사용자]") → 선행 조건 달린 등록 계획, 실행 아님.
- **선행 조건**: 실물 AI Worker(베이스 고정)·로봇 옆 RTX PRO 6000(§49) 시간과 안전 절차, 시뮬 E-TEACH-L REPLACE 또는 PARTIAL(학생 LLM), 실물 프레임 위 선생 정확도(E-ACC-R).
- **방식**: R-demo — 동기 선생 조종(로봇이 답을 기다림) 실물 시연; R-dagger — 학생(LLM 또는 VLA)이 몰고 선생이 라벨·인계. 실물 Astra 답은 **학생 LLM의 추가학습**(참값 없는 실물 증류 — 대체의 마지막 단계)과 VLA 추가학습 둘 다에 쓴다.
- **200편 실물 수집과의 관계**: 보류 중인 대체 경로 수집(공구 2개 × 직접 50 + 대체 50, MolmoAct D.7)을 R-demo로 대신할 수 있다(선생에게 "왼쪽/오른쪽으로 돌아서" 경로 지시). Astra로 200편 ≈ 11.8만 원(예산 초과) → 증류된 학생 LLM이나 무료 대형 선생이 전제. 선생 시연은 최소 저크 직선 모양이라 사람 시연과 분포가 다름(등록에서 따로 잰다).
