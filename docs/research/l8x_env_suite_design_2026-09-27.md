## 0. 결정과 순서
- 상위 실험(E-DIST8, E-STRIP8 재검증, 최종 35B 소규모)은 **L8-X 환경에서** 돈다. L8-D(탁자 높이·방해물·외관)는 L8-X의 첫 조각이다.
- 머리 각도는 고정(45° 정책, 시뮬 0.69 rad). 리프트는 플래그(기본 끔)로만 두고, 넓어지는 범위를 숫자로 보고해 사용자가 정한다.
- 조종 어휘는 집어 놓기(위에서 내려 잡기, user-log 136). 새 명령이 필요한 과제(깊은 선반 옆 잡기, 손목 회전, 서랍 열기)는 **한계 탐침(평가 전용)** 으로만 넣고 표시한다(§98).
- 참값 모델이 3번 중 2번 이상 성공하는 (장면, 과제) 조합만 데이터에 넣는다.
- 게이트(약관 동의) 공개 데이터는 비게이트로 먼저, 잘되면 사용자에게 제안.

## 2. 구현 방식
- **가구 = 정적 충돌체(원시 상자 조합)**. 편마다 위치·크기를 바꾸려면 PhysX 장면 재생성(하드 리셋) 때 USD 자세를 쓴다(물체와 같은 방식, `_recreate_physx_scene`). 크기는 프로세스(버킷) 단위.
- **받침면 표**: 장면마다 `surfaces = [{id, kind, top_z, xy 상자, 윗판 여부}]`. 물체의 받침면 z가 참값·라벨·행동 정책·방해물 배치의 기준이 된다.
- **참값 모델 확장(시험 먼저)**:
  - 잡기 z = 물체의 현재 밑면 + h − 1.8 cm(탁자 위에서는 지금과 같음).
  - 놓기 = 놓을 곳 윗면(받침면·통 바닥·받침대 윗면) + 여유.
  - 운반 z = max(집는 받침면, 놓는 받침면, 경로 위 가구 윗면) + 22 cm, 도달 표로 자름. 탁자 한 개일 때는 지금과 바이트 동일.
  - 여러 단계 = 하위 과제(대상, 놓을 곳) 목록을 차례로; 단계 끝 판정 = 기존 성공 술어.
  - 도달 확인 = 관문 탐침의 도달 지도(x, y, z).
- **요청 형식**: 받침면이 여럿이면 v2의 '탁자 윗면' 한 줄을 '받침면 목록' 줄로 바꾼 판(v2s)이 필요하다. 최소 형식(s-min, 탁자 줄 없음)은 그대로 쓸 수 있다. 격자는 대상이 선 받침면에 그린다. 형식 스위치(격자·손 정보·깊이)는 같은 편에서 고른다(1단계와 같음).

## 3. 단계
- **X0(진행 중)**: 탁자 높이 관문 G-H(도달 탐침·리프트 측정), L8-D 1단계 1,200편(탁자 높이·방해물 0–6·넓은 외관) → E-DIST8·STRIP8 재검증이 바로 쓸 수 있는 첫 묶음.
- **X1**: 가구 원시(조리대+벽, 계단식 선반, 통·그릇, 받침대, 낮은 탁자) + 받침면 표 + 장면 표본기. 도달 탐침을 낮은 z(바닥 통·낮은 탁자)까지 넓힘.
- **X2**: 과제·참값 확장(여러 단계, 관계, 속성, 담기, 선반 → 조리대). 조합별 참값 3회 중 2회 관문.
- **X3**: 허가 자산 가져오기(MolmoSpaces·BEHAVIOR·cyclo_lab) — 도우미 에이전트 제안(분리 가능한 일).
- **X4**: 보호 OOD 세트(OOD-H 높이, OOD-O 물체, OOD-S 가구·장면 종류, OOD-T 과제 조합)를 학습 전 커밋 → 본 생성 2,000–3,000편, 모든 빈 GPU.
