## 0. 요약

**병목을 한 줄로**: 실데이터(S-E2E)에서 분기 학습은 학습 분기를 맞추지만(손실 1.08 → 0.05) 새 편으로 덜 일반화한다(먼 구간 A_xy 0.339 → 0.536, 퍼짐 8.6 mm 대 청크 18.7 mm). R2 시뮬에서는 같은 레시피가 0.991이었다.

**문헌이 말하는 것 (이번 조사의 새 근거)**
1. **분기 데이터는 맞는 방향이다.** 다만 **"같은 상태에서 짧은 행동 조각만"** 주는 CAST식 증강은 **완전한 조종 궤적**보다 약하다. 근거는 ReSteer(RSS 2026)다. 이 논문은 LIBERO에서 CAST식 판을 같은 생성기로 구현해 비교했고, 실물 DROID에서는 조종 성공률 7 % → 33 %(미세조정) → **73 %**(ReSteer)였다. 준수가 약한 상태를 **조건부 상호정보(CMI)**로 골라 데이터를 만들면 표본 효율이 오른다(DROID 80 % 대 무작위 75 %).
2. **적은 데이터로 사후 학습하면 조건을 무시하는 'lock-in'이 생긴다.** DeLock(Stanford, 학회 미확인)은 두 가지로 이를 되살렸다.
   - 영상 인코더 드리프트 규제(우리는 SigLIP 고정으로 이미 비슷하게 함)
   - **추론 때 대조 안내(CPG)**: 음의 조건 = 학습된 지시
   - 결과: 공간 lock-in 과제 4개에서 CPG 없이 **0/20 ×4**, 있으면 **11–14/20**.
   - 이 대조 안내는 우리 E-SR1b의 드롭아웃 + CFG와 다르다. 무조건 속도가 아니라 **다른 조건의 속도**를 빼고, 추가 학습이 없다.
3. **시뮬 데이터를 섞는 공동학습(co-training)**은 실물 성능을 올린다. 기전도 분석됐다.
   - 평균 **+38 %**(RSS 2025 계열, 과제당 실물 시연 10–50개)
   - 결합 분포 정렬로 최대 +30 %(NeurIPS 2025)
   - '구조적 표현 정렬 + 영역 구별성'이 주요인이라는 분석(ICML 2026)
   - 우리 R2 분기는 이미 **과제를 넘어** 일반화했다(분기 없는 과제 0.979). → 실데이터 모델에 R2 분기를 **섞는 것**이 가장 직접적인 다음 수다. 단 §89(추가 학습은 시뮬을 거치지 않음)와 경계가 겹쳐 **사용자 결정이 필요**하다(4절 L2).
4. **행동 좌표를 영상에 그려 주면 방향 이해가 는다.**
   - AxisGuide(RSS 2026): 새 물체 위치 성공률 시뮬 52.38 → 65.71 %, 실물 30.12 → 50.00 %
   - AimBot(CoRL 2025): 실물 50회 중 OpenVLA-OFT 21 → 36, π0 27 → 43
   - VLM은 관점 전환에 약하다(APC, ICCV 2025: 순수 VLM은 좌우 과제에서 우연 수준, 추상 장면 + 시각 프롬프트로 89.67 %).
   - 이것은 Astra의 앞뒤(x) 부호 오류(프롬프트 검진: 부호 일치 11/26)와 같은 문제다.
5. **계층형 시스템 설계**(Hi-VLA 체계 연구, Shridhar·Shah 등, 학회 미확인)
   - 상위 VLM은 크기보다 **생각(thinking)**이 효과가 크다.
   - 텍스트 관측 설명(**경계 상자**)이 성능을 크게 올린다.
   - 편 안 기억은 효과가 거의 없고, 편 사이 요약은 도움이 된다.
   - 하위 VLA가 **지시에 반응해야** 한다. 좁은 지시로 미세조정하면 성능이 크게 떨어졌다.
   - 지연 쪽: 이중 시스템은 상위 VLM(Gemini 2.5 Pro) 지연 때문에 회복 시점을 놓친다. OneTwoVLA(ICLR 2026)는 87 %로 이중 시스템을 24 % 앞섰다(원문 "by 24%").
6. **실패 예측**
   - 토큰 확률만으로는 약하다: SAFE(NeurIPS 2025)에서 보지 않은 과제 ROC-AUC 최대 확률 61.64 대 SAFE-LSTM 77.04.
   - 다만 **TD 보정**을 거친 행동 확률은 은닉 상태 탐침과 비슷해진다(ICML 2026).
   - FIPER(NeurIPS 2025)는 OOD 신호와 청크 엔트로피가 **둘 다** 넘을 때만 경보를 낸다.
   - E-CONF 등록에는 흐름 분산·온도·로지스틱·등각 예측이 이미 있다. 빠진 것은 **지도 은닉 탐침**과 **시간 누적·TD 보정**이다.

## 1. 원인 정리 — 문헌 쪽에서 본 실데이터 일반화 실패

`sr1d.md` 3절의 세 가설에 이번 문헌을 붙인다. 모두 [가설]이다.

- **(a) 데이터 양·다양성**: 분기 61,993행(R2 128,661행). 실물 편은 과제·장면이 편마다 다르다.
  - 공동학습 문헌은 적은 실물 + 많은 대리 데이터가 이 격차를 메운다고 본다(2.2).
  - ReSteer는 준수 실패가 **과제 궤적 분포가 겹치지 않는 것**과 묶여 있다고 보고, 겹침을 **만들어 주는** 데이터가 필요하다고 한다(식 (9) 뒤 원문: "because D contains only single-instruction trajectories, it provides no instruction-contrasting supervision at the same underlying state").
- **(b) 분기 모양이 실기록과 다름**: 분기는 URDF IK 직선이고, 속도 윤곽은 기록 p99.9 안에서 일정하다. 기록 청크는 가감속 teleop이다.
  - 문헌의 생성 파이프라인(DemoGen, MimicGen 계열, SIDO)은 **시연 행동 자체를 변형**해 새 행동을 만든다. 행동의 결을 실기록에 맞추는 것이 공통이다.
  - 우리 분기는 이 점에서 벗어나 있다 → L3.
- **(c) 좌표 해석 부담**: 결정 토큰은 기저 좌표 방향이고 expert 출력은 관절 청크다. 관절 구성·시점이 편마다 다르면 "기저 +x"를 관절 움직임으로 옮기는 사상이 편마다 다르다.
  - AxisGuide는 이를 "action understanding" 부족으로 규정하고, 축을 그려 주면 새 위치 성공률이 오른다고 보였다.
  - 방향별 준수가 비대칭인 것도 이와 맞는다: C1 `minus_x` 0.405 대 `plus_x_plus_y` 0.687.
- **(d) 적은 데이터 lock-in**: 적은 사후 학습 데이터에서 정책은 학습 궤적 쪽으로 '잠긴다'(DeLock).
  - 추론 때 두 조건의 속도 차를 키우면 풀린다(CPG) → L1.
  - 우리 C1은 이미 강제 방향 쪽으로 조금 움직인다(평균 코사인 0.004 → 0.321). 대조 안내가 키울 신호가 있다는 뜻이다.

### 2.2 실데이터 효율 — 실시연 합성 증강·재표적·영상 증강, 시뮬 공동학습 (§89 제약에 맞춰)

§89 원문: 추가 학습·MolmoAct 이식은 **실데이터**, "시뮬거쳤다오는건 절대 반대". 본 학습은 "가정한 정답"(§92)이다. 아래 '제약 적합' 열은 이 둘을 가른다.
- **실→실**: 실영상·실행동만 변형하는 것. 추가 학습에도 적합하다.
- **시뮬 렌더/물리 경유**: 추가 학습에는 금지다.
- **시뮬 데이터 병행**: 시뮬 데이터를 실데이터 라벨로 만들지 않고 따로 섞는 것. 본 학습이면 가능할 수 있으나 **사용자 확인 필요**.

## 4. 다섯 가지 실행안 — 사전 등록 초안

공통:
- 실데이터 평가 = E-SR1d와 **같은** S-E2E val 1,799(먼 구간 848, 69편), 같은 판정 스크립트 함수(`tools/sr0`·`tools/sr1d`), 두 시드.
- 부트스트랩: 스냅샷 10,000회에 더해 **편 군집** 부트스트랩도 보고한다(E-SR1d는 스냅샷만 — 69편이라 구간이 넓어질 수 있음).
- 자체 검사(user-log 87): 관문 실패 → 멈추고 재설계 → 기록 뒤 재개.
- 코드는 새 파일만, 해시는 등록 때 고정한다.

### L1. 자기 결정 대비 대조 안내(Contrastive Decision Guidance, CDG) — 기존 C1, 학습 없음
- **바꾸는 결정**: 판정 FULL이면 실데이터 결합에서 **먼 구간(a = 1) 결정 경유 조종을 허용**한다(§84 보충 10을 고쳐 보충 8을 실데이터로 확장). 추론 경로에는 CDG를 먼 구간에서만 켠다. NONE이면 §84 보충 5 유지, L2/L3로 넘어간다.
- **방법**: 흐름 Euler 각 단계에서 v = v(o, d_force) + (w − 1)·[v(o, d_force) − v(o, d_self)]. d_self = VLA 자신의 확정 결정이다.
  - 근거: DeLock CPG(음 = 학습 지시), π\*0.6의 "moderate β" 경고, APG.
  - E-SR1b와 다른 점: 무조건 속도를 쓰지 않고, 드롭아웃 재학습도 없다.
  - **d_force = d_self이면 안내 항이 0**이다 → 근접(참 결정) 청크는 구성상 바뀌지 않는다.
  - 권한 a < 1이면 w_eff = 1 + (w − 1)·a.
- **조건**: C1_s1·C1_s2(`/data/harvest/ckpt/sr1d/c1_s{1,2}/last`) × w ∈ {1(= E-SR1d 재현), 1.5, 2, 3}. 규칙 칸은 w ≤ 3만 둔다. E-SR1b에서 w = 8은 MSE +330 %였다.
- **지표·규칙(고정)**
  - 주 지표: 먼 구간 A_xy ≥ 0.80(각 시드 ≥ 0.75).
  - 추가 조건: **먼 구간 참 결정 청크 MSE ≤ C1(w = 1) × 1.05**. 참 결정에선 안내 항이 0이라 같아야 하며, 경로 확인용이다.
  - 추가 조건: **강제 청크 크기 p95 ≤ 기록 청크 p95 × 1.2**(과격 청크 방지 — π\*0.6·APG 경고).
  - 추가 조건: 청크 경로 p95 ≤ C1 + 40 ms(두 번 순전파 [추정]).
  - 근접 비열등 N1–N5·전 구간 (i)–(iv)는 E-SR1d 문턱 그대로.
  - 통과한 w 중 가장 작은 w를 채택한다. 없으면 NONE.
- **표본이 가르는가**: 먼 구간 848 × 2시드. E-SR1d C1의 95 % 반폭은 약 0.012(스냅샷)였다. 편 군집으로 약 0.03–0.05 [추정]. 0.8 문턱은 참값이 약 0.75–0.85 밖이면 가른다. w 간 차이는 같은 스냅샷 짝이라 더 좁다.
- **관문**: G1 = w = 1이 E-SR1d C1 기록을 재현(청크 변위 차 최대 ≤ 0.001 mm). G2 = d_force = d_self 스냅샷에서 w > 1 청크가 w = 1과 같음(≤ 1e-6).
- **기대 [추정]**: 먼 구간 A_xy 0.60–0.80.
  - 근거: C1 평균 코사인 0.321·퍼짐 8.6 mm를 w배로 키우면, 방향 신호가 청크 크기(18.7 mm)에 가까워진다.
  - 위험: 반사실이 지지 밖이면 키운 방향이 틀릴 수 있다(E-SR0 R2 경험).
- **비용**: GPU ≈ 1 h(평가 4칸 × 2시드), 유료 0.

### L2. R2 분기 + S-E2E 공동학습 — **사용자 결정 필요**
- **먼저 물을 것**: 실데이터 체크포인트의 **본 학습**에 R2(시뮬) 분기 행을 따로 섞는 것이 §89("시뮬거쳤다오는건 절대 반대")에 걸리는가?
  - 실프레임에 시뮬 라벨을 붙이는 '왕복'은 아니다. 시뮬 데이터를 **병행**하는 것이다.
  - 그러나 결과 체크포인트는 실물용이다. 사용자가 금지로 보면 이 안은 버린다.
- **바꾸는 결정**: 통과하면 §92 레시피의 '먼 구간 분기 50 %'를 실데이터 판에서 **R2 분기 + 실데이터 분기**로 채운다(P1).
- **근거**
  - 공동학습 평균 +38 %(RSS 2025 계열), OT 정렬 +30 %(NeurIPS 2025), 기전 분석(ICML 2026: 구별성 유지가 필요).
  - 우리 E-SR1c: 분기 없는 과제 0.979. 행동 공간(같은 FFW 계열 팔의 관절 청크 [확인 필요: R2 모형과 S-E2E 기록의 관절 정의·순서가 같은가 — 등록 전 관문 G-emb])은 시각보다 영역 차가 작다.
- **조건**: C1 = E-SR1d C1 재사용. C2 = 실데이터 분기 50 % 중 절반을 R2 분기로 바꿈(배치의 25 % 실데이터 분기 + 25 % R2 분기 + 50 % S-E2E 원 행). R2 행에는 영역 토큰을 붙인다(구별성 — ICML 2026). 시드 2, 스텝 E-SR1d와 같음.
- **지표·규칙**: 주 지표 먼 구간 A_xy ≥ 0.80(각 시드 ≥ 0.75). 근접·전 구간 비열등은 E-SR1d 문턱. 추가로 **근접 참 청크 MSE ≤ C1 × 1.05**(시뮬 행동 결이 근접을 망치지 않는지).
- **표본**: L1과 같다.
- **관문**: G-emb = R2·S-E2E 관절 이름·순서·단위·한계 일치, R2 분기를 S-E2E 정규화 통계로 옮긴 값의 범위가 기록 p99.9 안.
- **기대 [추정]**: 0.6–0.85. 불확실성이 크다(영상 영역 차 — 결정 토큰은 같지만 expert가 읽는 백본 문맥이 시뮬 영상에서 온다).
- **비용**: GPU ≈ 2.5 h, 유료 0.

### L3. 실기록 모양 분기 + CMI식 상태 선택
- **바꾸는 결정**: 실데이터 분기 생성기를 IK 직선에서 **기록 청크 변형**으로 바꿀지.
- **방법**
  - (i) **기록 청크 회전**: 스냅샷의 기록 청크 손끝 변위를 수평면에서 강제 방향으로 회전한다(크기·시간 윤곽 유지, 수직은 강제 z). 관절은 E-SR1d와 같은 IK·G-kin 문턱으로 되푼다. 근거: DemoGen·MimicGen 계열 '시연 행동 변형', SIDO '시연 청크 변형'.
  - (ii) **CMI식 선택**: 기존 C1로 스냅샷마다 강제 8방향 청크를 뽑아 **방향 간 퍼짐(ReSteer의 CMI 대용 — 우리 '퍼짐 mm')**을 잰다. 가장 낮은 50 %의 스냅샷에 분기 예산의 2/3를 준다. 근거: ReSteer DROID 80 % 대 무작위 75 %.
  - 선택은 **학습 분할에서만** 한다. val 누수 금지.
- **조건**: C1 = E-SR1d C1. C3a = (i)만. C3b = (i) + (ii). 분기 비율·K·스텝은 E-SR1d와 같게 둔다. E-SR1e가 K·스텝을 바꾸므로, E-SR1e 채택값이 먼저 나오면 그것을 기본값으로 쓰고 그렇게 등록한다.
- **지표·규칙**: 주 지표 먼 구간 A_xy ≥ 0.80. C3b − C3a ≥ +0.03(짝 부트스트랩 하한 > 0)이면 선택을 채택, 아니면 단순한 C3a. 근접·전 구간 비열등은 E-SR1d 문턱.
- **관문**: G-kin(E-SR1d와 같음) + **G-shape**: 변형 분기의 속도·가속 분포가 기록 청크 분포와 KS 거리 ≤ 0.1. 그것이 목적이므로 못 맞추면 재설계한다.
- **기대 [추정]**: +0.05–0.15. 청크 모양만으로 큰 이득은 불확실하다. ReSteer의 핵심 이득은 '실제로 실행한 전환 구간'에서 나왔다.
- **비용**: CPU ≈ 1 h(생성) + GPU ≈ 0.3 h(CMI 대용 계산) + 2.2 h(학습·평가), 유료 0.

### L4. Astra 한 호출 정확도 — 손끝 축 덧그림 · 로봇 기준 평면도 · 경계 상자 텍스트 (E-ACC 팔 추가)
- **바꾸는 결정**: 프롬프트 v2(§94)에 넣을 영상 표시 구성. P4.
- **근거**: 앞 2.4절의 네 가지.
  - AxisGuide(RSS 2026): 축을 그리면 새 위치 +13–20 %p.
  - APC(ICCV 2025): 관점 전환은 추상 장면의 시각 프롬프트가 수치보다 +18.75·+26.33 %p.
  - Hi-VLA 연구: 경계 상자 텍스트.
  - 프롬프트 검진: 축을 말로 정의해도 xy 정답 17–18/30으로 가를 수 없었고, 앞뒤 부호 일치는 11/26이었다. 원근 착시로 보이며, 말 정의가 아니라 카메라 자세 정보가 필요하다는 것이 검진의 결론이었다.
- **조건**(E-ACC 등록의 같은 스냅샷·오라클 채점, 시뮬이라 투영이 정확함): A0 = 현행 프롬프트 v2 후보. A1 = A0 + 머리 영상 손끝에 기저 +x·+y·+z 화살표. A2 = A0 + 로봇 기저 평면도(손끝·대상·놓을 곳 점, 위에서 본 그림, 코드가 FK·장면 참값으로 그림). A3 = A1 + A2 + 경계 상자 텍스트(대상·그리퍼). effort는 E-ACC 기본값 하나로 고정한다(effort 축과 섞지 않음).
- **지표·규칙**
  - 주 지표: 수정 방향 xy 정답률(오라클), 앞뒤 부호 일치율.
  - 채택: 기준 대비 xy 정답률 **+0.10 이상**이고, 짝 McNemar 한쪽 p < 0.05(Holm, 3비교).
  - 부 지표: 구간 계획 정답률 비열등(−0.05), 호출 지연 p95 +20 % 이내.
- **표본이 가르는가**: 검진 표본 30은 0.57 대 0.67도 못 가른다. 짝 설계로 스냅샷 **120개**(오류가 많은 층 70 % + 잘 되던 층 30 % — 빠른 검증 규칙)면 +0.10 차를 검정력 약 0.8로 가른다 [추정: 불일치 쌍 비율 0.25 가정].
- **비용**: 120 × 4 = 480 호출 × 약 7–10원 ≈ **3,000–5,000원**. 예산 안이고, E-ACC 상한 안에서 자체 검사로 조정한다.
- **실물 이전 조건**: 실물은 카메라 보정 투영이 필요하다. E-MA1 G0의 투영 실패를 먼저 막는 관문(투영 손끝 대 포인팅 모델 손끝 ≤ 15 px)을 통과해야 쓴다. 통과 못 하면 A2(평면도, 투영 불필요)만 실물로 옮긴다.

### L5. E-CONF 다음 판 — 지도 은닉 탐침 · 시간 창 이중 조건 · TD 보정
- **바꾸는 결정**: §95 운용 점수를 무엇으로 할지. E-CONF가 끝난 뒤 새로 등록한다(E-CONF 결과를 보고 후보를 고르지 않는다 — 여기서 미리 고정).
- **후보**(E-CONF의 `base`·`lr`·`flow` 옆에 추가)
  - A. **SAFE식 지도 탐침**: 결정 위치 은닉 + 문맥 평균 은닉에 MLP 2층, 보정 분할의 '큰 오류' 라벨로 학습. E-NOV0에서 같은 특징의 비지도 점수는 0.570이었다.
  - B. **FIPER식 이중 조건**: E-NOV0 문맥 평균 k-NN(dr 이동 0.964)과 `flow`가 3결정(≈ 1 s) 창에서 **둘 다** 등각 문턱을 넘을 때만 위험으로 본다.
  - C. **TD 보정**: 편 안 margin 수열로 작은 가치 머리를 TD(0) 학습해 '앞으로 큰 오류가 날 확률'을 낸다. 과녁 = 다음 1 s 안 큰 오류.
- **지표·규칙**: E-CONF 5절과 같은 틀.
  - 결정 과녁 AUROC 향상 ≥ +0.03(R2-새와 S-E2E 둘 다), Holm, 추가 지연 p95 ≤ 5 ms.
  - 추가 과녁 '다음 1 s 안 큰 오류'는 보조로 보고한다.
  - B는 경보율(분포 안 fa95 ≤ 0.07)도 조건이다.
- **표본**: E-CONF와 같다(R2-새 8,208·S-E2E 1,799). E-CONF의 짝 차이 표준오차 추정(0.005–0.01)으로 +0.03은 가를 수 있다. S-E2E는 69편이라 탐침 학습에 교차 반쪽만 쓸 수 있다 — 과적합 관문(보정·평가 분할 AUROC 차 ≤ 0.05).
- **비용**: GPU < 1 h, 유료 0.

## 5. 하지 않을 것 / 보류

- **R2R2R·시뮬 렌더 증강을 추가 학습 데이터로 쓰는 것**: §89 위반 소지.
- **대규모 VL 공동학습(InstructVLA·OneTwoVLA식)**: 우리 규모·일정 밖이다. 구조 교훈(필요할 때만 추론, 지연 위험)만 쓴다.
- **RoboMonkey식 Astra 검증기**: 한 번 9–10 s라 청크 선택엔 늦다. 로컬 검증기가 생기면 다시 본다.
- **학회 미확인 2026 실패 탐지 preprint(SAFECAST·BOKBO·VLAConf·ActProbe·accel 등)**: 규칙상 쓰지 않는다. SAFE·FIPER·TD 보정으로 충분하다.
- **VLA 입력 축 덧그림(AxisGuide를 VLA에)**: 근거는 강하다(RSS 2026). 그러나 실물 투영 관문이 먼저이고 재학습이 필요하다. L4에서 Astra로 먼저 확인한 뒤, 실물 투영 관문이 통과하면 새로 등록한다.
