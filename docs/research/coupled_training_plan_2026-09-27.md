## 0. 한 줄 답

**엮을 부품은 대부분 이미 있다 — 모자란 것은 '학습'이다.** 런타임 배선(답 형식 `astra-couple@v2`의 구간 계획, 두 답 합의·동결, 도착 시 대조 네 판정, 권한 a × 편향, 두 층 관문 + T1, VLA 입력의 구간 줄·그리퍼 질문 `ser-A-min-3`)은 결합 계획 Task 1–26으로 코드·시험까지 끝났다. 없는 것은 셋이다. (1) **그 형식으로 학습된 VLA 체크포인트가 하나도 없다**(ser-A-min-3이 옛 체크포인트를 모두 거부 — 재학습 전에는 폐루프가 돌지 않는다). (2) **상위(8B → 35B)를 결합 형식으로 학습할 데이터와 라벨러가 없다**(E-TEACH-L8·E-PT·E-STRIP8은 모두 `astra-solo` 동기 형식이다; 결합 형식 참값 라벨러 `couple-truth`가 필요하다). (3) **VLA의 끝-끝(E2E) 학습**과 **결합 폐루프 검증**이 없다. 이 문서는 이 셋을 순서·데이터·판정까지 정한다.

### 1.6 검증 판정 — 무엇이 빠졌나 (G3)

사용자 문장의 "상위는 … 잡았다/못 잡았다를 더 정확히 검증"에 해당하는 **필드가 답 형식에 없다**. 지금은 `execution`(실행 상태)과 `claims`(주장, 참고용)로 흩어져 있다. 제안: 학생 상위 형식 `upper-couple@v1` = `astra-couple@v2` + `verify{segment: <직전 합의 구간>, result: achieved|missed|in_progress|unknown, evidence_view}`. Astra 팔은 등록 바이트(`PROMPT_ID` 83fa03a5de19)를 바꾸지 않고 `claims`·`execution`에서 같은 값을 규칙으로 뽑아 비교한다. 관문 근거는 그대로 T1·V1h — `verify`는 학습·평가·다음 의도용이다.

### 1.8 어긋남 목록 (정리)

## 3. VLA 학습 계획

### 3.0 우리 'VLA'의 역할 (user-log 128)

우리 VLA는 일반적인 **언어 → 행동 범용 정책이 아니다**. 계층의 **빠른 조이스틱**이다.
- 입력: 상위의 의도(구간 줄 now/do/next) + 영상(머리 + 활성 손목) + 상태 + 움직임 줄.
- 출력: typed 결정(방향·크기·대상·단계 + 쥐기·놓기 시점) → 흐름 행동 전문가가 0.5 s 관절 청크로 바꾼다.
- 과제를 스스로 해석하지 않는다(과제 문장·구간 계획은 상위 몫). 지금 의도를 실행하고 **세밀한 시점**을 가진다.
- 그래서 학습 목표는 "지시 따르기 일반성"이 아니라 (i) 의도를 받았을 때 그 구간을 끝내는 능력, (ii) 쥐기·놓기 시점 정확도, (iii) 결정과 청크의 일치(상위·관문이 결정을 읽으므로), (iv) 늦거나 틀린 의도에서도 위험하지 않음이다.

### 3.1 ser-A-min-3 단계식 재학습 (먼저, E2E의 비교 기준)

- **무엇**: 지금 레시피 그대로 = 단계 B(Qwen3-VL-4B + LoRA r32 + expert, KI stop + 보조 기하 헤드) + 움직임 줄(드롭아웃 0.3) + 그리퍼 질문 + 구간 줄(드롭아웃 0.3) + 먼 구간 반사실 분기 50 %(R2만, E-SR1c).
- **두 체크포인트**:
  - **VLA-sim**: R2_TRAIN(시뮬) — 결합 폐루프 시험용. 자리 = 본학습(§88·§89: 시뮬 데이터는 본학습 자리만).
  - **VLA-real**: S-E2E RB1·RB2(+ RB3, `rb3_data.md`) 실기록 규칙 라벨(그리퍼 라벨 = 기록된 그리퍼 **명령** 열림도 차분 ±0.176/s, 구간 = 그리퍼 사건 순서, §87·§90 구현 기록 2) — 실물 대비 본학습. 분기 넣을지는 E-SR1e 결과(3.3).
- **절차**: 재학습 뒤 결합 계획 Task 12 Step 17 + 정본 §83 구현 기록 4(카나리·보정·폐루프 스모크, 융합 보정 qid 한계). 코드 기반은 등록 커밋에 고정(P114), 옛 체크포인트 거부는 설계대로.
- **오프라인 관문(무료)**: 그리퍼 결정 정확도, 쥐기·놓기 시점 오차(프레임, 구간 줄 있음/unknown), 청크 그리퍼 준수, 먼 구간 A_xy(E-SR1c 틀), 근접 비열등 N1–N5 — 모두 거리 층(자유/근접)으로(§87 검증).

### 3.2 데이터와 자리 (§88·§89)

| 데이터 | 원천 | 자리 | 라벨 |

- **ADOPT_A / ADOPT_D**: VLA-real 레시피에 그 팔의 기구학 먼 구간 분기(스텝·비율)를 넣는다; §92 P1 '오프라인 성립'. 실물 결합의 먼 구간 결정 경유 조종 후보(런타임 a 추정은 별도).
- **CDG_ADOPT_w**: 학습 없이 먼 구간 대조 안내를 후보로(폐루프 확인 전 기본값 아님).
- **NOT_REACHED / NONE**: VLA-real은 분기 없이(또는 E2E 5절의 결정–청크 일치 경로로), 실물 결합은 청크·손끝 경유(§84 보충 5) 유지. VLA-sim은 E-SR1e와 무관하게 R2 분기 50 %로 바로 재학습한다(E-SR1c 채택).

### 3.4 VLA 단독 관문 (≥ 4/12)

- 실패하면 결합 폐루프(6절 V4)로 가지 않는다 — 짝 차가 정의상 0(P103). 단계별 분해(`diag_couple_dry.py`)로 원인을 나눈다.

### 3.5 뒤: E-TEACH-V — 결합 고리 안의 VLA DAgger

- 선생 = 시뮬 참값(무료)이 기본. 증류된 학생 상위가 자격을 얻으면 그것도(E-TEACH 설계 4절).
- 상태 = **결합 시스템(학생 8B 상위 + VLA)이 간 상태** — 상위의 늦은·틀린 의도, VLA의 지나침·이른/늦은 쥐기가 그대로 들어간다.
- 라벨 사상(기존 어휘): 오라클 부분 목표 − TCP → `dir_xy`·`dir_z`·`mag_coarse`(불감대 1 cm), 목표 물체 → target, 오라클 쥐기 순간(두 패드가 물체를 감싸고 잡기 높이) → gripper close, 놓을 곳 높이 도달 → open, 청크 목표 = 그 상태에서 계획기 스킬 직선 0.5 s(결정·청크 같은 뜻 — E-SR1b 교훈).
- 팔: C-cont(같은 계산량 계속 학습) / D-O(결합 방문 상태 × 참값). 판정 초안: D-O − C-cont ≥ +4/40(짝 부호 검정). 매 반복 기준 체크포인트에서 다시 미세조정(RECAP), APO 경고대로 같은 계산량 대조 필수.
- 5절 E2E가 채택되면 이 DAgger도 E2E 레시피로 한다(5.4).

## 4. 상위 학습 계획 — 결합 형식 (빠진 핵심)

### 4.0 원칙
- §96 보충 2: 35B의 학습·추론 출력은 **구간 의도 + 검증 판정**을 담은 결합 형식이어야 한다. solo 실험(E-TEACH-L8·E-PT·E-STRIP8)은 인식·조종 능력 시험이다.
- 형식: `upper-couple@v1` = `astra-couple@v2`의 요청(영상 3대·덧그림·`vla_now`·`since_last_request`·사건) + 답(평가·구간·명령) + `verify`(1.6). 학생 전용이므로 등록 Astra 바이트를 건드리지 않는다.
- 순서: **8B 대리 먼저(E-TEACH-L8C = L8 레시피를 결합 형식으로) → 35B(E-TEACH-35C)**. 8B는 경향만 보는 임시 대리다(user-log 125).

### 4.1 (a) 시뮬 참값 라벨러 `couple-truth` — 무료
요청 시각 t_send, 도착 예상 t_arr = t_send + L(그 상위의 실측 지연)에서 시뮬 상태로:

| 답 필드 | 참값 규칙 | 재료 |
|---|---|---|
| `segment.now` | t_arr에 오라클 계획기가 있을 단계 → `SEGMENTS`(close→grasp, place_descend→place, open→release) | `tools/eacc/score.py`의 오라클 부분 목표(t_snap + 9.3 s)를 L로 일반화, `intent.PHASE_ORDER` |
| `segment.do`·`next` | now의 그리퍼 할 일(grasp → close, release → open, 나머지 none)·계획 순서의 다음 | `intent` 어휘 |
| `assessment.execution` | 시뮬 사건: 빈손 닫힘(닫힘인데 접촉 없음)·놓침·탁자 밖 → failed, 실패 뒤 재파지 성공 → recovered, 그 밖 진행 → progressing | 시뮬 접촉·물체 자세 |
| `assessment.intent` | 실행 중 청크 변위와 오라클 부분 목표 방향 cos > 0.5 → aligned, < −0.5 또는 오표적(대상 아닌 물체 쪽) → misaligned | `adhere_cos` 정의와 같게 |
| `command` | 먼 구간(a = 1)이고 misaligned·failed면 edit(오라클 방향, 4 cm로 자름, `valid_until` segment_end), 성공 판정이면 stop, 그 밖 continue — 근접(a = 0)에서는 edit 금지(VLA 소유) | 권한 a 규칙(`sr1c_authority.Hysteresis`) |
| `verify` | 직전 합의 구간의 결과: grasp 뒤 쥠(두 패드 접촉 + 들림)·release 뒤 놓임(물체가 놓을 곳 위에 똑바로) → achieved, 시간 창 안 실패 사건 → missed | 시뮬 접촉·자세, `astra_motion/truth.py` 판정 |
| `claims` | 위와 같은 참값에서 | — |

- 평가·이유 문장은 템플릿(L8과 같음 — 한계로 적음).
- 관문 G-ct: 참값 라벨러를 상위 자리에 꽂은 결합 폐루프가 VLA-sim 단독보다 나빠지지 않고, 라벨 1,000개 눈·규칙 대조(구간 now 정답 ≥ 0.95 [가정 문턱]).

### 4.2 (b) 결합 시스템이 간 상태 — 결합 DAgger
- **왜**: 상위의 검증 능력은 **VLA의 실제 실행**(실수·이른/늦은 쥐기·지나침·hold)을 봐야 배운다. 오라클 시연 위 라벨만으로는 `since_last_request`·`vla_gripper_events`·§91 판정이 늘 '계획대로'라 검증을 배울 수 없다.
- **고리**: 반복 k에서 (학생 8B 상위 k) + VLA-sim이 R2 **TRAIN 시드**에서 결합 폐루프를 돈다. 상위 호출마다 같은 요청을 `couple-truth`에 넣어 라벨(β = 0: 학생 답을 실행, 참값은 라벨만). 시계는 시뮬 시간 + 학생 상위 실측 지연 분포 주입(`tools/couple_dry` 지연 주입 방식) — 실행 때와 같은 나이·늦은 답이 생기게.
- **씨앗(반복 0)**: (i) 참값 상위 + VLA-sim 결합 편(상위가 옳을 때의 VLA 실수), (ii) E-ACC식 교란 상태(off_a 오표적·off_c 놓을 곳 어긋남·off_b 다른 물체, `tools/eacc/capture.py`) — Astra가 0/13 놓친 알아채기를 학생이 배우게.
- **층화**: 구간 × (사건 전후 / 자유) × §91 판정(이미 됨·충돌·상황 바뀜 포함) × VLA 실수 종류(빈손 닫힘·늦은 닫힘·지나침·hold). 드문 층은 올려 뽑는다.
- **반복**: 매 반복 기준 체크포인트에서 다시 LoRA(RECAP), 데이터 누적, 2–3회.
- 자리: 시뮬 → 본학습만(§89).

### 4.3 (c) Astra 라벨 — 작은 실물·추가학습 자리만, 유료, 실행마다 사용자 승인
- 실물 프레임(RB2) 위 결합 형식 요청에 Astra 답(E-AT 형식 C·H와 같은 자리) → 학생 상위 **추가학습**. 참값이 없으므로 거르기 = 되짚기 일치·규칙 결과 신호·두 답 합의·T1식 근거(E-AT 3.3).
- 시뮬 안 L-A 팔(학생 상태 × Astra 답)은 §96대로 본학습 자리에 허용되지만 유료이므로 **사용자 승인 뒤**에만, 8B 결합 결과가 나온 뒤 필요성을 다시 판단한다.

### 4.4 (d) 공개 데이터 흐름 섞기 (§97 보충 1·3)
- §97 보충 1: 다양한 데이터는 **필수**, 비율·형태만 실험으로(E-XEMB8·E-OPEN8, 둘 다 초안).
- 결합 형식에 넣는 방식: (i) 인식 QA(물체 점·말단 점·탁자 평면, 픽셀 답)를 보조 행으로, (ii) 공개 편의 그리퍼 사건(T5 점 추적 + 관절값 사건, §97 보충 3)에서 **'이 닫기 뒤 쥐었나'·'지금 어느 구간인가'** 검증·구간 QA를 만든다 [제안 — 공개 시연은 대부분 성공이라 missed 표본이 적다(E-AT 3.2의 성공 편중 한계와 같음)]. 몫은 일반·공간 5–25 %(cross_embodiment 1.5절 보고 범위) 안에서 E-XEMB8 결과로 정한다.

### 4.5 (e) 최소 프롬프트 교훈 (E-STRIP8)
- E-STRIP8(`prereg_strip8.md`, 결과 없음)은 손으로 준 장면·요령 정보(탁자 높이·격자·낙하선·물체 크기·잡기/놓기 요령)를 추론 때 빼도 되는지, 학습 때 특권 정보 드롭아웃(모두 p 0.3, 아니면 각 p 0.5)이 돕는지를 잰다.
- 결합 형식 요청에는 이미 그 정보가 적다(덧그림은 로봇 기구학에서만, 물체 참값 없음 — `prompt_v2.OVERLAY_HEAD`). 그래도 과제 문장·물체 이름 외 손 정보가 있으면 E-STRIP8 판정대로: NOT_NEEDED면 결합 형식도 최소 요청으로 학습·추론, NEEDED면 특권 입력은 **학습 때만**(드롭아웃) 두고 추론 요청은 자동 원천(§97)으로 채운다. T1 판정 글(G4)도 같은 규칙으로 — 로봇 자기 정보(R)라 추론에도 넣을 수 있다.

### 4.6 35B로 옮기기
- E-TEACH-L8C가 6절 V4를 통과하면 같은 데이터(반복 누적분)로 35B-A3B LoRA(`harvest/teach_35b/train.py`, 라우팅 전문가 제외 LoRA, 생각 끔)를 학습하고, 35B로 결합 DAgger를 1회 더 돈다(35B가 간 상태는 8B와 다르다).
- 먼 구간 공간 목표를 점(E-PT)으로 결합 형식에 넣을지는 E-PT 결과와 V4 뒤 별도 팔로(G2).

## 5. VLA 끝-끝(E2E) 학습 (user-log 128)

### 5.1 지금은 무엇이 '따로'인가 (코드로 확인)
- 단계 B는 이미 **한 모델**에서 결정 NLL + 흐름 정합 + 보조 기하 손실을 함께 학습한다(`stageb_train.py`: loss = λ_dec·결정 + λ_act·흐름 + λ_aux·보조). 그러나:
  1. expert → 백본 기울기는 **차단**(`--ki stop` 기본, `stageb_model.insulate`) — 행동 손실이 백본에 닿지 않는다.
  2. expert는 학습 때 **정답 결정(라벨)**으로만 조건된다(`stageb_model.py:142` `D.dec_ids(s["committed"], …)`) — 실행 때는 모델 자신의 (틀릴 수 있는) 결정으로 조건되므로 노출 편향이 있다.
  3. 백본에는 행동 자체의 이산 표현이 없다(결정 토큰 = 목표 방향 규칙 라벨, 거침).
  4. 결정과 청크가 따로 감독되어 일치는 데이터에만 기댄다: 백본 문맥에 결정보다 촘촘한 같은 방향 정보(보조 헤드 `g2goal`)가 있어 expert가 토큰을 무시한다(`decision_adherence_0p8` 1.3). R2는 반사실 분기로 0.991(E-SR1c), 실데이터는 0.536(E-SR1d), E-SR1e 대기.
  5. 구간 줄은 unknown 드롭아웃뿐 — 늦은·틀린 의도가 없다(G5).
- 폐루프 증거: VLA 단독 approach에서 모델 답 방향이 머그를 가리킨 비율 36 %(오프라인 0.99), 청크는 결정을 72 % 따름(`vla_alone_diag.md`) — 결정 자체가 폐루프 상태에서 틀린다(분포 이동, 가설).

### 5.3 E2E 레시피 후보 (E-VLA-E2E, 무료, 새 사전 등록)
결정은 **감독된 중간 출력으로 남긴다**(상위·관문·확신도 기록이 읽는다). 바꾸는 것은 행동 신호가 모델 전체에 닿는 길과 결정–청크 일치다.

| 팔 | 바꾸는 것 | 근거 |
|---|---|---|
| S0 단계식 | 3.1 ser-A-min-3 그대로 | 비교 기준 |
| E1 이산 행동 토큰(KI식) | 백본이 결정 6질문 뒤에 **0.5 s 청크의 이산 토큰**(FAST식 또는 축별 구간 토큰)도 예측 — 행동 손실이 이 토큰으로 백본에 닿고, expert → 백본은 계속 차단 | KI |
| E2 예측 결정 조건(교과) | expert 조건을 학습 초반 정답 결정 → 뒤로 갈수록 백본이 **예측한** 결정(표집)으로 바꿈 — 실행 때와 같은 조건, 결정이 틀리면 청크도 그 결정을 따르게(일치) | Libra-VLA 동적 교과, 노출 편향 |
| E3 E1 + E2 | 둘 다 | — |
| E4 의도 교란 | 구간 줄: unknown p 0.3(기존) + **늦은 의도**(진짜 전이 뒤 0–L_max초 동안 이전 줄 유지, L_max = 상위 p95 지연) + 소량 틀린 do; 라벨은 참값 그대로 | G5, 실행 때 상위 의도는 늦게 온다 |
| (절제) E5 `--ki scale:g` | 작은 g로 흐름 기울기를 백본에 흘림 | KI가 '해롭다'고 보고 — 확인용 절제만 |
- 먼 구간 반사실 분기 50 %(R2)는 모든 팔에 공통(E-SR1c 채택). 실데이터 판은 E-SR1e 결과 레시피.
- 직렬화: E1(행동 토큰)은 결정 칸이 늘어 **판 올림**(`ser-A-min-4`, §77) — E-AT `quality:` 줄(G8)과 한 번에 묶는다. E2·E4는 학습 옵션이라 판 올림 없이 가능(새 인자는 재개 키, P114).
- 자리: R2 데이터 = 본학습. 실데이터 E2E = S-E2E 규칙 라벨 본학습. 실물 Astra 라벨은 추가학습만.

### 5.4 결합 고리 안의 E2E — VLA DAgger
- 3.5의 E-TEACH-V를 E2E 레시피(채택 팔)로: 결합 시스템(학생 8B 상위 + VLA)이 간 상태 × 시뮬 참값 결정·청크·그리퍼 시점 라벨, **입력 구간 줄은 상위가 실제로 보낸 것**(늦음·오류 포함) — 의도 교란(E4)을 인위가 아니라 실제 분포로 학습한다.
- 상위 DAgger(4.2)와 **번갈아**: 반복 k에서 상위 k + VLA k로 굴려 두 라벨을 한 번에 모으고, 둘 다 기준 체크포인트에서 다시 학습.
- 자리: 시뮬 → 본학습만. 실물 판은 E-TEACH-R·E-AT-R(추가학습, 실물 접근·승인 뒤).

## 7. 위험과 사용자 결정 (3개)

- **D1 학생 상위의 결합 형식에 명시적 검증 필드 `verify`를 더할까** (추천: 예). 등록 Astra 바이트(`astra-couple@v2`)는 그대로 두고 학생 형식만 `upper-couple@v1`로 둔다. 대가: Astra와 학생의 답 형식이 한 필드 다르다(비교는 `claims`·`execution`에서 규칙으로 뽑아 맞춤).
- **D2 GPU 순서 — ser-A-min-3 VLA-sim 재학습을 지금 가장 먼저 할까** (추천: 예). 모든 폐루프(V1–V4)와 E2E 비교 기준이 여기에 막혀 있다(handoff §0 [결정 필요]). VLA-real은 E-SR1e 결과 뒤. E2E 팔 학습은 V1 통과 뒤 같은 GPU 줄에.
- **D3 VLA 구간 줄의 세분도** (추천: 지금 4단계 줄 유지, V4의 쥐기 시점 오차로 다시 판단). 상위의 '이번엔 잡는다'(now=grasp)를 VLA에 따로 보이면 시점이 빨라질 수 있지만, 줄이 그리퍼 정답을 알려 주게 되어 VLA가 '언제'를 배우지 않는다(F12). Libra-VLA의 역U자처럼 세분도는 실험으로 정할 값이다.
- 위험(결정 아님): 결합 DAgger의 상태는 학생 상위·VLA가 둘 다 바뀌면 움직이는 과녁이다(번갈아 학습·반복마다 기준에서 재학습으로 줄임); 시뮬 참값 라벨은 실물에 없다 — 실물은 E-AT·E-TEACH-R(추가학습, 유료·승인)로만; 과제 하나(mug_tray)라 일반화 주장은 §97 보충 1의 OOD 세트 전까지 하지 않는다.
