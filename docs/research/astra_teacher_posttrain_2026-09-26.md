## 0. 요약

**한 줄 판정**: 실데이터 전용이라는 조건에서 Astra 교사 추가 학습은 **두 단계**로 나뉜다. (A) **지금 할 수 있는 것 = 기록된 실물 시연(ROBOTIS AI Worker RB1·RB2)을 Astra가 오프라인으로 보고 붙인 라벨로 추가 학습**(MolmoAct·Hi Robot·Steerable Policies식 "실물 영상에 모델 라벨") — 이것은 DAgger가 **아니다**(VLA가 스스로 간 상태가 없다). 되짚기(시연자가 실제로 간 방향)가 방향 정답을 공짜로 주므로, 돈을 내는 Astra 라벨은 **되짚기가 못 주는 것**(구간 품질·실패/재시도 판정·실패 진단 J2·"Astra라면 끼어들까")에만 쓴다. (B) **진짜 DAgger(개입 학습) = 실물 로봇 폐루프**(직렬 Astra 흐름 + VLA, 로봇 옆 RTX PRO 6000 — 정본 §49)에서 Astra 수정을 모으는 **E-AT-R** — 하드웨어 시간이 생기면 하는 **미래 작업**이다. 시뮬을 거쳐 돌아오는 경로(R2 폐루프 수집·R2 MolmoAct 데이터 M3·M4·dr)는 E-AT에서 뺀다.

### 1.3 문헌에서 가져오는 설계 원칙
1. **교정은 학생이 간 상태에서 모아야 한다**(CR-DAgger 원문, Qwen3 on-policy 증류, RECAP 개입) → 오프라인 시연 라벨은 DAgger가 아니며, 진짜 개입 학습은 실기 폐루프(E-AT-R).
2. **나쁜 행동도 명시 라벨로**(RECAP negative, APO 실패 25 %) — 버리기보다 표시해 학습.
3. **개입 BC 혼합만으로는 기준보다 나빠질 수 있다**(APO 39.0 대 40.5) → 같은 계산량 대조가 필수.
4. **교정 행동은 positive 강제**(RECAP) — 단 우리는 결과·T1로 확인된 교정만.
5. **VLM 라벨 정확도는 데이터마다 다르다**(RoboReward) → 우리 데이터에서 호출 단위 정확도 먼저(E-ACC-R, 정본 §88 선행 조건과 같음).
6. **정책·가치를 사전학습 체크포인트에서 다시 미세조정**(RECAP) — 반복하며 누적 표류를 막는다.
7. **실물 영상 + 모델 라벨 → 작은 모델 학습**(MolmoAct·Hi Robot·Steerable)은 실데이터 전용 조건에서 쓸 수 있는 검증된 경로.

## 2. 실데이터 전용으로 바뀐 전제 (정본 §88 대비)

| 정본 §88 초안 | 사용자 지시 뒤(이 설계) |
|---|---|
| 추가 학습 데이터 = 결합 폐루프(직렬 Astra + VLA)에서 Astra가 낸 판단·수정 | **오프라인 E-AT** = 기록된 실물 시연(RB2)을 Astra가 보고 붙인 라벨. **E-AT-R**(미래) = 실물 로봇 폐루프에서 Astra가 낸 수정 |
| 거르기: 오라클·결과·두 답 합의·T1 | 시뮬 오라클 없음 → **되짚기**(시연자가 실제로 간 방향·거리 = 실물 정답), **규칙 결과 신호**(재파지·놓침·정체), 두 답 합의, **T1식 기록 고유감각** |
| E-ACC(시뮬 로그 대비 정확도) | E-ACC의 **프롬프트 교훈**(정의 누락 등)은 가져오되, 정확도 수치는 시뮬 장면 기준이라 **실물 라벨 자격 근거로 쓰지 않는다** → 실물 프레임 위 **E-ACC-R**을 따로 잰다 |
| 결합 폐루프 R2 판(E-Couple 데이터)도 라벨 원천 후보 | **빼다**(시뮬 왕복). E-Couple이 잰 호출 단가·지연은 비용 추정에만 쓴다 |
| MolmoAct R2 데이터(M3 경로 다양화·M4 두 대상·dr 변형) 포함 | **E-AT 데이터에서 뺀다**(시뮬). 실물에서의 대응 다양성 = RB2 공구 11종(대상 선택)·RB1 병 색·상자 색(대상 선택)·좌/우/양팔·과제 떼어 두기 |

**무엇이 오프라인에서 되고 안 되나 (정직한 구분)**
- 된다: 시연 구간의 **품질 판정**(어느 구간이 헛손질·재시도·정체였나), **실패 진단**(왜 첫 시도가 실패했나 — J2), **의미 라벨**(지금 어느 하위 단계인가), **VLA 예측 청크 비평**(VLA가 이 장면에서 낸 청크를 Astra라면 고칠까 — 단 로봇은 그 청크를 실행하지 않았으므로 결과는 모름).
- 안 된다: VLA가 스스로 만든 **분포 밖 상태**에서의 교정(= DAgger의 핵심), **Astra 없는 성공률·새 환경 성공률**(실행이 없으므로). 이 두 가지는 E-AT-R에서만.
- 방향 정답은 **되짚기가 이미 준다**(S-E2E 휴리스틱 라벨 `se2e_heur_ee033@v1`이 바로 그것). 따라서 시연 상태에서 Astra의 `edit` 방향을 돈 주고 사서 방향 정답으로 쓰는 것은 되짚기보다 나을 수 없다 — **유료 라벨은 되짚기가 못 주는 정보에만 쓴다.**

## 3. 라벨 설계 — Astra 출력 → VLA 학습 목표

Astra 답 형식은 결합 구현 그대로 `astra-couple@v1`(`harvest/couple/schema.py`: 실행 상태 not_started/progressing/failed/uncertain/recovered, 의도 aligned/misaligned/uncertain, 확신 low/medium/high, 명령 continue/edit/stop, `edit` = 위치 변위 m·회전 rad·그리퍼 keep/open/close, 주장 종류 grasp_ready/grasped/…). 오프라인 라벨용으로 **두 요청 형식**을 새로 둔다(프롬프트 판본은 실행 에이전트가 고정·해시):
- **형식 H(되짚기 구간 판정, MolmoAct식)**: 기준 시점 t의 앞 3 s·뒤 2 s 구간을 1 Hz 프레임 격자로(머리 격자 1장 + 활성 손목 격자 1장), 그리고 코드가 만든 수치 문장(활성 팔, 손끝 속도 구간 `still/slow/fast`, 그리퍼 명령·상태 열, 과제 문장). 미래 프레임을 보여 주므로 **라벨 전용**(실행 때 쓸 수 없는 정보) — MolmoAct의 미래 궤적 라벨과 같은 성격.
- **형식 C(비평, 실행과 같은 조건)**: 시점 t의 세 카메라(머리·양 손목) 정지 영상 + 움직임 줄(§83) + **VLA가 이 장면에서 낸 청크의 로봇 기준 변위 문장**(FK, 예: "policy plans forward 2.1 cm, left 0.4 cm, down 0.8 cm over 0.5 s, gripper keep"). 미래 프레임 없음. 덧그림은 안 쓴다(S-E2E 머리 카메라 FK 투영 G0 실패 — §85; P65·P77).

### 3.1 출력별 학습 목표

| Astra 출력 | 학습 목표 | 결정층·expert 의미 맞춤(E-SR1b 교훈) | 거르기 |
|---|---|---|---|
| **평가(assessment)** — 형식 H의 구간 실행 상태 | **이점 표시 한 줄** `quality: good|bad|unknown`(RECAP식)을 문맥의 결정 질문 바로 앞에 넣는다. progressing·recovered = good, failed·"정체" = bad, 라벨 없는 행 = unknown | 표시 한 줄이 결정 토큰과 expert 청크 **둘 다의 조건**이 된다(둘 다 같은 행의 기록된 움직임을 배우므로 뜻이 같다). 실행 때는 항상 `good` | 규칙 사건과 일치(§3.3), 두 답 합의, 근거 카메라가 손목이어야 '실패 쥠' 주장 유효(설계 §12) |
| **`edit` 방향·크기** | 결정 토큰 값은 **항상 되짚기**(다음 0.3 s 실제 손끝 변위의 `dir_xy`·`dir_z`·`mag_coarse`, 본 학습과 같은 정의), 청크 목표는 **항상 기록된 청크**. Astra `edit`은 **행 가중**만 바꾼다: 형식 C에서 Astra가 VLA 청크를 수정했고 그 `edit` 방향이 되짚기 방향(다음 1 s)과 cos > 0.5로 맞으면 그 행 가중 ×2(어려운 표본), 맞지 않으면 가중 변화 없음 + 불일치 기록 | Astra `edit`의 시간 척도(다음 답까지 약 9–10 s, 창 1–8 s)는 결정 창 0.3 s·청크 0.5 s와 다르다 → **Astra의 크기를 크기 토큰으로 옮기지 않는다**. 방향 토큰에 Astra 방향을 직접 넣으면 결정층은 Astra 뜻, expert는 기록 청크 뜻을 배워 E-SR1b B의 비열등 실패(청크 MSE +14.6 %)를 되풀이한다 | 되짚기 일치, 두 답 합의, 근접 구간(그리퍼 사건 전후 1 s) 폐기 |
| **계속/정지(continue/stop)** — 형식 C | 학습 라벨로 쓰지 않는다. 대신 (i) **무료 대리 지표 검증**: "VLA 청크 방향이 되짚기와 어긋남(cos ≤ 0.5)"이 Astra `edit/stop`을 얼마나 맞히는가(E-ACC-R 관문 Q5), (ii) 통과하면 **호출 필요 머리**(확인 헤드 옆 이진 머리, "Astra가 고칠 확률")를 무료 대리 라벨로 학습(선택 팔, 7절 [결정 필요])·실행 때 T_nov 후보, (iii) 평가 감사(6절) | 머리는 결정·청크 경로와 떨어진 보조 출력이라 조이스틱 의미를 바꾸지 않는다 | 대리–Astra 일치 ≥ 0.8일 때만 머리 학습 |
| **계속/정지 — 형식 H의 `stop`(과제 끝·단계 끝)** | 쓰지 않는다 — 단계 끝은 그리퍼 사건 규칙이 더 정확(§82: K3 성공 판정은 작은 모델·코드로 강등) | — | — |
| **J2 실패 진단·복구**(형식 H, 사건 구간에만) | 행동 라벨이 **아니다**. 실패 유형 범주(접근 어긋남·너무 일찍 닫음·미끄러짐·부딪힘·가려져 모름) + 한 레버 복구 + `verify_after`·`falsify` → **J6 교훈 저장**·`recovery_cache.py` 씨앗(실물 런타임용), 재시도 구간을 good으로 표시하는 근거 중 하나 | — | 시점은 Astra가 아니라 규칙 사건(FLARE: 시점 정확도 66–78 %), 범주만 Astra; 두 답 합의 |
| **그리퍼 판단**(§87 쥐기/놓기/유지) | Astra에서 받지 않는다. 라벨 = 기록된 그리퍼 명령 규칙(§87 계획) | — | Astra low는 실제 쥠 13/25를 놓침(§86) |

### 3.2 규칙 결과 신호와 T1식 근거 (무료, 실물 기록만으로)
시뮬 오라클 대신 기록된 10 Hz 상태·행동에서 규칙으로 뽑는다. 문턱은 **라벨을 보기 전에** 학습 분할 분위수로 고정한다(§83 움직임 줄 경계와 같은 절차).
- **T1식 쥠 근거**: 그리퍼 **행동(리더 명령)은 닫힘**(≥ 분위 문턱)인데 **상태는 완전 닫힘 전에서 0.5 s 이상 멈춤** → 물체가 손가락을 막고 있음(쥠). 그리퍼 상태 0 = 열림, 약 1.1 = 닫힘(`se2e_data.md` 3절). 관문 G-T1R: 무작위 30장을 손목 영상과 나란히 눈으로 확인해 규칙이 맞는지 본다(P61: 만든 방법 이름을 정답으로 믿지 않는다).
- **E1 재파지(실패 시도 + 회복)**: 닫힘 명령 → 3 s 안에 열림 명령(그사이 손끝 이동 < 5 cm, T1 쥠 근거 없음) → 5 s 안에 다시 닫힘. 앞 시도 = 실패 후보, 뒤 시도 = 회복 후보(뒤 시도에 T1 쥠 근거가 있어야 회복 확정).
- **E2 놓침**: T1 쥠 근거가 있던 뒤 열림 명령 없이 상태가 완전 닫힘으로 튐 → 물체를 떨어뜨림.
- **E3 정체**: 편의 첫·끝 1 s 밖에서 손끝 속도 `still` + 그리퍼 변화 없음이 1.5 s 이상.
- **E4 되돌아감**: 연속 0.5 s 변위 두 개가 cos < −0.5(각 > 1 cm).
- **되짚기 방향**: 다음 0.3 s(결정 라벨)·다음 1 s(`edit` 비교)·다음 그리퍼 사건까지(구간 판정 문맥)의 실제 손끝 변위(URDF FK).
- 편 끝 결과: 원격조작 시연이라 대부분 성공으로 보되, **성공 표시가 데이터에 없다**는 점을 한계로 적는다(RoboReward의 "success-heavy" 문제와 같다).

### 3.3 거르기 규칙 (라벨이 되는 조건)
1. **자격(E-ACC-R 통과)**: 그 답 종류가 호출 단위 정확도 문턱을 넘은 경우만(6.5절 규칙).
2. **결과·규칙 일치**: 형식 H의 bad는 E1 앞 시도·E2·E3·E4 구간과 겹칠 때만, good은 사건이 없는 구간 또는 T1 확인된 회복 구간일 때만. 규칙과 어긋나는 Astra 판정은 라벨로 안 쓰고 `disagree` 기록(나중에 사람 표본 검사).
3. **두 답 합의**: 같은 입력을 두 번 물어(gpt-6-astra는 temperature·seed를 거부 — P49, 자연 변동) 실행 상태·실패 범주가 같을 때만. 한 답만 있는 종류(대조 구간)는 합의 대신 규칙 일치만.
4. **T1식 근거**: "쥠 실패"·"쥠"과 관련된 모든 판정은 T1식 근거와 맞아야 한다(Astra 손목 판정은 참고, §86).
5. **근접 권한**(user-log 93): 그리퍼 사건 전후 1 s 안(실물 오프라인의 근접 대용 — 물체 위치가 없으므로)에서는 Astra `edit` 관련 가중을 주지 않는다.
6. **무효 답**: 형식 오류·범위 밖(`edit` > 5 cm 등, P62)은 라벨에서 빼고 무효율로 센다(> 10 %면 멈추고 재설계, user-log 87).

### 3.4 늦은 답(15 s)과 지연 9–10 s의 몫 나누기
- **오프라인 E-AT**: 로봇이 움직이지 않으므로 "늦은 답"이 없다. 모든 답은 **입력 프레임의 시각 t에 붙는다**(보낸 시점 = 라벨 시점). 이것이 오프라인 라벨의 장점이다 — 지연 9–10 s가 몫 나누기를 흐리지 않는다.
- **E-AT-R(실기 폐루프, 미래)**: (1) 답의 **평가**는 보낸 시점 상태 s_send에 붙인다(Astra가 본 것). (2) `edit`은 나이 > 15 s면 런타임이 이미 버리므로(§86) 라벨에서도 뺀다. (3) 나이 ≤ 15 s인 `edit`은 **도착 뒤 실제로 실행된 움직임**(VLA + §11 편향)으로 되짚어 결정 토큰·청크 목표를 만든다 — 라벨 = "편향을 받은 뒤 로봇이 실제로 한 것"이라 결정층과 expert가 같은 뜻을 배운다. (4) 그 수정이 좋았는지는 **도착 뒤 창(다음 답까지) 안의 결과**로 판정: T1 쥠 확정·진행(과제 단계 전이)·되돌아감 없음이면 positive 강제(RECAP), 창 안에 실패 사건이면 그 수정 구간은 bad. (5) 보낸 시점과 도착 시점 사이(약 9–10 s)의 VLA 단독 구간은 Astra 평가가 failed면 bad 후보(APO의 "개입 직전 행동 = 나쁨"), 단 두 답 합의가 있을 때만. (6) 근접 구간 수정은 라벨로 쓰지 않는다(권한 분배, user-log 93).

### 4.3 E-ACC-R — 실물 프레임 위 Astra 호출 단위 정확도 (유료, 자격 판정)

- **정답**: 형식 C — `edit` 방향 대 되짚기 1 s 방향(cos > 0.5), `continue` 대 "VLA 청크가 되짚기와 맞음"; 형식 H — 실행 상태 대 규칙 사건(3.2), 실패 범주는 사람 표본 20개(사건 영상을 보고 적은 범주 — 실행 에이전트가 유료 전에 적어 둔다, P61).

### 4.4 유료 라벨 (자격 통과 종류만, G0 통과 때만)
- **형식 H 사건 라벨**: RB2 학습 분할 E1·E2 사건 최대 100개 × 두 답 = 200호출 → 사건마다 앞 시도 구간(bad 후보)·회복 구간(good 후보)·J2 진단.
- **형식 H 대조 구간**: 사건 없는 구간 40개 × 한 답 = 40호출 → good 표시의 교정용(규칙만으로 good인 구간과 Astra good의 일치율).

- 형식 C는 라벨 단계에서 부르지 않는다(방향 정답은 되짚기가 준다 — 2절). 호출 필요 머리는 E-ACC-R Q5 통과 때 무료 대리 라벨로 만든다.

| **이 결과로 바꾸는 설계 결정** | (D1) Astra가 실물 프레임에서 낸 답 가운데 **어느 종류를 학습 라벨로 써도 되는가**(E-ACC-R). (D2) 오프라인 Astra 라벨 추가 학습을 **융합 VLA 레시피에 넣는가**(AT-ind / AT-w / 안 넣음). | **표본으로 가를 수 있나** | D1: 종류당 60 입력 → 정확도 0.80에서 Wilson 95 % 하한 약 0.68(30 입력이면 약 0.63) — 그래서 **점추정 ≥ 0.80 그리고 하한 ≥ 0.65**로 등록(6.5; 항목 30개뿐인 종류는 점추정 약 0.83 이상이어야 통과). D2: 주 지표 층(사건 주변) 행 ≥ 780이면 짝 최소 검출 효과 약 0.05 [추정: p ≈ 0.5, 짝 상관 0.5, 80 % 검정력, 편 안 상관은 무시 — 에피소드 단위 부트스트랩이면 더 커질 수 있어 G0에서 편 수도 함께 본다] — G0 관문(a)가 이것을 보장; 못 넘으면 D2는 **판정하지 않고** 4.4를 뺀다. D3: 형식 C 60 스냅샷의 일치율, 문턱 0.8. D4: D1·D2의 결과가 곧 근거 |
| **더 싼 사전 실행** | G0(규칙 집계, CPU) → 로컬 Qwen 사전 실행(4.2, 무료) → 유료 첫 20호출로 **단가 실측**(추정 40원/호출을 넘어 50원 초과면 4.4 사건 수를 80으로 줄인 판을 등록 변경으로 커밋한 뒤 재개) |
| **도중 멈춤 조건** | 무효 답 > 10 %, 규칙–판정 일치가 사전 실행 대비 급락(프롬프트·입력 버그 의심), 비용·시간 2배 초과, 관문 실패, 두 답 합의 < 0.5(라벨 원천으로 부적합) → 멈추고 재설계 → 등록 변경 커밋 → 재개 |
| **끝 검증** | 판정 스크립트(등록 때 고정)와 따로 쓴 재집계가 주요 값 차 0.0, 표·프레임 표본 눈검사(규칙 사건 영상 10개), 비용 장부 합계 대조 |

### 6.2 팔과 데이터
- B0(기준, 시드 1·2) → C / AT-ind / AT-w(각 시드 1·2), 5절 레시피. 라벨은 4.4에서 거르기(3.3)를 통과한 행만.
- 평가 집합은 4.0 그대로, 모든 팔에 같은 스냅샷(sha 고정).

### 6.3 지표
| 지표 | 정의 | 역할 |
|---|---|---|
| **P1 사건 주변 방향 적중**(주) | 평가 집합 사건 ±3 s 행 중 **good 구간**(규칙상 실패 시도가 아닌 행)에서, 참 결정 조건 청크의 손끝 xy 변위와 기록 변위의 cos > 0.5 비율(E-SR0 진단과 같은 정의) | D2 주 지표 — 어려운 장면에서 좋은 행동에 가까워지는가 |
| P2 실패 시도 거리 | 사건 앞 시도(bad) 행에서 예측 청크와 기록 청크의 MSE 상대 변화(클수록 실패 행동을 덜 따라 함) | 판정 밖 보고 |
| **Astra 없는 성공 대리**(오프라인) | P1 + 전체 방향 적중 + 결정 정확도 | "Astra 없이 맞게 움직이는가"의 대리 — 실기 성공률 아님을 표기 |
| **새 환경 대리** | 떼어 둔 과제 2종에서 P1·전체 방향 적중 | "새 환경 성공률"의 대리 |
| **Astra 호출 필요량** | (a) 무료: 평가 스냅샷 중 "청크 ≠ 되짚기" 비율(자유 층), (b) 유료 감사: 고정 40 스냅샷에서 형식 C로 Astra가 `edit/stop`을 낸 비율(최선 AT 팔 대 C, 짝 80호출). **분당 교정 수는 E-AT-R에서만**(오프라인엔 시간 축이 없음) | D2·D4 |
| **결정·청크 준수** | 결정 정확도(휴리스틱 라벨 3질문), E-SR0 반사실 A_xy·A_z(도구 `tools/sr0/` 재사용), 청크 MSE | 비열등 |
| **근접 능력** | 그리퍼 사건 1 s 안 행의 그리퍼 상태 일치·청크 MSE·(Task 12 뒤) 그리퍼 판단 정확도와 시점 오차(프레임) | 비열등 |

### 6.4 채택 규칙 (결과 전 고정)
1. **ADOPT_AT(팔)**: 최선 AT 팔(두 팔 Holm 보정)에서 P1 차(AT − C) ≥ **+0.05**, 짝 부트스트랩(에피소드 단위 10,000회) 95 % 하한 > 0, **그리고** 비열등 전부 통과: 전체 결정 정확도 ≥ C − 0.01, 전체 청크 MSE ≤ C × 1.05, 근접 층 그리퍼 일치 ≥ C − 0.01, RB1 층 방향 적중 ≥ C − 0.02, A_xy ≥ C − 0.02, 떼어 둔 과제 P1 점추정 ≥ C. 두 AT 팔이 모두 통과하면 단순한 AT-w.
2. **NO_OFFLINE_GAIN**: 비열등은 통과하지만 P1 문턱 미달 → 레시피에 넣지 않음. Astra 라벨은 J6 교훈·복구 캐시에만 남기고, 교사 추가 학습은 E-AT-R(실기 폐루프)로만 간다.
3. **REJECT**: 비열등 하나라도 실패.
4. 경계(P1 차 [+0.04, +0.06])면 시드 3을 한 번 더(E-SR1c와 같은 규칙).
5. C − B0 차도 보고한다(계속 학습만의 효과; 판정 밖).

### 6.5 라벨 자격 규칙 (E-ACC-R, 결과 전 고정)
- 답 종류(형식 H 실행 상태, 형식 H 실패 범주, 형식 C `edit` 방향, 형식 C continue 판단)마다: **정확도 점추정 ≥ 0.80 그리고 Wilson 95 % 하한 ≥ 0.65**, 항목 ≥ 30, **두 답 합의 ≥ 0.75**, 무효 < 10 %. 형식 H 실패 판정은 추가로 재현율 ≥ 0.70·정밀도 ≥ 0.80(규칙 사건 기준).
- Q5(무료 대리 검증): "청크 ≠ 되짚기" 대 Astra `edit/stop` 일치 ≥ 0.80 → 호출 필요 머리를 무료 대리 라벨로 학습(선택 팔).
- 자격 없는 종류는 라벨에 쓰지 않는다. 형식 H 실행 상태가 자격 미달이면 4.4 전체를 하지 않는다(AT 팔의 라벨 원천이 없어짐 → D2 판정 안 함).

## 7. 미래 작업 — E-AT-R (실물 로봇 폐루프 개입 학습)

- **언제**: 실물 AI Worker(FFW-SG2, 베이스 고정, §36–§39)와 로봇 옆 RTX PRO 6000(§49) 시간이 생기고, 오프라인 E-ACC-R 자격 결과가 있을 때.
- **무엇을**: 직렬 Astra 흐름(한 번에 하나, F0, low, 늦은 답 15 s·시간 초과 20 s — §84 보충 2·§86) + 융합 VLA(E-AT에서 채택된 판 또는 B0)로 실제 과제를 돌리며, Astra 답을 3.4절 규칙으로 라벨화 → RECAP식 표시 + 교정 positive 강제(T1·결과 확인된 것만) → 사전학습 체크포인트에서 다시 미세조정(RECAP). 사람 교정은 쓰지 않는다(Astra가 교사) — 다만 되감기(RaC식, 근거 약함)는 쓰지 않고 실제 개입만.
- **지표**: Astra 없는 실기 성공률(편당), 새 물체·새 배치 성공률, **분당 Astra 수정 수**·교정 비율(GPT-as-Policy 14.4 % 기준 크기), 결정·청크 준수(런타임 `adhere_cos`, 계획 Task 7), 근접 능력(T1 관문 통과율·쥐기 시점 오차).
- **규모 [추정]**: 로봇 1분당 350–500원(§86) → 23,000원이면 약 46–66분, 편 2분이면 23–33편 — ConRFT(45–90분 온라인)·CR-DAgger(교정 50–100편) 규모의 하한. 편 수가 부족하면 E-AT-R은 "라벨 파이프라인 실기 확인"으로 등록하고 성공률 판정은 하지 않는다(가를 수 없는 단계 빼기).
- **결정 준수 의존**: 실기에서 Astra `edit`은 §11 편향(청크·손끝 기준)으로 반영된다. 결정 토큰 경유 조종(E-SR1c ADOPT_C1)은 **시뮬 분기 데이터**로 얻은 결과라, 실데이터 전용 본 학습에서 같은 준수가 나오는지는 따로 확인해야 한다(8절).
