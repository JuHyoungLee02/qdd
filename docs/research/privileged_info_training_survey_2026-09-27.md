# 학습 때만 있는 참값(손 정보) 활용 조사 — 보조 헤드·교사-학생·드롭아웃·깊이로 재기, R/H/D 적용안, 격자·점 (2026-09-27)

## 자리

- 질문: 시뮬 L8-X에는 탁자 높이·물체 크기 같은 참값("손 정보")이 있지만 실제 환경에는 없다. 사용자 결정(user-log 154): **손 정보는 추론 입력으로 넣지 않는다.** 그러면 학습 때만 어떻게 쓰나?
- 우리 실측(E-STRIP8b 중간): 손 정보를 빼면 새 높이 오차 3.3 mm → 20.1 mm. E-PT: 점 + 깊이 → xyz(D 줄기)는 새 높이에서 3.5 mm.
- 줄기: R(RGB만) / H(깊이 선택) / D(깊이 필수, 점 + 깊이 → xyz). 줄기 정의·깊이 입력 방식은 `rgb_depth_hybrid_survey_2026-09-27.md`(이하 "하이브리드 조사")를 따른다. 겹치는 논문(Spatial Forcing, MolmoAct, QDepth-VLA, DepthVLM, FALCON, RoboRefer, SD-VLM)은 그 문서 2·3절을 인용만 한다.
- 규칙: 결정 근거는 2025-03 이후 + (주요 학회 또는 코드·결과 공개). 그 이전은 **[기초]** 로 표시하고 배경으로만 쓴다. 별 수 등 확인 못 한 수치는 적지 않았다.

## 0. 결론 요약

1. **문헌의 공통 원리: 특권 정보는 "입력"이 아니라 "목표·보상·교사"로 들어간다.** 학습 신호로만 쓰면 추론 때 없어도 된다. 방식은 네 가지다 — (a) 출력 쪽 보조 과제, (b) 교사-학생 증류, (c) 특권 입력 드롭아웃·커리큘럼, (d) 참값 대신 센서(깊이)에서 재기.
2. **가장 싸고 우리 틀에 맞는 것은 (a) 출력 쪽 보조 필드**다. 답의 앞부분에 `table_z`, `obj_h` 같은 값을 **모델이 영상에서 추정해 쓰게** 하고 참값으로 감독한다. 입력에는 없다. ECoT-Lite(CoRL 2025)는 중간 추론을 학습에만 쓰고 추론 때 빼도 이득 상당 부분이 남는다고 보고했다 → "드롭한 보조 필드" 팔을 함께 잰다.
3. **교사-학생(b)은 우리 경우 출력 증류로는 이득이 거의 없다.** 교사(손 정보 입력, 3.3 mm)의 출력은 이미 참값에 가까워서, 교사 출력을 목표로 삼는 것은 참값 라벨과 같다. 로봇 RL에서 교사-학생이 통하는 이유는 교사가 **학습하기 쉬운 행동**을 만들고 학생은 **관측 이력**으로 숨은 값을 추정하기 때문이다(legged 계열). 우리 학생에게 남는 것은 은닉 특징 정렬(비대칭 증류) 정도이고, 이것은 Spatial Forcing 계열(하이브리드 조사 2.2)과 같은 틀이다 → 2순위.
4. **"모방 격차"가 핵심 위험이다.** 학생 관측(RGB만)에서 특권 값이 원리적으로 안 보이면 어떤 학습법으로도 오차가 남는다[기초: Weihs 2021]. R의 20.1 mm 중 일부는 단안 척도 모호성 때문일 수 있다. D가 3.5 mm로 일반화한 것은 **(d) 센서에서 재기**가 이 격차를 없앤다는 우리 쪽 증거다.
5. **권장(3절)**: M1 출력 보조 필드(R·H), M2 깊이에서 재는 기하 필드 + 참값은 라벨 생성에만(H·D), M3 특권 입력 드롭아웃 커리큘럼(R, 비교 팔). 싼 8B 시험은 4절.
6. **격자·점(5절)**: **점만 찍는다(출력)**, 입력 영상에는 격자를 덧그리지 않는다. 최근 로봇 VLM(RoboRefer, RoboBrain 2.0, MolmoAct, Gemini Robotics-ER 1.5)은 덧그림 없이 정규화 좌표 점을 출력하고, Qwen3-VL도 0–1000 좌표를 기본 지원한다. 덧그림은 미세조정 없는 API 모델용 기법(SoM·PIVOT·MOKA, [기초])이다.

## 1. 네 갈래 정리

### 1.1 출력 쪽 보조 과제 (참값을 목표로)

| 연구 | 방식 | 추론 때 참값 | 신뢰도 |
|---|---|---|---|
| **ECoT-Lite** "Training Strategies for Efficient Embodied Reasoning" (2505.08243) | 중간 추론(물체 상자·그리퍼 위치 등, 참값·자동 라벨)을 학습에 쓰고, **추론 때 추론 문장을 빼는** 방식(reasoning dropout, 사전학습에만 추론 등)을 비교. 추론을 빼도 이득 상당 부분이 남음 → 이득이 "입력 정보"가 아니라 "표현 학습"에서 온다는 해석 | 불필요 | 높음: CoRL 2025 |
| RoboRefer (NeurIPS 2025) | SFT 뒤 강화미세조정에서 **중간 단계 참값(위치·거리 등)으로 과정 보상**(metric-sensitive process reward)을 준다. 참값은 보상에만 쓰이고 입력엔 없음 | 불필요 | 높음(하이브리드 조사 0절 인용) |
| Spatial Forcing / MolmoAct 깊이 토큰 / QDepth-VLA / DepthVLM | 깊이·3D 특징을 **출력 또는 정렬 목표**로만 | 불필요 | 하이브리드 조사 2.2 인용 |
| [기초] ECoT (CoRL 2024), LUPI (Vapnik 2009) | 중간 추론 감독 / 특권 정보로 학습 | — | 배경 |

우리 적용: 답 앞에 `table_z`, `obj_h`(필요 시 `obj_w`)를 **추정값**으로 쓰게 한다. 참값은 손실 목표로만 들어간다. 이 값을 추론 때 쓰는(CoT 유지) 경우와 빼는(드롭) 경우를 모두 잰다. 위험은 **오류 전파**다. 추정한 탁자 높이가 틀리면 xyz도 거기에 맞춰 틀린다. 그래서 보조 필드 오차와 z 오차의 상관을 함께 본다.

### 1.2 교사-학생·비대칭 증류

| 연구 | 방식 | 신뢰도 |
|---|---|---|
| **TWIST** (2505.02833) | 인간형 전신: 특권 정보(미래 동작 등)를 보는 RL 교사 → 실측 관측만 쓰는 학생을 RL+BC(DAgger류)로 증류 | 높음: CoRL 2025 |
| **ASAP** (2502.01143, 경계) | 인간형: 시뮬 특권 정보로 학습 후 실측 델타 행동 모델로 보정 | 높음: RSS 2025, 코드 공개 |
| HOVER (2410.21229, 경계·[기초]에 가까움) | 특권 정보 전문가 정책 → 다중 모드 학생 증류 | ICRA 2025, 코드 공개 |
| [기초] Lee 2020 (Science Robotics), RMA (RSS 2021), Miki 2022, 비대칭 actor-critic (Pinto 2018) | 교사는 지형·마찰 참값, 학생은 고유감각 이력으로 잠재값 추정 | 배경 |
| [기초] Weihs 2021 "Bridging the imitation gap" | 학생 관측에서 특권 정보를 복원할 수 없으면 모방만으로 실패 → 교사 신호와 자체 보상 혼합 | 배경 |

우리와 다른 점: 로봇 RL 교사는 **행동을 만드는 역할**(정답 행동이 원래 없음)이다. 우리는 eef 목표 xyz 참값이 이미 있으므로 교사 출력은 새 정보를 주지 않는다. 남는 선택지는 (i) 교사 은닉층에 학생 은닉층을 맞추는 비대칭 특징 증류(Spatial Forcing과 같은 틀, 교사만 VGGT 대신 "손 정보 교사"), (ii) 교사가 쓴 설명문(CoT)을 학생 목표로 쓰기. 둘 다 M1이 안 될 때의 2순위다.

### 1.3 특권 입력 드롭아웃·커리큘럼

| 연구 | 방식 | 신뢰도 |
|---|---|---|
| FALCON (ICLR 2026) | 깊이·카메라 자세를 베르누이로 넣고 빼기 | 하이브리드 조사 0절 인용 |
| ECoT-Lite (위) | 추론 문장 드롭아웃(입력이 아니라 출력 쪽이지만 같은 원리) | CoRL 2025 |
| [기초] Information Dropout / privileged-information dropout (Lambert 2018, CVPR), 모달리티 드롭아웃 | 특권 입력을 점점 가리기 | 배경 |

우리 적용: 손 정보를 **학습 입력에만** 넣고 확률을 1 → 0으로 줄인다(최종 구간은 0). 추론 입력에는 넣지 않으므로 user-log 154와 충돌하지 않는다. 단, 마지막 구간이 손 정보 없는 학습과 같아지므로 이득이 남는지는 실험으로만 알 수 있다 → 비교 팔로만 둔다.

### 1.4 참값 대신 센서에서 재기

- 하이브리드 조사의 결론과 같다: 깊이를 입력 갈래로 두고(H), 점 + 깊이 → xyz(D).
- 추가로, 탁자 높이·물체 높이 같은 **특권 값의 센서 판본**을 만들 수 있다. 깊이 역투영 점구름에서 평면 맞춤(RANSAC)으로 탁자 높이, 점 주변 깊이 분포로 물체 윗면 높이를 잰다. 이것은 손 정보가 아니라 **측정값**이므로 H·D 입력(글 한 줄)으로 넣어도 규칙 위반이 아니다. 단안 m 깊이(Depth Anything 3, 2511, 코드 공개; VGGT CVPR 2025)는 척도 오류가 있어 R에는 강화 단계 후보로만 둔다(하이브리드 조사 3.4와 같은 결론).
- 우리 증거: E-PT 3.5 mm. 손 정보 교사(3.3 mm)와 거의 같다 → **D에서는 특권 정보가 이미 센서로 대체됐다.**

## 2. 우리 수치로 본 해석

- 교사(손 정보 입력) 3.3 mm, D 3.5 mm, R(손 정보 없음) 20.1 mm. D ≈ 교사이므로 **특권 정보가 주는 것은 "척도·높이"이고, 깊이가 그것을 대신한다.**
- 그러므로 특권 정보 학습법의 주 대상은 **R과 H-off**다. D에서는 M2(라벨 생성·일관성)만 의미가 있다.
- R에서 20.1 mm 중 줄일 수 있는 부분(영상 단서: 원근·그림자·탁자 가장자리)과 줄일 수 없는 부분(단안 척도 모호성)을 가르는 것이 시험의 목적이다. M1 보조 필드의 `table_z` 추정 오차가 그 상한을 직접 보여 준다.

## 3. 권장 설계 (입력에는 넣지 않고 학습에만)

| 방법 | 내용 | 줄기 | 추론 때 |
|---|---|---|---|
| **M1 출력 보조 필드** | 답 = `table_z`, `obj_h` (추정) → 점 → xyz. 참값으로 감독. 학습 표본의 50 %는 보조 필드를 생략(필드 생략 = 손실 가림, 하이브리드 조사 5번과 같은 장치) | **R**(주), **H**(두 모드 공통) | 필드 있음/없음 둘 다 평가 |
| **M2 깊이로 재는 기하 필드 + 참값은 라벨에만** | H-on·D: 깊이 평면 맞춤으로 잰 `table_z_meas`를 입력 글로 넣고(측정값), 참값은 점 목표·높이 의도 라벨을 만드는 데만 사용. 학습 손실에 "추정 `table_z`와 측정값 차이"를 보조로 | **H-on, D** | 측정값만 사용 |
| **M3 특권 입력 커리큘럼** (비교 팔) | 손 정보를 학습 입력에 확률 p로, p를 1 → 0(마지막 40 % 구간 0) | **R** | 손 정보 없음 |

2순위(M1이 기대에 못 미칠 때): 손 정보 교사의 은닉층 → 학생 은닉층 코사인 정렬(비대칭 특징 증류). 코드 변경이 커서 싼 시험에서 뺐다.

## 4. 싼 8B 시험 설계 (설계만, 실행 안 함)

Qwen3-VL-8B LoRA, L8-X b1, 816걸음, E-STRIP8b와 같은 데이터·표본·시드·학습률로 R 줄기 네 팔을 짝 비교한다 — R0(손 정보 없음, E-STRIP8b 재사용), R-M1keep(보조 필드 학습, 추론 때 보조 필드 생성), R-M1drop(같은 체크포인트, 추론 때 보조 필드 생략 프롬프트), R-M3(입력 손 정보 커리큘럼 1 → 0). 기준선으로 교사(손 정보 입력, 3.3 mm)와 D(E-PT 3.5 mm) 값을 그대로 인용한다. 평가는 `/data/harvest/out/teach_l8d/data/eval`에서 본 높이/새 높이를 나눠 xyz 오차 중앙값·p90, z 오차 따로, 보조 필드 `table_z`·`obj_h` 추정 오차, 보조 오차와 z 오차의 상관을 잰다. 판정 규칙은 사전 고정한다: 새 높이 중앙값이 R0 대비 40 % 이상 줄고(≤ 12 mm) 본 높이가 1 mm 넘게 나빠지지 않으면 채택, 아니면 `table_z` 추정 오차가 z 오차와 같은 크기인지 보고(같으면 단안 한계 → R은 여기까지, H·D로 간다). 학습 팔은 두 개(M1, M3)뿐이고 M1keep/drop은 같은 체크포인트라 비용은 E-STRIP8b 팔 두 개 수준이며 0원이다. H-on에 M2를 붙이는 것은 하이브리드 조사 5절의 H 팔이 선 뒤 한 팔로 더한다.

## 5. 격자·점 표현

- **권장: 출력은 점(정규화 좌표), 입력 영상은 덧그림 없음. 격자는 하지 않는다.**
- 근거:
  - 최근 미세조정된 로봇 공간 VLM은 덧그림 없이 점을 낸다: RoboRefer(NeurIPS 2025), RoboBrain 2.0(2025-07), MolmoAct(ICRA 2026), Gemini Robotics-ER 1.5(2025-09). Qwen3-VL 자체도 0–1000 상대 좌표 점·상자 출력을 사전학습에서 익혔다 → 우리 LoRA는 그 형식을 재사용하는 것이 가장 싸다.
  - 덧그림(Set-of-Mark 2023, PIVOT 2024, MOKA RSS 2024, 모두 [기초])은 **미세조정 없는** API 모델의 좌표 약점을 메우는 기법이다. 미세조정 모델에서는 픽셀을 가리고, 시뮬·실물에서 똑같이 그려야 하는 부담이 생긴다.
  - SpatialVLA의 "적응 격자"는 **행동 공간 이산화**이지 영상 덧그림이 아니다(혼동 주의).
  - 점을 **입력에** 그리는 것은 이전 점·궤적을 넘길 때만 근거가 있다: Magma(CVPR 2025, 2502, 경계)의 Trace-of-Mark는 학습 목표(출력)로 쓰였다.
- 둘 다(격자 + 점)는 근거가 없다. 원하면 R 줄기에 "격자 덧그림" 한 팔을 더하는 것보다 M1이 먼저다.
