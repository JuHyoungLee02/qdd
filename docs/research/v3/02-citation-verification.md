# v3-02 핵심 인용의 원문 재검증

작성: 2026-09-24, v3 초안 조사. 대상: `docs/plan.md` v2와 `paper/main.tex`에 쓰인 핵심 인용 22편.

## 1. 조사 방법과 한계

- **WebSearch 0회.** 모두 원문과 1차 메타데이터로 확인했다.
  - arXiv API(`export.arxiv.org/api/query?id_list=...`): 첫 제출일(v1), 최신 판 날짜, 저자 comment(학회 표기)
  - arXiv HTML 본문 22편을 받아 해당 절과 표를 직접 읽었다. 수식 안의 수치는 MathML alttext로 복원했다.
  - Semantic Scholar batch API: 인용 수(2026-09-24 기준)
  - OpenReview 검색 API: venue와 venueid(채택/거절). 개별 note 조회는 챌린지로 막혀 decision 본문은 못 봤다. venueid로 판정했다.
  - ACL Anthology 이벤트 페이지(SiT-Bench), Crossref(LiPo 저널), GitHub API(스타), 프로젝트 페이지(AGNOSTOS)
- 한계
  - FLARE의 보충 자료(supplementary)는 읽지 못했다. 온라인 감시기의 호출 주기는 본문에 없어 확인하지 못했다.
  - Slow Brain Fast Planner와 2606.13355의 학회 채택 여부는 OpenReview와 arXiv comment에서 찾지 못했다. "미채택"이 아니라 "확인 못 함"이다.
  - PDF 전용 부록(A2C2 그림 수치 등)은 HTML에 있는 표만 봤다.

## 2. 검증 표

표기: 확인 수준 = ORIGINAL-CONFIRMED / CONFIRMED-MULTI / SINGLE-SOURCE / UNCONFIRMED / WRONG. "학습 없이"는 우리 구조(Jev 텍스트 전용 하위, Astra API 상위)에 무게 학습 없이 옮길 수 있는지를 말한다. 인용 수는 Semantic Scholar 값이다.

## 3. 새로 찾은 것과 모듈별 시사점

- **M9(FLARE)**: 우리 구조에 맞는 부분은 "MLLM이 실패를 ID(정책이 스스로 회복 가능)와 OOD(환경 상태가 깨짐)로 나누고, OOD일 때만 복구 스킬로 바꾼 뒤 확인하고 복귀하는" **조율 규칙**과 **분석 프롬프트**(Error Group, "먼저 조작해야 할 물체를 reset 대상으로")다. 재시도 능력은 FLARE에서 학습으로 얻은 것이다. 우리는 이를 "Jev 재시도 + 기존 스킬 재호출"로 대체한다. 원문 증거로 보면 Reset의 순기여는 +2~4%p로 작고, Oracle과의 차이(최대 +12%p)가 더 크다. 복구 성능의 병목은 "어떤 복구를 부를지 판단"보다 "복구 스킬 자체의 성공률"(두 번째 물체 20~24%)일 가능성이 있다. [제안] M9 평가에 "복구 스킬 성공률"을 따로 둔다.
- **M4**: 원문 기준으로 학습 없이 옮길 수 있는 것은 SmolVLA 스케줄러, RTC의 고정 + 재생성 개념, Slow Brain의 stale 선택 융합, LiPo다. VLASH와 A2C2는 **원 논문에서 학습이 필요하다.** 우리 쪽 "상태 굴리기"와 "기하 보정"은 발상만 빌린 새 설계라고 적어야 한다.
- **M8 시간 초과 호출**: Sentinel(CoRL 2024)이 VLM 프롬프트에 경과 시간과 시간 한도를 넣은 **선례**다. 효과 측정은 없으므로, 우리 비교 실험(주기 / 정한 순간 / 시간 초과)이 이 빈자리를 채우는 기여가 될 수 있다. 부재 주장은 이번에 검색하지 않았으니 주장하지 않는다.
- **평가(X-ICM 기준선)**: X-ICM은 테스트 때 **시뮬레이터 정답 물체 위치**를 텍스트로 받는다. 카메라만 쓰는 VLA와의 비교에 특권 정보가 섞여 있다. 우리가 AGNOSTOS를 쓰면 (a) 정답 위치 조건과 (b) 인식 앞단 조건을 둘 다 보고해야 공정하다.

## 4. 반대 증거와 위험

1. **"텍스트가 이미지보다 낫다" 근거가 약해졌다.** BALROG에서 최고 모델(Claude 3.5 Sonnet)과 Gemini-1.5-Pro는 이미지 추가로 나아졌다. SiT-Bench는 이미지와 비교하지 않았고, 오히려 시각 학습을 거친 백본이 텍스트 과제에서도 낫다. Jev 텍스트 입력의 정당화는 "Jev가 텍스트만 받는다"는 제약 자체로 하고, 성능 우위 주장에는 쓰지 않는 편이 안전하다.
2. **A2C2는 ICLR 2026에서 거절됐다.** v2가 "ICLR 2026, 단일 출처"로 적은 것은 틀렸다. 수치도 초록과 본문이 서로 다르다(LIBERO +7%p).
3. **FLARE 88/96%는 시뮬레이션 2개 작업, 50개 영상, 오프라인 분석** 수치다. 온라인 감시 정확도나 실제 로봇 수치가 아니다.
4. **FailBench는 LOW**다(신생 소규모 연구실, 인용 0). "접촉 판정은 센서로"라는 설계는 상식적 근거로 유지하되, FailBench를 핵심 근거로 쓰지 않는다. "추론량을 늘려도 성공 편향이 줄지 않는다"는 Astra effort 실험의 가설로만 쓴다.
5. **기간 밖 문헌**: BALROG(2024-11), GVL(2024-11), AHA(2024-10), Sentinel(2024-10)은 모두 1.5년 밖이다. 쓰려면 "기간 밖, 기초 문헌" 표시와 사용자 허용이 필요하다(plan §5의 [결정 필요] 4에 BALROG, GVL, Sentinel을 추가).
6. **LiPo 수치는 10회 시행**이라 통계적 의미가 약하다. "학습 없는 후처리의 실례"로만 인용한다.
