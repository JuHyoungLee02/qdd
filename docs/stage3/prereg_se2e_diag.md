## 2. D1 — 학습 부족(계산 한계)인가
- 설정: se2e_A_s0 `last/` 가중치(어댑터 + 헤드, 정규화 통계·어휘 포함)에서 시작, **옵티마이저·스케줄러 새로**. lr LoRA·헤드 모두 **5e-5 상수**(50스텝 선형 워밍업 뒤), 전체 train, 묶음 8, 시드 0, **+1,200스텝**, 300스텝마다 평가(0, 300, 600, 900, 1200).
- 전제 확인: D1 step 0 eval의 `dec`는 A의 step 4686 기록값과 같아야 한다(가중치 적재 확인). 같지 않고 차 > 1e-3이면 D1은 무효로 보고한다.
- **규칙**: step 1200 `dec` ≤ 0.95 × 0.6777731 = **0.64388** → "**학습 부족(계산 한계)**". 아니면 → "**이 lr에서 계산 한계 아님**".

## 3. D2 — 라벨이 외울 수는 있는가(과적합 시험)
- 설정: **기반 모델에서 새로**(S-E2E와 같은 설정, 정규화 통계·어휘는 S-E2E처럼 전체 train으로 맞춤). 학습은 train에서 **고정 무작위 1,000개**(`--train-subset 500`: RB1 500 + RB2 500, 키 정렬 뒤 시드 0 추출)만. 묶음 8, **1,000스텝**(≈ 8 에폭), lr 1e-4 상수(50스텝 워밍업 뒤), 시드 0. 200스텝마다(0, 200, …, 1000) (a) 그 1,000개 학습 부분집합, (b) 같은 검증 300개를 평가(같은 `evaluate()`, 드롭아웃 끔).
- **규칙**(step 1000 평가 기준):
  - 학습 부분집합 `dec_acc` ≥ **0.95** 이고 검증 `dec_acc` ≤ **0.75** → "**라벨은 학습 가능, 일반화 간극 → 데이터 늘리기가 듣는다(데이터 규모 레버)**".
  - 학습 부분집합 `dec_acc` < **0.85** → "**외워도 못 맞춤 → 라벨 모호성·잡음 또는 입력 한계**".
  - 그 밖(0.85 ≤ 학습 < 0.95, 또는 학습 ≥ 0.95 인데 검증 > 0.75) → "**불확정**".

## 4. D3 — 오답 해부
- 설정: se2e_A_s0 `last/`로 검증 300개의 항목별 예측 저장(`predict`: 옵션별 트라이 정규화 로그확률, argmax, 정답; 같은 `evaluate()` 경로라 집계 `dec`·`dec_acc`는 A step 4686 기록과 같아야 함). 행 파일(`/data/harvest/data/se2e/conv/<kind>.stageb.jsonl`)의 `ee_delta`(라벨을 만든 실제 변위 Δ, m)를 키(`<kind>_ep<seed>_k<k>`)로 붙인다.
- 보고: 질문별(dir_xy·dir_z·mag_coarse) 정확도·혼동행렬, 출처별(RB1·RB2) 정확도, 여백 구간별 정확도, 인접 프레임 라벨 일관성.
- **여백(margin) 정의 — 라벨 규칙에서 결과 보기 전에 고정**(데드밴드 D = 1 cm, MAG 경계 e ∈ {0.707, 1.414, 2.828, 5.657} cm):
  - dir_xy: m = min(| |Δx| − D |, | |Δy| − D |)
  - dir_z: m = | |Δz| − D |
  - mag_coarse: m_rel = min_e | ‖Δ‖ / e − 1 |
- **모호 밴드**: dir_xy·dir_z는 **m < 2 mm**(데드밴드의 ±20 %), mag_coarse는 **m_rel < 0.10**(경계의 ±10 %; 구간 폭이 로그 2배라 구간 안쪽 약 29 %). 이 밴드 안의 항목은 Δ가 ±2 mm(또는 ±10 %)만 달라도 라벨이 뒤집힌다.
- **규칙**: 오답 항목(세 질문 합산) 가운데 모호 밴드 안 비율 ≥ **50 %** → "**라벨 모호성 한계**". 아니면 → "라벨 모호성 한계 아님"(오답 대부분이 경계에서 먼 실제 움직임 차이).
- 해석 보조(판정 밖, 같이 보고): 전체 항목 중 밴드 안 비율(기저율)과 밴드 안·밖 오답률(농축비). 기저율이 40 % 이상이면 D3 판정은 "약함"으로 표시한다.
- **인접 프레임 라벨 일관성**(판정 밖, 참고): 같은 에피소드의 인접 프레임(k, k+1; 0.1 s 간격 — 입력 이미지가 거의 같음) 쌍에서 질문별 라벨이 다른 비율 p를 (i) val 전체 행, (ii) train 전체 행, (iii) 검증 300개와 그 k±1 이웃으로 잰다. 0.1 s 해상도로 구별 안 되는 입력이라면 정확도 상한 ≈ 1 − p/2(대략치)로 참고한다.

### 7.2 주 지표와 읽기 규칙
- 주 지표: step 2000의 **검증 dec_acc**(결정 정확도)와 **검증 dec**(결정 NLL).
- 적합: 네 점에 최소제곱으로 acc = a + b·log10(N).
- **규칙**:
  - b ≥ **0.05**(10배당) 그리고 acc(100 %) − acc(25 %) ≥ **0.03** → "**데이터 규모 레버 확인**".
  - acc(100 %) − acc(50 %) < **0.01** → "**포화**" 표시(확인과 함께 나올 수 있다: "확인, 단 50 %→100 % 포화").
  - 둘 다 아니면 → "**데이터 규모 레버 약함(같은 스텝 기준)**".
- 외삽(판정 밖, **외삽임을 표시**): b > 0이면 acc(100 %)보다 +0.05에 필요한 N* = 37,484 · 10^(0.05 / b).
- 참고(판정 밖): NLL에도 같은 로그 적합을 보고한다. 같은 스텝이라 작은 N은 여러 에폭(N = 1,000은 16 에폭)을, 100 %는 0.43 에폭을 본다 — 이 곡선은 "같은 계산에서 데이터 다양성"의 효과다.
