### 0.4 초안 대비 확정·변경(등록 때 정함, 결과 전)
1. **GPU**: 초안의 "메인 GPU 2·3" 대신 메인 배정 — 메인 파드 GPU 0 = Isaac(G-br 재생, 끝나면 비움), GPU 1 = 학습·평가. E-SR1b(x2 0·1, 메인 2·3)는 건드리지 않는다.
2. **권한의 단계 입력**: 초안은 "결정층 `phase` 보기"였으나, 우리 결정층 `phase` 질문은 labels_v2 `phase_choice`(continue·next·hold)라 접촉 단계를 담지 않는다 → 런타임이 expert에 이미 주는 **하위 단계 입력 `phase_id`**(`runtime.fused_model.chunk_raw`의 `phase`)를 쓴다(학습·평가·런타임 같은 값). 거리 = 보조 헤드 추정.
3. **분기 기준점**: 초안 "현재 관절에서" → **스냅샷의 첫 기록 목표**(`action_exec[0]`)에서 시작. 기록 목표에는 계획기의 중력 처짐 보상(`_gravity_offset`, 2 cm 수준)과 명령 선행이 들어 있어, 측정 관절에서 시작하면 첫 틱에 명령이 뒤로 튄다. FK(마지막) − FK(처음) = 강제 변위가 되어 E-SR0 변위 정의와 같다.
4. **관절 한계**: 시뮬 로봇의 기록 목표가 URDF 범위 밖일 수 있어(R2 관절 7 = 1.80 > 1.58) 기준점에 있는 관절은 그 자리에 머무를 수 있게 하고 더 밖으로는 못 가게 한다(시험). 사전 실행에서 이 처리 전 IK 탈락 202/240 → 뒤 34/960.

6. **분기 표본의 학습 배치**: C0 레시피는 배치 8 → 매 스텝 분기 8개(균등 복원 추출, numpy RNG(시드, 염) — torch 난수열과 독립), 분기의 문맥은 **기울기 없는** 공유 접두 전방(KI stop이라 expert 손실은 백본에 안 닿음), L_fm = 0.5·L_fm(실제 8) + 0.5·L_fm(분기 8); 결정·보조·검증 손실은 실제 표본만(C0와 같음). 정규화 통계·어휘는 실제 표본으로만(C0와 같음).
7. **분기 자격 = 특권 a = 1인 fit 분할(단계 B train) 스냅샷**, bottle_tray 제외(일반화 확인). 주 지표 A_xy_far는 **bottle_tray를 포함한** 먼 구간 전체(379)로 잰다(초안 문구 그대로: 과제별 값은 판정 밖 보고).
8. **G-br 측정**: 초안의 "스냅샷 상태 쓰기" 대신 **리셋부터 기록 행동 재생**(하드 리셋 빌드, 상태 쓰기는 2.3–7.8 mm 어긋남 P36), 추종 오차는 같은 스냅샷에서 기준점을 붙잡은 **정지 참조 재생**과의 차로(명령 선행·중력 처짐 상쇄), 끝에서 0.33 s 정착 뒤 잰다. 스냅샷 단위로 뽑아(한 스냅샷의 분기 전부) ≥ 200분기(dr 100 + standard 100).
9. **근접 비열등 N3**: 어휘에 §87 그리퍼 선택지가 아직 없음(R2 체크포인트 질문 5개) → `phase_id` close/open 그리퍼 적중(E-SR0 정의) 대용(초안대로).
10. **추가 보고(메인 지시)**: 그럴듯한 편집 준수(기록 청크 xy 변위를 ±30°·±45° 돌린 1–5 cm 편집 → 8방향 칸·크기 칸으로 결정, 청크 xy cos(편집) > 0.5)와 스트레스(±90°·180°) — 층별, 판정 밖.
11. **책상 침투 대용(ii)**: 반사실 `xy:<d>` 청크(라벨 방향 제외)의 최저 패드 높이 = 스냅샷 측정 손끝 z + 청크 FK z 최저 변화 − 27 mm < 2 mm인 쌍의 비율.
12. **지연(iv)**: `sr1c_eval --latency 50` — 평가 집합 앞 50스냅샷 × 4회(예열 3), 문맥 미리 계산, 청크 경로(`cond`(C2는 권한 추정 포함) + Euler 10) CUDA 동기, p95.
13. **C0 재사용 조건**: `/data/harvest/ckpt/ma2/c0/last`. 새 판 학습 인자는 C0 학습 기록(`logs/ma2/train_c0.out` config)과 **E-SR1c 옵션·이름 말고 전부 같아야** 한다(관문 cfg).
14. **대체 판 S**: 코드(`harvest/train/sr1c_resid.py`)는 C1·C2 모두 불채택(RUN_S)일 때만 작성하고, **실행 전에** 변경 기록으로 해시를 등록한다(설계·규칙은 여기서 고정, 2절·4절).
15. G2 시간 문턱: E-MA2 판 약 41분(C0 학습 루프 2,306 s)의 2배 = **판마다 4,920 s**(분기 전방 때문에 사전 실행에서 약 1.4배 예상).

## 4. 지표와 판정(고정, `tools/sr1c/sr1c_verdict.py`)
- 주 지표 **A_xy_far**: E-SR0 정의(쌍 (스냅샷, d), d ∈ 8방향 ≠ 라벨; |청크 xy| ≥ 0.1 mm 그리고 cos > 0.5)를 먼 구간 스냅샷에서.
- 근접 비열등(근접 층): **N1** 참 결정 청크 정규화 MSE 평균 ≤ C0 × 1.05; **N2** 참 청크 끝점 FK 오차 중앙값 ≤ C0 × 1.10; **N3** `phase_id` close/open 그리퍼 적중 ≥ C0 − 0.02; **N4** target·phase 질문 결정 정확도 ≥ C0 − 0.01; **N5** 참 결정 방향 적중(라벨 ≠ none) ≥ C0 − 0.02.
- 전 구간: **(i)** 참 결정 방향 적중 ≥ 0.90; **(ii)** 반사실 청크 책상 침투 대용 비율 ≤ C0 + 0.02; **(iii)** 결정 정확도(5질문, 명령 없음) ≥ C0 − 0.01; **(iv)** 청크 경로 p95 ≤ C0 + 10 ms.
- **판정**(CMP_EPS 1e-12):
  1. ADOPT(판) ⇔ A_xy_far ≥ 0.80 ∧ N1–N5 ∧ (i)–(iv). 등급: 먼 구간 A_z ≥ 0.80 ∧ ρ ≥ 0.5 → FULL, 아니면 XY(결합에서 수평만 결정 경유).
  2. 둘 다 ADOPT → A_xy_far(C2) − A_xy_far(C1) ≥ +0.03 그리고 짝 부트스트랩(10,000회) 2.5 % > 0이면 C2, 아니면 C1.
  3. 하나만 → 그 판. 4. 둘 다 아님 → **RUN_S**: S의 A_xy_far ≥ 0.99(구성 검사, 미달 = 구현 버그 → 멈춤), 채택 = N1–N5 + (ii) + (iv) + 먼 구간 참 청크 끝점 오차 중앙값 ≤ C0 × 1.15 → STRUCT, 아니면 NONE.
  - A_xy_far 통과·N 실패 = **근접 번짐**(불채택, 기록).
  - 경계: 어느 판이든 A_xy_far ∈ [0.77, 0.83] → 그 판 시드 1 학습·평가, 두 시드 지표 평균으로 1–3 다시.
- 판정 밖 보고: 층별 모든 지표(먼·근접·띠(비어 있음)·전 구간), 근접 A_xy(번짐 크기), 과제별 A_xy_far(bottle_tray = 분기 없는 과제), 강제 방향별·라벨 크기별, 추정 a = 1 대 < 1로 나눈 먼 구간 값, 편집 준수(±30·±45)·스트레스(±90·180), 우연·평균 코사인·A_z·ρ의 부트스트랩 95 % 구간, 학습 기록의 `fm_branch`.

## 5. 해석 한계
오프라인·청크 하나(0.5 s), 한 시드(경계 제외), 2,000스텝, 시뮬만. 분기는 관측을 새로 만들지 않아 "강제 방향으로 간 뒤의 관측"은 학습에 없다(CAST와 같은 한계 — 연속 반사실 추종은 폐루프 E-Couple에서). 평가 과제(강제 방향 0.5 s 이동)가 분기 학습 과제와 같은 형태라 "그 능력을 배웠는가"이며 새 명령 형식으로의 일반화가 아니다(bottle_tray 값으로 일부 확인). 분기 청크는 직선·등속이라 계획기 청크(가감속)와 모양이 다르다. 근접 능력은 오프라인 청크 지표로만 — 실제 파지 성공은 폐루프에서. 준수 지표는 URDF FK로 잰 목표 변위(E-SR0 정의)이고 URDF FK는 시뮬 말단과 약 1 cm·운동학적으로 다르다(G-fk) — 방향 판정(±60°)에는 작은 영향이지만, 실행된 움직임의 방향은 G-br(분기)와 폐루프에서만 직접 확인된다. 권한 경계(5/10 cm)는 가정이고 eval 분할에 띠 스냅샷이 없어 경계 근처 번짐은 이 실험이 직접 재지 못한다.

## 6. 합치기 규칙
- 6.1 E-SR1b가 0.8 이상으로 채택되면: C2를 빼고 C0·C1만(0절). E-SR1b 채택 판도 이 등록의 근접 비열등(N1–N5)으로 판정 밖 재평가.
- 6.2 E-SR1b가 CFG를 채택하면: 이 등록 채택 판을 E-SR1b 드롭아웃 p(a = 1 표본만)로 한 판 더 학습해 w(a) = 1 + (w* − 1)·a로 평가 — 판정 밖, 변경 기록 뒤.
- 6.3 S-E2E 확장(기구학 분기를 실물 프레임에)은 이 등록 밖.
