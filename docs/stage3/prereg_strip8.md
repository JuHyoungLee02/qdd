## 1. 요청 (필드별 제거, `harvest/teach_strip8/strip.py`)
v2 요청에서 다음 네 필드를 **필드 단위로** 뺀다. 나머지는 바이트 그대로다.

| 필드 | 무엇 (§97 인벤토리 번호) | 빼면 |

| `overlay` | 격자·낙하선 범례 (20, 22) — 둘 다 코드가 **아는 탁자 높이**에 그림 | 고리만 범례 + 고리만 머리 영상(`img1_head_ring.png`), '영상 밖' 안내문은 nd판 |

- **남기는 것**: 로봇 좌표계, 그리퍼 기하(패드 4.5 cm·몸통 2.5 cm·열림 10.7 cm·빈 닫힘 약 5.0 cm), 명령 설명, 카메라 자세, 판정 정의, TCP 고리, NOW(TCP·패드 간격·손목 카메라 자세), 측정 이력, 과제 문장, 물체 이름·역할, 성공 규칙.
  - 이것들은 §97 분류 R(로봇 자기 정보: URDF·관절 상태·camera_info·실행기 측정으로 코드가 만들 수 있음)과 K(과제·인터페이스)다. 그리퍼 기하는 지금 손으로 쓴 상수지만 URDF 값과 같은 로봇 자기 정보라 남긴다(§97 7–9행). 판정 정의(23·24, X)는 이번 범위 밖이라 남긴다.
- **낙하선 결정**: 낙하선은 TCP에서 **탁자까지** 내린 선이라 탁자 높이 없이는 끝점을 그릴 수 없다(FK + 보정만으로는 '아래 방향 선'만 가능). 그래서 최소 요청에서 격자와 함께 뺀다.
- **확인된 관계**: `strip(v2, {table, overlay})` = E-PT `nd-xyz@v1` 요청(바이트 동일, 시험 + G-id). 즉 사다리는 v2(L8) → nd-xyz(E-PT ND-1: 탁자·격자 뺌) → **최소**(+ 크기·요령 뺌)다.
- 최소 요청 판본 `strip8-min@v1`.

## 2. 데이터 (상태는 L8과 같게 — 새 수집 없음)
- 원천: E-PT 수집 `/data/harvest/out/teach_pt/collect`(L8과 같은 편·시드·행동 정책, 호출마다 v2 요청·nd 요청·v2 덧그림 영상·고리만 영상 저장; E-PT 관문 G1)과 그 행 파일 `/data/harvest/out/teach_pt/data/<split>_nd-xyz.jsonl`(L8 라벨·반복 가중·보조 QA 그대로). L8 수집 폴더(`/data/harvest/out/teach_l8`)에는 격자 없는 영상이 없어 E-PT 수집을 쓴다 — 같은 L8 편이다.
- 팔별 행(`harvest/teach_strip8/dataset.py`, 출력 `/data/harvest/out/strip8/data`): 조종 행의 요청 글·머리 영상만 바꾸고 라벨·보조 QA 행은 그대로다(보조 QA는 nd판: 고리만 영상, 격자 언급 없음).
  - **s-min**: 모든 조종 행 = 최소 요청 + 고리만 영상(TRAIN·DEV·OOD-H).
  - **s-drop**(학습만): 조종 행이 나올 때마다(반복 가중 행도 따로) 뽑기 — 확률 0.3으로 네 필드 모두 빼고, 아니면 필드마다 독립으로 확률 0.5로 뺀다(필드별 빠질 확률 0.65, 모두 빠짐 0.344, 모두 있음 0.044). 격자(`overlay`)가 남으면 v2 덧그림 영상, 빠지면 고리만 영상. 시드 0 고정.
  - **s-stale**(평가만, OOD-H): v2 요청에 **손으로 쓴 탁자 높이 0.850**(프롬프트 코드가 쓰던 값)을 넣은 것 — 탁자 줄·작업 상자 z를 0.850으로, 격자·낙하선을 0.850에 다시 그림(고리만 영상 위에 v2 덧그림 함수 `head_overlay`로; 고리는 위에 다시 그려져 참 높이면 저장 영상과 화소 동일), 영상 밖 안내문도 다시 정함. 현장에 사람이 적어 둔 높이가 탁자가 바뀐 뒤에도 그대로인 상황이다.
- **관문 G-id**: 모든 조종 행에서 `strip(v2, {table, overlay})` = 저장된 nd-xyz 요청(하나라도 다르면 빌드가 멈춤).
- **관문 G-stale**: OOD-H 조종 행을 그 행의 **참 높이**로 s-stale 재구성 → 글 바이트 동일·머리 영상 화소 동일 비율 각 ≥ 0.99(`tools/teach_strip8/check_stale.py`). 미달이면 s-stale 팔을 빼고 적는다.
- 행 수는 로더가 실제로 만든 수로 보고한다(P115). 예상: 조종 2,496 고유 → 반복 가중 뒤 4,025 + 보조 2,496 = 6,521(E-PT nd-xyz 빌드와 같음).

## 3. 학습
- L8·E-PT 레시피 그대로(`harvest.teach_l8.train`): Qwen3-VL-8B-Instruct, LoRA r 16·α 32·dropout 0.05, 언어 모델 q/k/v/o·gate/up/down, 비전 동결, AdamW lr 1e-4 코사인(warmup 20), 미세 배치 8 × 누적 2, bf16, seed 0.
- **같은 걸음 수·같은 표본 수**: `--max-steps 816`(= L8의 총 걸음, 13,056 표본), `--epochs 3`(E-PT와 같음). 팔 둘(s-min, s-drop), 각 약 1.4 GPU-h.
- 평가 모델 = 마지막 어댑터 병합(`teach_l8.merge`) 후 vLLM(`tools/teach_strip8/vllm.sh` = E-PT 설정), 탐욕 복호, max_tokens 2000.
- 학습 자체 검사: 첫 20걸음 손실 하강, 로더 행 수 = 파일 행 수.

## 5. 판정 (결과 전 고정)
### 5.1 최소 팔 고르기
- DEV 접근 xy 중앙이 작은 쪽(S-min, S-drop)을 **최선 최소 팔**로 한다. 차이 ≤ 1 mm면 S-min(더 단순). OOD-H 값은 고르는 데 쓰지 않는다.
### 5.2 주 판정 — 손으로 준 정보가 추론 때 필요한가
- **DEV 비열등**: 최선 최소 팔의 접근 xy 중앙 ≤ S-full + 5 mm **그리고** 유효 ≥ 0.95 **그리고** 그리퍼 행동 정확도 ≥ S-full − 0.05.
- **OOD-H 호출**(주 지표 = 접근 3D 오차, 스냅숏 짝, 두 높이 합동; 기준 = S-full 참 높이): 차의 95 % 구간 상한 < 0 → BETTER; 상한 < +5 mm → NONINFERIOR; 하한 > +5 mm → WORSE; 그 밖 → INCONCLUSIVE.
- **NOT_NEEDED**(추론 때 필요 없음): DEV 비열등 **그리고** OOD-H가 BETTER 또는 NONINFERIOR.
- **NEEDED**(필요함): DEV 비열등 실패 **또는** OOD-H WORSE.
- **UNCLEAR**: 그 밖(DEV는 비열등인데 OOD-H INCONCLUSIVE).
- 같은 규칙으로 최선 최소 팔 대 **S-stale**(손으로 쓴 0.850)도 OOD-H 호출을 낸다(기술 — 정보가 틀렸을 때의 비용).
### 5.3 L8의 의존도 (S-full→min)
- **DEPENDENT**: S-full→min의 DEV 접근 xy 중앙 > max(2 × S-full, S-full + 10 mm) **또는** 유효 < 0.95. 아니면 **ROBUST**. OOD-H 값은 같이 적는다(기술).
### 5.4 드롭아웃 효과 (S-drop 대 S-min, 기술)
- DEV 접근 xy·OOD-H 접근 3D의 짝 차와 구간을 적는다(S-min 기준, 5.2의 호출 규칙). 판정이 아니라 설명.
### 5.5 폐루프 (영상 필수, 방향만)
- 대상: 최선 최소 팔과 S-full. 조기 종료 20호출·60 s, 프롬프트 한도 40호출·180 s(L8·E-PT와 같음).
  - DEV 4판(standard·dr × s0·s1): 최선 최소 팔은 새로 돌린다. S-full은 L8 2단계 결과(4/4, `/data/harvest/out/teach_l8/closed/ft`)를 쓰고, GPU가 남으면 같은 러너로 다시 돌린다.
  - OOD-H 4판(s0·s1 × 0.82·0.88): 둘 다. S-full은 E-PT 5.3의 L8-xyz OOD-H 4판이 있으면 쓰고, 없으면 직접 돌린다.
- 러너 `harvest.teach_strip8.run_closed`(최소 요청 = E-PT nd-xyz 편에서 요청 글만 최소로, v2 = astra-solo 편 그대로). 편 판정은 L8 5.2 규칙(WORKS / PERCEPTION / DOWNSTREAM).
- 영상: 편마다 연속 mp4 + 모델 시점 mp4, `/data/harvest/videos/strip8/<세트>/<팔>/` + 색인(`tools/astra_solo/make_videos.py`, `/data/harvest/venv_train/bin/python`).
- **관문 G-wire**: 최소 요청 인터페이스로 참값 모델(NdTruth) DEV standard s0 1판 성공(배선 확인, 참값은 요청 글을 읽지 않는다).

## 7. 이 시험이 말하는 것과 못 하는 것
