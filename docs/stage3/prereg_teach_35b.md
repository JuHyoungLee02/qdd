### 3.1 한계 찾기 지표 (상위 단독, 폐루프 — 모든 판에서 같이 기록)
- **편당 벽시계**(기다림 포함): 편 시작 → 성공(또는 끝)까지 실제 초 = 상위 지연 합 + 실행기 움직임 + 대기. 움직임 시간(시뮬 초)과 상위 대기 합을 나눠 적는다. 비교: Astra 단독(파일럿 성공까지 움직임 12.7–22.7 s, 편 1–3.5분), 8-L8(편 약 33 s).
- **호출 수**: 편당 상위 호출 수(성공 편·실패 편 따로), 무효 답·재질문 수.
- **교란 아래 행동**(0.2 교란 주입 선행): (i) 물체 옮김 — 편 도중 대상이 3–8 cm 순간 이동했을 때 다음 몇 호출 안에 새 위치로 목표를 고치는가(고친 호출 수, 고친 뒤 접근 xy 오차), 성공; (ii) 미끄러짐 — 운반 중 그리퍼가 열려 물체를 놓쳤을 때 알아채고(`execution_status` failed·재파지) 다시 잡는가, 성공. 판마다 n이 작으므로 방향만.
- **접촉 정밀도**: 첫 닫기 때 손끝 xy − 대상 중심(mm), 닫기 높이 − 잡기 높이 참값(mm), 빈손 닫힘 횟수, 놓기 때 물체 xy − 놓을 곳 중심(mm)·똑바름.
- 이 넷은 판정 규칙(4절)에 넣지 않는 **기술 지표**다 — 한계를 찾아 다음 설계(VLA 복귀 여부 포함)를 정하는 근거로 결과에 표로 적는다.

## 4. 판정 (결과 전 고정 — 등록 때 확정)
- **크기 효과(OOD-H, 주)**: 35-L8 접근 3D 중앙 ≤ 0.8 × 8-L8 **그리고** 스냅숏 짝 부트스트랩(10,000회, 시드 0) 차의 95 % 구간 상한 < 0 → **BIGGER_HELPS**; 구간이 0 포함 → **SAME**; 하한 > 0 → **WORSE**. DEV는 둘 다 ≤ 10 mm면 '가르지 못함'.
- **H-L**:
  - (a) 지연: 학습된 35B의 DEV 한 요청씩 p50 ≤ 2.0 s **그리고** ≤ Astra/3 (solo: Astra low p50 6.8 s → 2.27 s; 결합: E-ACC v2 low p50 5.38 s → 1.79 s. 결합 팔은 1.79 s가 묶는 기준).
  - (b) 성공: DEV 짝 시드 성공 수 ≥ Astra 단독 − 3/40.
  - (c) 정밀: 접근 목표 xy 편 중앙의 중앙 ≤ 14 mm.
  - 셋 다 → **H-L PASS**(이 과제·시뮬 한정); 하나라도 미달 → 어느 것인지 적고 **FAIL**.
- 결정: BIGGER_HELPS 또는 8-L8이 OOD-H에서 무너지는데 35B가 버티면 → 상위 단독 본학습(다양화 혼합 포함)을 35B로 한다(최종 상위 = 35B는 이미 §96 보충 2의 결정이므로 이 판정은 '크기 값'의 근거). SAME이면 → 설계 반복은 8B로, 최종 학습만 35B로. 3.1의 한계(벽시계·교란·접촉)가 상위 단독으로 풀리지 않으면 → VLA 등 다른 층 복귀를 새 등록으로 제안한다.

## 6. 이 시험이 말하는 것과 못 하는 것
- 말하는 것: 같은 데이터에서 35B-A3B가 8B보다 본 적 없는 높이에 더 일반화하는가, 그리고 학습된 35B가 H-L의 속도·성공·정밀 기준을 이 시뮬 과제에서 넘는가.
- 못 하는 것: 실물 성능, Astra 라벨 증류 효과(L-A — 유료, 별도 등록), 결합 형식의 폐루프 가치(35-C는 결합 러너 폐루프가 따로 필요 — 이 등록은 오프라인 결합 채점까지).
