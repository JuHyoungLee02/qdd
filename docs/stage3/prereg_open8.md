## 4. 평가 (E-PT 채점기)

### 4.1 세트
- DEV 약 305 스냅숏.
- OOD-H 약 150 스냅숏(E-PT와 같은 파일).
- 공개 보류분(held-out open): 스트림마다 학습에 안 쓴 편에서 200행.
  - RB2: 보류 편 20 %.
  - MolmoBot: 보류 꾸러미.
  - MolmoAct: 다른 조각.

### 4.2 지표
- 유효 JSON률.
- 그리퍼 행동 정확도.
- 접근 xy 오차, **접근 3D 오차(주)**.
- **좌표 누수율**: `fmt.leak_flags`. 우리 요청의 답에 `frame`·`point`·`trace` 등 공개 키가 나오거나, 우리 작업 상자 ± 5 cm 밖의 목표가 나오면 누수다.
- 공개 보류분 정확도: 점 픽셀 오차, C′ 목표 오차(그 로봇 기저, mm).

## 5. 판정 (결과 전 고정)

- **관문(모든 팔)**: 누수 0건, 유효 JSON ≥ 0.95. 못 넘으면 그 팔은 판정하지 않고 형식을 고친다.
- **O-A 전이**: DEV 접근 xy 중앙 ≤ 0.5 × O-0(= 62.8 mm) → **TRANSFER**. ≤ 0.8 × O-0 → **PARTIAL**. 그 밖은 **NONE**. 폐루프 DEV 4판(standard·dr × s0·s1)은 기술만 하고 영상을 남긴다.
- **O-B 일반화**: E-PT 5.2 규칙을 그대로 쓴다. 주 지표는 OOD-H 접근 3D 오차 중앙이다.
  - 팔 ≤ 0.8 × L8이고, 스냅숏 짝 부트스트랩(10,000회, 시드 0) 95 % 구간 상한 < 0 → **BETTER**.
  - 구간이 0을 포함 → **SAME**. 하한 > 0 → **WORSE**.
  - DEV 비열등: ≤ L8 + 5 mm.

## 6. 결정 규칙
- **O-A TRANSFER 또는 PARTIAL**: 공개 데이터가 형식·자기 정보 읽기를 가르친다는 근거로 본다. 35B 혼합의 공개 몫을 유지·확대한다(교차 기체 문서 3.2).
- **O-A NONE**: 공개 데이터만으로는 우리 요청을 못 푼다. 공개 데이터는 보조(O-B) 역할로만 쓴다.
- **O-B BETTER**: E-XEMB8 E팔(자체 + 공개)의 출발 구성으로 쓴다. **SAME**: 필수 원칙(user-log 116)대로 유지하고 OOD-O·D에서 다시 잰다. **WORSE/누수**: 해당 스트림을 고친다.
