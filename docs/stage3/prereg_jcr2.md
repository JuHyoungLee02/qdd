  - 원문 요지: "JCR은 외란이 있어야 의미가 있는 설계 방식이라, 물체가 옆으로 치워진다든지 넘어져 있다든지 하는 상황을 의도적으로 만들어 JCR이 어떻게 반응하게 할지, 그런 교란·실패를 상정한 데이터가 많을수록 JCR이 더 의미 있는 결론을 낼 것."

- JCR1(`prereg_jcr1.md`)과의 관계: JCR1 학습·스윕은 그대로 둔다. d2는 JCR1 판정 뒤 **JCR1-0 + d2 합본을 처음부터 다시 학습**하는 2판의 데이터다(교정 데이터만으로 이어 학습하지 않음, 변경 1).

## 1. 교란 분류 (의도적으로 만든다; 시드 재현)

**발생 시점**: approach 접근 중 / pregrasp 잡기 직전(손끝–물체 5 cm 안) / carry 운반 중 / place 놓기 직전.

**크기**: S(작음) / M(중간) / L(큼). 수치는 아래 표.

| 코드 | 교란 | 시점 | 크기 S / M / L | 만드는 법 (특권 쓰기) |
|---|---|---|---|---|
| D1 | 대상 물체 옆으로 밀림 | approach, pregrasp | 1–2 / 2–4 / 4–8 cm | 자세 한 번 쓰기, 수평 무작위 방향 |
| D2 | 대상 물체 넘어짐 | approach, pregrasp | 기울기 30° / 60° / 90°(옆으로 누움) | 자세 쓰기(축 무작위) + 안착 0.5 s |
| D3 | 잡은 물체 미끄러짐 / 떨어짐 | carry | 그리퍼 폭 +3 mm 0.2 s (S) / +6 mm 0.3 s (M) / +12 mm 0.4 s (L, 대개 떨어짐) | 그리퍼 명령에 순간 열림 더하기 |
| D4 | 예상 밖 접촉 | approach, carry | 장애물 경로 위 / 옆 2 cm / 옆 5 cm | 방해 물체 등장(P2식, 경로까지의 거리로 크기) |
| D5 | 놓을 자리 막힘 | place | 쟁반 위 작은 물체(가장자리 / 가운데 / 쟁반 이동 3 cm) | 물체 등장 또는 쟁반 자세 쓰기 |
| D6 | 위치·깊이 잡음 | 모든 호출 | 깊이 잡음 zed_mini × 0.5 / 1 / 2, 점 픽셀 잡음 σ 2 / 4 / 8 px | 어댑터 입력(머리 깊이)에 잡음 |
| D7 | 상위 명령 지연 | 모든 명령 | 0.5 / 1.0 / 1.5 s | 답 적용을 늦춤(E-DEP1 러너 방식) |

- 한 편에 교란을 1–2개(교란 편) 또는 0개(정상 편) 넣는다. 종류·시점·크기는 시드로 정한다.
- P3·P4(TEST 보류) 코드는 쓰지 않는다.

## 2. JCR 반응 규칙 (권한 원칙: JCR은 새 목표를 고르지 않는다)

| 상황 (특권 판정, 라벨용) | JCR 정답 행동 | 이상 신호 | 상위 다시 부르기 | 근거 / 상태 |
|---|---|---|---|---|
| 작은 밀림(D1-S, 마스크로 보이는 범위 ≤ 3 cm) | 어댑터가 마스크 추적으로 목적지를 옮기고, JCR은 계속 따라간다(참값 = 옮겨진 참 자세, 끌림 규칙 안) | target_moved 없음(≤ 2 cm) 또는 약 | 안 부름 | 마스크 게이팅 2507.10899, SAM2 추적(기초). 경계 2 cm는 **가설** |
| 큰 밀림(D1-M/L) | 안전 정지 → 2 cm 위로 물러남, 매끄럽게(≤ 0.04 rad, 가속 한도) | target_moved | 부름(어댑터 보고 문장) | IDA(필요할 때만 개입, 기초), PACS 경로 유지 제동 2511.06385. 물러남 2 cm는 **가설** |
| 넘어짐(D2) | 안전 정지 → 물러남. 다시 잡는 자세는 상위가 정한다 | unrecoverable(이 명령 안에서) | 부름 | 권한 원칙(NOW §1-0b) |
| 떨어뜨림(D3-L, 패드 빈 채 닫힘) | 정지 → 물러남 | dropped | 부름 | 변경 1(복구 불가 = 이상 + 멈춤) |
| 미끄러짐 초기(D3-S/M, 패드 폭 증가 + effort 감소) | 그립 유지·다시 닫기(허용된 close 방향 안), 운반 속도 50 % | slip(새 칸) | 놓치면 부름 | effort 기반 쥠 술어 T1(BA ≥ 0.99, 자체 근거). 다시 닫기는 **가설** |
| 예상 밖 접촉(D4) | 최소 후퇴(접촉 반대 방향 1–2 cm) 후 정지 | unexpected_contact | 부름 | CBF/PACS식 안전 필터(최근). 후퇴 거리는 **가설** |
| 놓을 자리 막힘(D5) | 놓기 높이 위에서 정지(놓지 않음) | place_blocked(새 칸) | 부름 | 권한 원칙(놓을 곳은 상위가 정함) |
| 잡음(D6) | 끌림 규칙 그대로(규칙 B/C가 잡음을 흡수할지가 질문) | 큰 불일치면 cmd_mismatch | — | 변경 3 스윕 |
| 지연(D7) | 받은 명령까지 따라감(오래된 명령) + 어댑터 이어가기 | — | — | E-DEP1(지연 = 측정값) |

**라벨 규칙 (변경 1을 이어받음)**
- 실패 편에서 실행된 행동은 BC 라벨로 쓰지 않는다. 방문 상태에 참값 교정 행동을 붙인다(CR-DAgger 2506.16685, RaC 2509.07953).
- 교란 뒤 3 s 안에 복구하지 못한 꼬리는 제외한다(RaC).
- 이상 신호는 별도 이진 헤드로 두고, 임계는 보류 세트 conformal로 오탐 5 %에 고정한다(FAIL-Detect 2503.08558, FIPER).
- 새 이상 칸 2개를 추가한다: slip, place_blocked. 헤드 출력이 6 → 8개가 된다.
- 반응 행동(정지·물러남·다시 닫기)은 참값 함수가 특권 상태로 만든다. 학습된 정책 라벨은 없다.
- 복구 불가 판정은 반사실 롤아웃 N = 3(hard reset 재생 분기)이다. 변경 0-2에서 2판 부품으로 미뤄 둔 것이고, d2에서 넣는다.

## 3. 데이터 구성 d2

**양과 비율**
- 3,000편: SoloWorld mug_tray(1판과 같은 세계) standard·dr 각 1,500편. 시드는 R2_TRAIN 30000–31499 / 40000–41499다(d1과 겹치지 않음).
- 교란 편 비율: d1 50 % → **d2 70 %**. 교란 편 안에서 D1·D2·D3·D4·D5 각 ~16 %, D6·D7은 다른 교란에 겹쳐서 40 %.
- 합본 학습(JCR1-0 d1 1,916편 + d2 3,000편)의 정상 편 비율은 약 41 %다.
  - **변경 1의 '정상 ≥ 50 %' 규칙을 d2 판에서 바꾼다.** 근거는 사용자 요청과 DART식 커리큘럼(교란을 성공률에 따라 키움)이다.
  - 대신 정상 성능 비열등을 **관문으로 지킨다(아래 D0-2와 §4 비열등)**.
- 크기 커리큘럼(DART 1703.09327): d2 앞 1,000편은 S·M만, 뒤 2,000편은 S·M·L이다. 앞 1,000편의 참값 실행기 성공률이 0.8 미만이면 L을 줄인다(변경으로 기록).
- 실패 편: 참값 실행기가 복구하지 못한 편도 상태를 재라벨해서 쓴다. 꼬리 규칙은 그대로다.

**관문 D0-2 (생성 뒤, 학습 전)**
- D0 항목(한도·G-br·접촉 검수)을 그대로 적용한다. 선택 도구 `select_data.py`도 그대로 쓴다.
- 교란별 라벨 검수: 종류마다 무작위 10틱을 프레임으로 본다. 반응 라벨(정지·물러남·다시 닫기·이상 칸)이 영상과 맞아야 한다(종류당 오류 ≤ 1).

## 4. 평가 세트 (결합 계획 P1에 추가)

**세계·명령**
- SoloWorld mug_tray DEV 0–19 × standard·dr = 40편이다.
- 상위는 본 35B 최적 체크포인트(E-DEP1과 같은 d-min 러너, S0 배치)다. 참값 명령 조건과 상위 조건을 둘 다 돈다.

**조건 (같은 시드 짝)**
- C0 교란 없음.
- C1 교란 있음: 평가용 고정 시드, 교란 종류마다 같은 비율, S·M·L 고르게.

**팔**

| 팔 | 구성 |
|---|---|
| N0 'JCR 없음' | 상위 + 어댑터 + IK 스크립트 실행기(TruthExec 규칙 S) + 규칙 그리퍼(도착하면 의도대로 닫기·열기, 이상 판단 없음) |
| J1 | 상위 + 어댑터 + JCR(2판, 채택 규칙 A 또는 B/C) |
| (참고) OX | 참값 명령 + 스크립트 = 상한 |

**지표**

| 지표 | 정의 |
|---|---|
| 성공 | 과제 자체 판정 |
| 복구율 | 교란 편 중 교란 뒤 성공한 비율 |
| 이상 신호 정확도 | 교란 시점 기준 ±1 s 창 안의 신호를 정탐으로 본다. 오경보율(교란 없는 구간의 신호 / 분)과 놓침률 |
| 상위 재호출 수 | 편당 호출 수, 교란 편과 정상 편을 나눔 |
| 그 밖 | 명령 없는 시간, 관절 걸음 위반 0 |

**합격 조건 (짝 부트스트랩 10,000)**
1. C0(교란 없음): 성공 J1 − N0의 95 % 하한 ≥ −5 %p(비열등).
2. C1(교란 있음): 성공 J1 − N0의 95 % 하한 > 0이고 차 ≥ +10 %p(우월).
3. 이상 신호: 놓침률 ≤ 20 %, 오경보 ≤ 0.5회/분(보고 기준선, FAIL-Detect식 conformal 임계).
4. 상위 재호출: J1이 N0보다 많아도 되지만, 교란 편당 +3회를 넘으면 '상위에 짐을 넘김'으로 적는다.

**판정**
- 1·2 모두 만족하면 `JCR_VALUE`로 둔다. 핵심 가설(외란에서의 JCR 가치)의 근거다.
- 1만 만족하면 `JCR_NEUTRAL`, 1을 못 넘으면 `JCR_HARMS`다.

## 5. 렌더 계획 (카드는 메인이 사용자 확인 뒤)

d1 실측: x2 GPU1 한 장, 레인 4개, 2 카메라·결정 시점 프레임, 60 s 상한, 361–441편/h.

| 일 | 편 수 | 카드 | 예상 시간 |
|---|---|---|---|
| d2 생성 | 3,000편 (교란 처리로 편당 약 15 % 더 걸린다고 가정) | 렌더 1장(x2 GPU1 또는 7a2a 0·1·3 중 1장) | 약 8–9 h |

## 6. 만들 부품 (렌더 전, 카드 없이)

1. `harvest/jcr/disturb.py` d2 판: D1–D7 계획, 크기 S/M/L, 시점, 커리큘럼 인자.
