- 적재 = `stageb_train.load_backbone`(bf16) + `stageb_model.load_heads` + `aux_model` + `temporal_model`(E-SR0와 같음). 특징은 decide 한 번의 부산물(추가 순전파 0).
- **새로움 점수**: 참조 집합의 평균으로 중심화한 뒤 단위 길이(cl2n), 질의와 참조 사이 코사인 거리(1 − cos)의 **가장 가까운 k = 10개 평균**. 참조 = 기억 집합(시험마다 §3의 부분).
- **모델 오류(평가 분할만)**: 질문마다 보기 로그확률 argmax(예측 결정)가 라벨 정답 목록(`target`)에 없으면 틀림; **결정 오류** = 5개 중 하나라도 틀림. **청크 오차** = 예측 결정을 조건으로 준 expert 청크(Euler 10, 흐름 잡음 시드 `0 × 1,000,003 + 순번`; 순번 = E-MA2 평가 집합 1,200개는 그 목록의 위치(E-SR0·ma2eval과 같은 번호 — G1이 같은 잡음으로 비교), 나머지 6,108개는 1,200 + 정렬 순서 위치)의 기록 행동 대비 정규화 MSE(유효 스텝, E-SR0 `pred`와 같은 식). **큰 오류(주 목표)** = 결정 오류 **또는** 청크 MSE ≥ 평가 분할 청크 MSE의 90 분위. 확신도 기준선(판정 밖) = −(질문별 top-1 − top-2 로그확률의 최솟값).

## 3. 집합
- R2 결정 스냅샷 = `/data/harvest/data/ma2/view/<variant>/<task>/P{0,1,2}` 18폴더(`stageb_data.load_for_training("r2")`, 151,870, `r2_ma2.sample_id`로 id). split `train` = fit, `val` = eval(시드 % 20 == 0).
- **fit 장면 시드 분할**: `sha256("nov0part@v1|<seed>")` 앞 8자리 / 2³² < 0.15 → 보정(cal), 나머지 → 기억(mem). 같은 시드는 변형·과제가 달라도 같은 부분(서로소 보장).
- **기억 집합** = (variant, task) 6칸마다 기억 시드 스냅샷에서 2,500개(시드 0 무작위, 정렬 id에서) = 15,000. **보정 집합** = 칸마다 보정 시드에서 500개 = 3,000. **평가** = eval 분할 전체 7,308. **S-E2E** = `se2e_c1/conv` 검증 분할 전체(1,799, 움직임 줄 없음 — C0 입력 형식), 실물 공개 데이터(내부용, §63 (6)).
- **시험**(참조 / 분포 안 / 이동):
  - `shift_dr`: 기억 standard / 평가 standard / 평가 dr. 보정 standard 점수의 95 분위 τ에서 두 쪽 경보율도.
  - `shift_task`: 과제 t마다 기억(t 제외) / 평가(t 제외) / 평가 t; 세 과제 평균.
  - `shift_real`(G5 온전성): 기억 전체 / 평가 전체 / S-E2E.
  - `err`: 기억 전체 / 평가 전체의 점수로 큰 오류·결정 오류·청크 큰 오차 AUROC, 청크 MSE와 Spearman.

## 5. 지표와 판정 규칙(고정, `tools/nov0/nov0_verdict.py`, 비교는 CMP_EPS 1e-12)
- **AUROC**: Mann–Whitney(동점 1/2). 95 % 구간 = 편 군집 부트스트랩(주 특징 10,000회, 보조 2,000회, 시드 0; 이동 시험은 분포 안 편과 이동 편을 따로 뽑음).
- **고정 문턱의 호출률 대 잡기율**: 보정 집합 점수(기억 전체 참조)의 분위 q ∈ {0.5, 0.7, 0.8, 0.9, 0.95}를 τ로, 평가에서 점수 > τ 비율(호출률)과 큰 오류·결정 오류·청크 큰 오차 중 걸린 비율(잡기율). `fa95` = q 0.95의 평가 호출률(분포 안 거짓 경보율).
- **90 % 재현율 작동점**: 평가 큰 오류의 90 %가 점수 ≥ τ90이 되는 가장 큰 τ90에서 호출률, **호출 감소 = 1 − 호출률**. 교차 맞춤: 편 id 해시(`nov0xfit@v1`)로 두 반쪽, 한쪽 τ90을 다른 쪽에 적용한 재현율·호출률의 평균.
- **지연**(`tools/nov0/nov0_latency.py`): 기억 15,000 × 2,560(float32) 참조, 질의 하나씩 1,000회(예열 50) — 중심화·정규화·유사도·top-10·평균. GPU(H200 GPU 2, 매 질의 동기화)와 CPU(numpy) p50·p95. decide FULL p95 약 96 ms(E-MA2 실측) 대비.
- **판정(주 특징 `dec`, cl2n, k 10)**:
  - **R1 게이트**: 큰 오류 AUROC **≥ 0.75** 그리고 90 % 재현율에서 호출 감소 **≥ 0.30** 그리고 교차 맞춤 재현율 **≥ 0.85** 그리고 GPU 점수 p95 **≤ 5 ms**.
  - **R2 새 환경 채널**: dr 이동 AUROC **≥ 0.80** 그리고 과제 빼기 평균 AUROC **≥ 0.80** 그리고 `fa95` **≤ 0.07**.
  - **G5**: 실물 대 시뮬 AUROC **≥ 0.90**이 아니면 `HOLD_G5`(판정 보류, 파이프라인 확인 → 8절 기록).
  - 판정 = **GATE+NOV**(R1·R2) → 결합 흐름에 새로움 게이트(τ는 보정 분위로 정해 E-Couple에서 폐루프 확인) + T_nov 채널; **GATE**(R1만) → 게이트만; **NOV**(R2만) → T_nov AND 채널 후보만, 흐름 호출은 그대로; **NONE** → 둘 다 안 함.
- **판정 밖 보고**: 보조 특징 세 개의 같은 표, 확신도 기준선(오류 AUROC·작동점), 과제별·변형별 값, dr 이동의 τ95 경보율, 질문별 오류율, 청크 MSE Spearman, 호출 감소를 원으로 환산(흐름 50원/회·로봇 1분당 350–500원 기준).
- 입력 검사(스크립트): 집합마다 id 중복 없음·메타와 특징 id 순서 같음·특징 유한·평가 7,308개·세 부분 시드 서로소·평가 MSE 유한. 결과 뒤 고치지 않는다.
- **해석 한계**: 오프라인 스냅샷(폐루프 아님), 계획기 시연 분포, 체크포인트 하나(2,000스텝), 큰 오류 정의의 청크 부분은 평가 분할 안 분위(상대 기준), dr은 C0가 학습한 변형이라 `shift_dr`은 "참조에 없는 외관 변화를 특징이 드러내는가"만 잰다(모델에게 새로운 환경은 아님), 과제 빼기는 문맥 문장(과제 이름)을 LLM 특징이 그대로 담아 쉽게 갈릴 수 있다.
