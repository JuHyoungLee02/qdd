용기는 **kinematic 몸체 + 삼각형 메시 충돌체**로 둔다(볼록 껍질이면 안쪽이 메워진다). 편 동안 움직이지 않는 목적지다. 바구니를 밀어 옮기는 일은 없다고 가정하고, 이 가정은 실물과 다른 점으로 적어 둔다. 안쪽은 메시에서 구한다.

- 림: 15° 부채꼴마다 바깥 벽 최고점을 구해 중앙값을 쓴다. 손잡이 고리는 무시된다.
- 입구 상자: 림 바로 아래 띠에서 가장 가까운 벽까지.
- 관문: 물체를 입구 3 cm 위에서 하나씩 떨어뜨려 안에 머무는지 본다(용기마다 8개, ≥ 75 %). 안에 머문 물체는 그 용기의 "fits" 목록에 들어간다.

## 과제 (쉬운 것부터)

### 1. 바구니(와 담는 기물 전체)에 옮기기 `bk__<물체>__<바구니>` / L8D `ov_into__<물체>__<용기>` — 가장 쉽다
- 목적지: 관문 통과 into 기물 32개(바구니·그릇·상자·싱크·쓰레기통·냄비·컵) + onto 3개(도마·접시·THOR Sink_1 윗면). 판정은 대상 중심이 inner_box 안, 밑면이 inner_floor ±1 cm(onto) 또는 inner_floor−1 cm~rim(into).
- 대상은 관문을 통과한 **모든 실물 물체**다(사용자 정정). objects_real의 gso_·thor_·gsor_ 물체 관문 통과분, 잡을 수 있는 크기의 안정 상품(products, 잡는 폭 2.5–8.5 cm), 과일이 포함된다. 과일에 한정하지 않는다. 바구니별로는 "fits"에 있는 물체만 쓴다.
- 참값: 기존 들어 옮기기 계획(`xlabels.plan`)을 그대로 쓴다. 놓는 점만 바꾼다.
  - 놓는 점 = 입구 상자 중심, 높이 = 림 + 3 cm + (TCP − 물체 바닥).
  - 림 위에서 놓아 떨어뜨린다. 지금 통(bin) 과제와 같은 방식이다(`place_top` = 림).
  - 가능성: 높음. 이미 mug_bin·clear_to_bin 참값이 통과했다.
- 판정: 물체 중심이 입구 상자(+1 cm) 안, 바닥이 안쪽 바닥 − 1 cm와 림 사이, 놓은 상태 1 s, 바구니 이동 ≤ 1 cm. 서 있을 필요는 없다(바구니 안에서 누워도 성공).
- 명령 어휘: 기존 eef / gripper / stop 그대로다. 새 판이 필요 없다(판정·문장만 새 과제).

### 2. 면 접촉 밀기 `pu2__` — 첫 포크 설계 6절
- 닫힌 집게 옆면이나 손가락 끝 면으로 민다. 넘어짐 조건(μ·h < 반폭)을 못 맞추는 물체는 뺀다. +x·+y 방향부터 시작한다.
- 판정: 물체가 목표 ±3 cm 안, 들린 적 없음(1 cm), 서 있음.
- 명령 어휘: eef + `yaw_deg`(+x2 계열).

### 3. 열린 믹서기에 넣기 `bl__<물체>__<용기>`
- 대상: **입구에 들어갈 크기의 모든 물체**다(사용자 정정: 과일 한정 아님). 2 × footprint_r ≤ 입구 − 2 cm이고 관문 "fits"에 든 물체다.
- 참값: 바구니와 같은 틀이다. 다만 입구가 좁고(12–13 cm) 림이 높다(탁자 위 24–28 cm).
  - 운반 높이 = 림 + 12 cm(기존 carry 22 cm는 낮다).
  - 입구 중심 위에서 림 + 3 cm까지 내린 뒤 놓는다.
  - 손가락(열림 10.7 cm)이 입구에 들어가지 않게 놓을 때 벌림을 `width_m`(물체 폭 + 2 cm)로 제한한다(+x2의 gripper width_m 재사용).
  - 가능성: 중간 이상. 실행기 상자 z 상한(탁자 + 40 cm) 안에 든다.
- 판정(입구 기준): 물체 중심이 입구 원(반지름 r_top) 안, 물체 바닥이 림보다 낮음(용기 안), 놓은 상태 1 s. 용기 밖 바닥에 떨어지면 실패다.
- 명령 어휘: eef / gripper(+width_m) / stop → **+x2 판**(nd-xyz@v1+x2, d-min@v1+x2).

### 4. 서랍·문·가전 열고 닫기 — 첫 포크 설계 1–5절
- 서랍 열기는 b3d로 확인했다(219·224). 문·가전은 경첩 원호 참값과 `yaw_deg`가 필요하다. 목록은 `l8x_articulated_list.json`에 있다.

### 5. 볼펜을 펜꽂이에 꽂기 `pn__<펜>__<펜꽂이>` — 가장 어렵다
- 가는 물체(7–9 mm): 지금 물체 관문(잡는 폭 ≥ 2.5 cm)과 크기 사전 필터(1.6 cm)에 걸리므로 펜 전용 관문을 따로 둔다.
  - 위에서 잡으면 패드가 탁자 위 ~3 cm에서 닫힌다. 펜은 탁자에 누워 있어 중심 높이가 3.5–4.5 mm라 패드 아래 끝이 탁자에 닿는다.
  - 잡을 높이 = 탁자 + 반지름이다. 패드 아래 끝이 탁자보다 낮아지므로, 비스듬히 기울여 잡거나 펜을 받침(연필꽂이 옆 트레이 홈) 위에 올려 둔 초기 상태가 필요하다.
- 세워 꽂기: 누운 펜을 잡으면 펜이 손가락 닫힘축에 수직으로 수평하게 잡힌다. 세우려면 손목을 닫힘축(x) 둘레로 90° 굴려야 한다.
  - 지금 어휘(orient down / front)로는 불가능하다. front는 y축 둘레 회전이라 펜이 여전히 수평이다.
  - 필요한 어휘: `orient: "side"`(집게 축이 ±y를 향하고 닫힘축은 x 유지) 또는 일반 `rot_deg`. IK 도달 범위도 따로 확인해야 한다.
- 참값 모델: 계획은 쓸 수 있다(펜 끝 위 → 잡기 → 들기 → 굴리기 → 펜꽂이 입구 위 → 끝을 입구 안 2 cm까지 내리기 → 놓기). 다만 관문 전에는 가능성이 **낮다고 본다**.
  - 걸림 1: 잡은 펜이 손가락 사이에서 미끄러져 돈다(마찰·질량 20 g).
  - 걸림 2: 입구 오차 허용이 좁다(수저통 입구 ≥ 3.7 cm이면 끝 오차 ±1.5 cm).
  - 우선 **물리 가능성**만 관문으로 봤다: 펜을 세운 채 입구 1 cm 위에서 놓으면 꽂힌 채 머무는가(기울기 ≤ 35°). 통과 3/4: BIA 수저통 4/4, 머그 2종 4/4(펜 세워 떨어뜨림 기울기 ≤ 35°). 탈락: Circo 칫솔꽂이(입구 3.7 cm, PhysX 멈춤)DROP.
- 판정: 펜 한쪽 끝이 펜꽂이 안쪽 바닥과 림 사이, 펜 축과 수직의 각 ≤ 35°, 놓은 상태 1 s.
- 명령 어휘: +x2에 `orient: "side"`를 더한 새 판(+x3)과 정밀 접근(1 cm 단위 edit)이 필요하다.

## 제안 순서
1. 바구니(새 어휘 없음, 참값 기존 틀)
2. 면 접촉 밀기(+x·+y)
3. 믹서기(+x2 width_m)
4. 서랍 → 문·가전(관절 기물 목록, `yaw_deg`)
5. 펜꽂이(+x3 `orient: side`, 펜 전용 잡기 관문 먼저)

각 과제는 기존처럼 관문 깨끗한 참값 10편 ≥ 8/10을 통과한 뒤에 편을 만든다.
