### 0.4 E-SR1d 대비 확정·변경
1. C0 = motion_s1·s2(재학습 없음), **평가는 이번 평가 단계에서 다시**(같은 GPU·같은 부하에서 C0·A·D를 차례로 — 지연 비교 공정성 P86); G1 = C0 재평가가 E-SR0 기록을 재현.
2. 평가 조건·지표·판정 함수는 E-SR1d 그대로(`tools/sr1d/sr1d_eval.py`·`sr1d_verdict.py` 가져와 무수정).
3. 판정 문턱 = E-SR1d(= E-SR1c 등록 값): 먼 구간 A_xy ≥ 0.80(각 시드 ≥ 0.75), N1–N5, (i)–(iv).
4. 학습 GPU: 학습 한 판이 약 80 GB라 **GPU당 한 판**. 레인 GPU 2 = A s1 → D s1, 레인 GPU 3 = A s2 → D s2(`tools/sr1e/lane_sr1e.sh main`; GPU 3은 통제자 허락 '비어 있으면' — 등록 시점 우리 쪽 E-VLA-solo Isaac(약 4 GB)만 돌고 남의 프로세스 없음; GPU 2에는 다른 에이전트 `conf_extract`가 가끔 뜬다 — 건드리지 않음). 두 레인이 끝나면 GPU 2에서 평가 단계. 예상 벽시계 약 6 h(A 6,000 × 2.3 s ≈ 3.8 h + D 3,000 × 2.8 s ≈ 2.3 h) + 평가 약 2 h → **GPU ≈ 12.5 + 2 = 14.5 GPU-h**(예상)

### 2.2 L1 (`tools/sr1e/cdg_eval.py --w W`, E-SR1d C1 `/data/harvest/ckpt/sr1d/c1_s{1,2}/last`)
Euler 각 단계 v = v(o, d) + (w_eff − 1)[v(o, d) − v(o, d_self)], d_self = 모델 자신의 결정(평가 조건 `pred`), w_eff = 1 + (w − 1)·a(대용 a; unknown → 1). w ∈ {1, 1.5, 2, 3}. 지연은 두 번 전방 경로로 잰다.
### 2.3 평가 단계(`run_sr1e.sh eval 2`, 모든 학습 뒤, 한 프로세스씩): C0 s1·s2(+G1) → A s1·s2 → D s1·s2 → 판정 → L1 8회 → L1 판정 → 판정 밖(반쯤 체크포인트 A s1·D s1, train 먼 400 in-sample 4판).

## 3. 평가
`tools/sr1d/sr1d_eval.py` 그대로(val 1,799, 잡음 시드 0 × 1,000,003 + 순번, Euler 10, `--latency 50`). 판정 밖: 편 군집 부트스트랩(lit_sweep 공통 요구) — 결과 문서에 보고.

## 4. 지표와 판정(고정, `tools/sr1e/sr1e_verdict.py`)
### 4.1 주 부분(A·D)
팔마다 E-SR1d 규칙 그대로(C0 = 이번 재평가): ADOPT(등급 FULL ⇔ 먼 구간 A_z ≥ 0.80 ∧ ρ ≥ 0.5, 아니면 XY) / NEAR_BLEED / NOT_ADOPTED / NOT_REACHED. 종합: 둘 다 ADOPT 아님 → 모두 먼 구간 실패면 NOT_REACHED, 아니면 NONE_ADOPTED; 하나만 ADOPT → ADOPT_그 팔; 둘 다 → 단순한 A, 단 D − A 먼 구간 A_xy ≥ +0.03이고 짝 부트스트랩 2.5 % > 0이면 D.
### 4.2 L1
w마다: 먼 구간 A_xy ≥ 0.80(각 시드 ≥ 0.75), N1–N5·(i)–(iii)는 C0 대비 E-SR1d 문턱, (iv) 대신 지연 p95 ≤ w1 + 40 ms, 먼 구간 참 결정 청크 MSE ≤ w1 × 1.05, 먼 구간 강제 청크 |변위| p95 ≤ 기록 청크 p95 × 1.2(각 시드). 통과한 가장 작은 w → CDG_ADOPT_w, 없으면 CDG_NONE. (근접 a = 0이라 근접 청크는 구성상 w = 1과 같다.)
### 4.3 판정 밖
층별 전 지표, 데이터별, 편집·스트레스, 반쯤 체크포인트(스텝 곡선), train in-sample(적합 대 일반화), 편 군집 구간, D − A.

## 5. 해석 한계
오프라인·청크 하나(0.4 s)·시드 2개·실물 실행 없음(E-SR1d와 같음). URDF FK 대 실제 말단 오차 미상. 권한은 그리퍼 사건 되짚기 대용. D는 A와 스텝·실제 표본 수도 다르다(같은 GPU 시간 비교) — 'D > A'는 '같은 비용에서 분기 몰기가 낫다'까지만. L1은 추론 시 두 배 계산; 반사실이 지지 밖이면 안내가 틀린 방향을 키울 수 있다(추가 조건으로만 막음). 폐루프 효과는 모른다.

## 6. 합치기·다음 규칙
- ADOPT여도 실데이터 결합의 먼 구간 결정 경유 조종은 런타임 a 추정·폐루프 확인 뒤.
- 통제자 메모: 결합용 체크포인트는 VLA 단독 폐루프 관문(DEV ≥ 30 %)을 먼저 통과해야 유료 E-Couple — 이 실험은 S-E2E 실데이터라 DEV(시뮬) 폐루프로 잴 수 없다(§89); VLA 단독 폐루프 진단·속도 팔은 별도 등록(`prereg_vla_solo.md`, 다른 에이전트)에서.
