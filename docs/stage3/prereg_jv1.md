## 2. 팔

**권한 원칙(NOW §1-0b·§1-0e, 세 팔 공통):** 둘 다 상위(여기서는 시뮬 참값 명령) 명령만 따른다. 새 목표를 고르지 않는다.
- 실행 동작은 코드가 상위 목적지 끌림과 섞는다. 실행 규칙은 envelope B(우선순위 섞기)이고 설정은 §4와 같다.
- 그리퍼는 상위가 허용한 방향으로만 움직인다. 도착 뒤 1.5 s 안에 쓰지 않으면 코드가 대신 쓴다(grip_fallback으로 셈).
- 관절 걸음 ≤ 0.04 rad/틱은 월드 IK가 강제한다.
- 세 팔 모두 같은 실행기(`harvest/jcr/exec_jcr.JcrExec`, 수정 없음)와 같은 기록기(`harvest/jcr/record.py --mode eval`)를 지난다. 다른 것은 행동을 내는 클라이언트뿐이다.

**B 세부 (`harvest/jv1/`)**

*입력*
- 영상은 A와 같다. 머리 + 오른손목이고, 대상 마스크가 칠해져 있다.
- 글자는 A의 cond 벡터와 같은 정보를 공간 글자로 바꾼 것이다(`text.prompt`).
  - 명령: 목적지의 점과 높이, 허용 그리퍼, 단계, 끌림 세기, 명령 나이.
  - TCP: 점과 높이, 명령−측정 오프셋 mm, 속도 mm/s, 패드 간격 mm, effort, 7관절.

*출력*
- x y: 머리 영상 0–1000 좌표(Qwen-VL 관례). 영상 밖 값도 허용한다.
- h: 테이블 윗면 위 높이 mm.
- 사건: k(유지) / c<r>(r행에 닫기) / o<r>(r행에 열기) / s(정지).
- 접촉 1/0, 이상 5비트는 truth.ANOMALIES 순서다.

*점 → xyz*
- 머리 카메라 광선과 수평면 z = 테이블 + h의 교점이다(깊이를 쓰지 않음). 머리 카메라는 d1 2,000편 모두 같다(표준편차 1e-15). 실행 때 실제 카메라와 같은지 WORLD 줄에서 검사한다.
- d1 검증 1,998표본의 양자화 오차는 중앙 0.38 mm, 최대 1.14 mm다.

*경유점 라벨*
- 'P'(= JCR1-0P와 같은 규칙)는 참 작업점이다. 정지일 때는 현재 명령 TCP다.
- 위로 먼저 가기(via-above)·가감속·제동은 제어기가 맡는다.
- d1 검증에서 '참 경유점(양자화) → 제어기' 행과 P 라벨 청크의 차이는 중앙 0.35 mm, 최대 7.8 mm다(via-above 2 cm 경계에서 양자화로 갈리는 경우).

*규칙 조이스틱 제어기*
- `truth.smooth_chunk`/`truth.step`을 쓴다. 매 20 Hz 틱마다 현재 명령 TCP·속도에서 경유점(via-above)으로 간다.
- 속도 ≤ 0.08 m/s, 가속 ≤ 0.32 m/s², 이산 제동이 있어 넘치지 않는다. 즉 최소 가속 제한 궤적이다.
- 그 뒤 A와 똑같이 코드 끌림 섞기와 IK(관절 걸음 ≤ 0.04 rad)를 거친다.
- 과제 지시문의 '30 Hz'는 이 월드의 제어 틱이 20 Hz(dt 0.05 s)이므로 20 Hz로 읽는다. A도 20 Hz다.

*확률*
- 탐욕 디코딩이다.
- 접촉·이상은 해당 자리의 p('1') / (p('0') + p('1'))이고, 이상 'any' = 다섯 개의 최대다.
- 사건은 원-핫이다. 형식이 깨진 답은 오류로 세고, 그 결정에서는 멈춰 선다(A의 서버 오류와 같은 처리).

*추론*
- LoRA를 병합해서 쓴다.
- 스모크(x3, 2 CPU) 실측: 답 21토큰, 프롬프트 558토큰, prefill 37 ms, 답 하나 0.52 s(병합 전 1.08 s). 본 값은 §4-2 벤치로 정한다.

## 4. 평가 (P0 정답 명령 폐루프, 짝 비교)

- **세트**: SoloWorld mug_tray, DEV 배치 시드 0–19 × standard·dr = **40편**. 명령은 시뮬 참값(`--src truth`, P0)이고, 명령 30회·동작 120 s 제한은 E-CJ1·E-JCR1 OJ와 같다.
  - **clean**: 교란 없음.
  - **dist**: d1과 같은 물리 교란 종류(push 대상 밀림 / shake 잡기 직전 흔들기 / obstacle 운반 경로 옆 장애물 / slip 운반 중 그리퍼 잠깐 열림) 중 1–2개를 d1과 같은 크기(scale 0.75)로 넣는다.
  - 고정 난수 [시드, 변형, 7101]은 결과 전에 고정했고 모든 팔이 같다(`harvest/jv1/plan.py`).
  - 학습 시드(R2_TRAIN)와 겹치지 않는다.
- **실행 규칙**(모든 팔 같음): envelope B, PRIO = 임시 기본값(가우시안, ρ 3 cm, w_min 0.2, w_max 0.7, A 10 cm, ε 1 cm, t_ramp 1 s).
  - 스윕 1단계에서 채택 후보가 0개(`sweep1`: n_adoptable 0)라 기본값을 고정한다.
  - E-JCR1이 JCR1-0P의 실행 규칙을 다르게 확정하면, 그 값으로 바꾸는 것을 '변경'으로 기록한 뒤 돈다.
- **조건 Z (지연 0, 모델 품질)**: 호출 동안 시뮬이 멈추고, 모든 팔이 0.2 s마다 답한다(= E-JCR1 OJ 방식).
- **조건 R (실시간 모사, 주 판정)**: 팔마다 §4-2 벤치에서 고정한 lat_s·period_dec를 쓴다(`harvest/jv1/realtime.DelayedClient`).
  - 모델은 period_dec 결정(0.2 s 단위)마다 한 번 묻는다. 관측 t_j의 답은 t_j + lat_s(시뮬 시간)부터 효력이 생기고, 그 전에는 이전 답이 계속 돈다.
  - A: 이전 청크를 시간 맞춰 이어 실행하고, 끝나면 마지막 행에 머문다(순진한 비동기, RTC 없음).
  - B: 20 Hz 제어기가 그때 유효한 경유점을 따라간다.
  - 그리퍼 사건은 현재 결정 기준으로 다시 색인해 한 번만 넘긴다.

## 6. 판정 규칙 (`tools/jv1/summary.py`, 등록 시점 고정; 짝 부트스트랩 10,000회, 단위 = (세트, 변형, 시드))

- Δ_R = 성공(B) − 성공(A), 조건 R의 clean + dist 80쌍. Δ_Z도 같은 방식이다.
- **`B_BETTER`**: Δ_R ≥ +10 %p, Δ_R의 95 % 하한 > 0, **그리고** Δ_Z 하한 > −10 %p(Z에서 비열등).
- **`A_BETTER`**: Δ_R ≤ −10 %p, 상한 < 0, 그리고 Δ_Z 상한 < +10 %p.
- **`MIXED`**: R과 Z가 서로 반대 방향으로 유의할 때. 주기·지연 탓인지 품질 탓인지를 분해해 보고한다.
- **`BOTH_FLOOR`**: Z clean에서 A·B 모두 ≤ 4/40. 비교하지 않고 원인부터 분해한다.
- 그 밖은 **`NO_DIFF`**다. 근거 없이 바꾸지 않으므로 기본 JCR은 A로 유지한다. B는 후보로 남기고 보조 지표를 보고한다.
- **제어기 한계**: C Z clean < 30/40이면 B의 제어기가 병목이다. 판정과 함께 적는다.
- 숫자만으로 결론 내지 않는다. 팔마다 실패 편 전부와 성공 편 일부의 머리 + 손목 영상(10 fps 이상, `/data/harvest/videos/jv1/`)을 확인하고 단계별로 실패를 분해한다(NOW: 단계별 분해 추론).

## 7. 버리기 전 재검증

진 쪽을 버리기 전에 아래를 한 번 한다. 결과는 '재검증' 절에 따로 적고, 판정은 바꾸지 않는다.

## 9. 한계 (결과 해석 때 함께 적음)

- **시뮬 한정 이점**: B의 규칙 제어기는 A의 라벨을 만든 함수(`truth.smooth_chunk`)와 같다. 그래서 B는 동작 모양을 배울 필요가 없다. 실로봇 원격조종 데이터로 옮기면 이 이점이 줄 수 있다.
  - 이 몫은 C − B(인식 손실)와 A의 끝점 오차(모양 + 인식)를 나란히 보고해 드러낸다.
- B의 R 지연은 HF generate(병합 LoRA) 실측이다. 더 빠른 서빙(vLLM 등)은 나중 선택지이고, 이 판정에는 쓰지 않는다.
- R은 0.2 s 결정 격자 위의 모사다. 지연은 틱(0.05 s) 단위, 주기는 결정 단위로 반올림된다.
- 목적지 민감도는 같은 영상을 쓰는 운동학 근사다.
- 세계는 SoloWorld mug_tray 하나다. L8S·L9로 일반화되는지는 별도 실험이다.
- JCR1-0A(딱딱한 범위) 짝인 B 라벨 'A'는 코드에 있다(`--label A`). 하지만 이번 예산 밖이다. 필요하면 변경으로 추가한다.
