## 1. 질문
Astra `edit`(손끝 기준 이동, 수치)을 VLA 입력에 (C1) 문장 한 줄로, (C2) 머리 영상에 코드가 그린 2점 화살표로 주고 되짚기 명령으로 학습하면, 반사실(돌린) 명령을 줬을 때 VLA의 결정과 청크가 명령을 따르는가 — 명령이 없을 때 정확도는 유지되는가, 지연은 얼마나 느는가.

## 2. 입력 정의 `ma2@v1` (`harvest/train/r2_ma2.py`)
- **명령 c(학습, 되짚기)**: 결정 스냅샷 k의 손끝(손가락 중점 `tcp`, 탁자 좌표 = 로봇 x·y 축, z = 탁자 위 높이)의 다음 1.0 s 변위 `tcp[k+30] − tcp[k]`(끝을 넘으면 마지막 프레임), 축마다 ±5 cm로 자름(`edit` 범위).
- **주는 표본(50 %)**: `give(id)` = sha256("ma2give@v1|<변형>/<과제>/<섭동>/ep<시드>/k<k>") 앞 8자리 < 0.5 — 결정적, C1·C2에서 같은 표본(짝). 명령이 없는 표본은 C0과 입력이 같다.
- **C1 문장**: 문맥 끝과 모든 질문 문장의 같은 자리에 `astra edit: move fingertip dx=+1.2 dy=-0.4 dz=+0.0 cm (robot frame)`(cm, 소수 1자리).
- **C2 화살표**: 머리 영상(672×376)에 시작점 원(반지름 3 px) + 선(3 px) + 화살촉(10 px, 길이 ≥ 4 px일 때), 청록 (0, 255, 255), 시작 = 현재 손끝, 끝 = 손끝 + c. 투영 = 시뮬 머리 카메라(상수: R1-DEV 804 스냅샷의 링크 × 장착 변환 중앙값, 최대 편차 4.8 mm; fx = fy 367, 주점 (336, 188); 두 코드 판의 카메라 사양·머리 관절 0.69·탁자 높이 0.85 같음 확인). 학습 영상은 원 JPEG을 풀어 그린 뒤 q90로 저장(`tools/ma2/build_ma2.py arrows`), 지연 측정은 실행 때처럼 메모리에서 그림.
- **라벨(Claude 결정, 등록 전)**: 명령을 준 표본의 `dir_xy`·`dir_z` 정답(과 확정 결정)을 **명령의 칸**(labels_v2 규칙, 축마다 1 cm 사각대)으로 바꾼다. `mag_coarse`·`target`·`phase`는 labels_v2 그대로. 이유: 데이터에서 되짚기 명령 칸과 labels_v2(부분 목표 방향)의 일치는 `dir_xy` 0.74·`dir_z` 0.70뿐이라(4절), 바꾸지 않으면 명령을 준 표본의 약 4분의 1에서 "명령과 다른 쪽이 정답"을 가르치게 되어 따름을 **학습으로 억누른다**. MolmoAct의 궤적 조건 데이터도 조건과 실제로 이어진 행동을 정답으로 쓴다(연구 문서 §2.3·§4.1 "그린 것을 따르도록 학습시켜야 따른다"). 명령 없는 표본은 labels_v2 그대로라 명령 없는 정확도 비교(C0 대비)는 같은 정답으로 한다.

## 6. 지표와 판정 규칙 (고정)
- **준수율(모델)** = 평가 쌍 (스냅샷, 회전 ∈ {e90, e180}) 중 참 명령 |xy| ≥ 1 cm이고 돌린 명령의 `dir_xy` 칸이 `none_xy`가 아닌 쌍에서, [예측 `dir_xy` = 돌린 명령의 칸] **그리고** [청크 손끝 변위 xy와 명령 xy의 코사인 > 0.5]인 비율(변위 xy ≈ 0이면 실패). C0은 명령을 못 보므로 `none` 기록으로 같은 쌍을 채점(참고 바닥값).
- **명령 없는 정확도** = `none` 조건의 모든 결정 항목(5문항) 정확도(labels_v2 정답).
- **지연** = `tools/ma2/ma2_latency.py`(E-CAM3 도구와 같은 방식): 결정 1회 = `forward_shared([표본])`, FULL = 이미지 읽기(+ C2는 메모리 그리기)·전처리·토큰화·GPU(cuda 동기), 묶음 1, 평가 집합에서 시드 0 표본 50개(참 명령 e0), 세 형식 교차, 예열 30, 4회, 가중치 c0(계산량은 가중치와 무관), GPU 2, 다른 줄이 끝난 뒤.
- **판정**(CMP_EPS 1e-12):
  1. C1·C2 준수율이 **둘 다 < 0.6** → **NONE**: VLA는 명령을 보지 않고 §11 코드 편향만 쓴다(설계 유지).
  2. 아니고, 준수율(C2) − 준수율(C1) **≥ +0.10** 그리고 명령 없는 정확도 C2 − C0 **≥ −0.01** 그리고 FULL p95(C2)/FULL p95(C1) − 1 **≤ 0.10** → **C2 채택**(VLA 입력에 코드가 그린 화살표).
  3. [등록 보충 — 초안이 비워 둔 경우, Claude 결정] 아니고, 준수율(C1) **≥ 0.6** 그리고 명령 없는 정확도 C1 − C0 **≥ −0.01** 그리고 FULL p95(C1)/FULL p95(C0) − 1 **≤ 0.10** → **C1 채택**(문장 한 줄).
  4. 그 밖 → **NONE**.
- 판정 밖(보고 의무): 회전별 준수율, 참 명령(e0) 준수율, 결정만·청크만 준수 성분, 스냅샷 부트스트랩 10,000회(시드 0) 95 % 구간(준수율 차, 정확도 차), 질문별 정확도, GPU p50/p95, 프롬프트 토큰, 학습 시간.
- 판정 스크립트 `tools/ma2/ma2_verdict.py`(시험 `tests/test_ma2_verdict.py`, 경계값 포함). 입력 검사: 세 파일 모두 평가 id × 조건이 정확히 한 번, 요약의 조건 일치, 기록된 돌린 명령 = 다시 계산한 값. 결과 뒤 고치지 않는다.
- **해석 한계**: 오라클 계획기 시연(경로 다양성 낮음, MolmoAct 조종 시연과 다름), 오프라인(폐루프 아님) 준수율, 시드 하나, §56 소규모(2,000스텝). 채택이어도 "이 규모에서 형식 선택"이며 폐루프 효과는 E-Couple에서.
