# 결합 실험 프로그램 — 상위 LLM + 조이스틱 VLA (연결 손실 재기·줄이기)

> **명칭 갱신 (2026-10-01):** 사용자 확정으로 하위 모델을 'VLA'가 아니라 **JCR(Joystick-Conditioned Reflex, 조이스틱 반사 정책)**로 부른다(언어·계획 없음). 이 문서의 기존 'VLA' 표기는 그대로 두되, 새로 쓰는 문서·논문은 JCR을 쓴다. 자세한 내용은 NOW.md §1-0.

- 작성 2026-09-30 22시경 KST, COUPLE 에이전트. 번호는 `D:\tools\scratch_qdd\board\PLAN_coupling.md`(P0·P1·P2)와 맞춘다.
- 목표(NOW.md §1): 명령 권한은 늘 상위. VLA = 상위 명령의 허용 범위 안 좁은 조이스틱 + 이상 신호. 합격 = **연결 손실 ≤ 5 %p**, **연결 탓 실패 ≤ 전체 실패의 10 %**.
- 핵심 가설(NOW.md §1-1): 계획·판단·명령을 상위가 떠안고 VLA에게는 조이스틱만 주면, 같은 VLA가 스스로 계획할 때(단독)보다 낫다. 이 프로그램은 이 비교를 직접 넣는다(P0-8, P1-2).

## 2. 인터페이스 (P0-2, 첫 판)

- **명령(상위 → 코드)**: 방식 D 그대로 — 머리 영상 점 + 높이 의도(above·grasp·place·lift) + 그리퍼 의도(open·close·keep). 코드가 깊이로 목표 xyz를 만든다(`astra_solo/resolve.py`, D·참값 공용).
- **조이스틱(코드 → VLA, 0.33 s마다)**: `harvest/couple_joy/joy.py` — 방향·크기 = labels_v2('목표 − 손끝'), 단계 = 상위 의도에서(다가가기 approach · 내려가기 descend · 쥐기 close · 들기 lift · 옮기기 carry · 놓으러 내려가기 place_descend · 놓기 open · 물러나기 retreat), 대상 = 1단계 물체 / 2단계 놓을 곳, phase 슬롯 = 사각지대 안이면 next, 빈손으로 닫혀 있으면 hold, 아니면 continue.
- **허용 범위(권한)**: 어디로(목표)·무엇을(그리퍼 의도)은 상위, 어떻게(관절 경로)·언제(허용된 방향의 그리퍼 동작 시점)는 VLA. 그리퍼는 상위가 허용한 방향으로만 움직인다(`grip_gate`). 도착 뒤 1.5 s 안에 VLA가 허용 동작을 끝내지 않으면 코드가 끝낸다(`grip_fallback` = 연결·VLA 이상 신호로 셈). 관절 걸음 ≤ 0.04 rad/틱.
- **도착 규칙**: 스크립트 실행기와 같다(reach 8 mm, 3 cm 안 멈춤 = settled, 그 밖 멈춤·시간 초과 = timeout).
- 되돌림 신호(이상 점수 3종), 명령 나이·시간 예산 필드는 첫 판에 없음 → P0-2 다음 판.

## 4. 지표와 연결 탓의 정의

- **성공률**(과제 판정 = 에피소드 자체 판정), 들어 올림, 실패 단계, 벽시계·호출 수, VLA 지연 p50/p95, `grip_fallback`·`vla_error`·timeout 수, 폐루프 조이스틱 준수(한 결정 스텝 동안 실제 손끝 이동 방향이 명령 방향과 같은 비율).
- **연결 손실**(2×2가 다 찬 뒤) = min(PX, OV) − PV. PX = 상위 + 스크립트(상위의 상한), OV = 시뮬 참값 + VLA(VLA의 상한).
- **실패 원인 (편 단위, 같은 시드·변형)**: PV 실패 편에서
  - PX 성공 ∧ OV 성공 → **연결 탓**(둘 다 혼자서는 되는데 붙이면 실패),
  - PX 실패 ∧ OV 성공 → 상위 탓, PX 성공 ∧ OV 실패 → VLA 탓, 둘 다 실패 → 둘 다.
  - 결정성 확인: 같은 편을 두 번 돌려 판정이 바뀌면 '불안정'으로 따로 센다(E-CJ3에서 편 안 반사실 재생으로 좁힌다).
- **핵심 가설 지표**: OV(또는 PV) − V0, 같은 시드 짝 차와 부트스트랩 95 % 구간.
