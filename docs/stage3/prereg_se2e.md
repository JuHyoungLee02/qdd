# S-E2E 학습 판정 — 사전 등록 (2026-09-25T09:39:32Z, 학습 전)

작성 S-E2E 학습 에이전트. 이 문서는 S-E2E 본 학습(두 시드)을 시작하기 **전에** 고정한다. 학습 결과를 본 뒤에는 문턱·비교 방식·검증 부분집합을 바꾸지 않는다. 결과는 `docs/stage3/results/se2e_train.md`에 적는다.

근거: 정본 `docs/design/00-interfaces.md` §56(소규모 시험 성격), §58(융합 모델), §62(10 Hz 그대로), §63(데이터·열린 문제 처리), §69 N2·N3(층화 검증 부분집합, 중간 체크포인트·재개, 평가 간격·크기), §71(해시 보호 파일 무수정), `docs/stage3/results/se2e_data.md`, `r4_stageB.md`, `r3_throughput.md`, R7 10–12회차 N5·N8·N10(작은 스모크에서 fm 손실 비단조 → 어느 손실을 볼지 명시).

## 1. 성격
- **파이프라인 시험이다(§56)**: "실물 공개 데이터로 융합 모델 단계 B 학습이 끝까지 돌고, 손실이 줄고, 저장·재적재·재개가 정확한가"만 본다. 과제 성공·로봇 실행(실물 데이터라 롤아웃 없음)은 보지 않는다. 수치는 논문 결과·근거로 인용하지 않는다.
- RB1은 라이선스 미표기(§63 (6)) → 체크포인트·프레임은 **내부 시험용**, 공개·논문 게재 금지.
- 결정 라벨은 휴리스틱 `se2e_heur_ee033@v1`(다음 0.30 s 실제 말단 변위, 1 cm 데드밴드, labels_v2 MAG 구간)이며 §63 (5)의 라벨 창·데드밴드는 `se2e_data.md` 5절 값 그대로 고정한다(0.30 s = 3스텝, 1 cm).

## 2. 사전 측정(판정 밖, 공개)
사전 등록 전에 코드 경로 확인용 스모크를 GPU 2에서 돌렸다(`/data/harvest/ckpt/se2e_smoke`, 40스텝, 검증 10개, 결과로 쓰지 않음):
- 처리량 약 **1.4 s/스텝(묶음 8)**, 검증 표본당 약 0.28 s → 아래 스텝 수·평가 크기를 정하는 데 썼다.
- 저장·재개 경로: 20스텝 체크포인트에서 재개하면 **첫 재개 스텝(21)은 손실·기울기 노름·lr·배치까지 비트 동일**, 22스텝부터 총손실 상대차 0.03–0.7 %. 같은 체크포인트에서 **두 번 재개한 두 판끼리도 같은 크기로 어긋났다** → 상태 복원 누락이 아니라 GPU 역전파 비결정성(주의 커널 등) 바닥으로 본다. 그래서 (e)는 비트 동일 또는 아래 허용치로 판정한다.
- evalck(20스텝 체크포인트 재적재 → 같은 검증) = 기록된 eval과 **완전히 같음**(차 0.0).
- 손실 값은 판정 문턱을 정하는 데 쓰지 않았다(스모크 40스텝의 값은 문턱과 무관한 규모).

## 4. 판정 기준 (파이프라인 건강, 과제 성공 아님)
평가 지표 이름(`evaluate()` 출력, 검증 부분집합 300개):
- `dec` = **검증 결정 NLL**(질문 3개의 트라이 재정규화 집합 NLL 평균),
- `fm` = **검증 흐름 정합 손실**(고정 t·noise),
- `sample_mse_norm` = **검증 샘플 청크 오차**(10 오일러 스텝, 정규화 단위).

"처음" = step 0 eval, "끝" = step 4686 eval, "끝 3점 평균" = step 4000·4500·4686 eval의 산술 평균(fm이 짧은 구간에서 비단조였으므로 평활 창으로 판정). 시드마다:

- **(a) 완주**: 주 학습 rc 0, 학습 기록 스텝이 1…4686 빠짐 없음, 학습·평가 손실(fm·dec·total·grad_norm, eval fm·dec·sample_mse_norm) 모두 유한, step 4686 eval·체크포인트·`last/` 존재.
- **(b) 감소**:
  - (b1) `dec`: 끝 3점 평균 ≤ **0.70 ×** 처음, 그리고 끝 ≤ **0.80 ×** 처음.
  - (b2) `fm`: 끝 3점 평균 ≤ **0.80 ×** 처음, 그리고 끝 ≤ **0.90 ×** 처음.
  - (b3) `sample_mse_norm`: 끝 3점 평균 ≤ **0.80 ×** 처음.
- **(c) 재적재 일치**: (c1) 끝: `--reload-check`의 `max_abs_action_diff` = **0.0** 그리고 `eval_equal` = true. (c2) 중간: `evalck --ckpt ckpt/step_002000 --against log.jsonl --step 2000`의 `equal` = true(모든 eval 필드가 학습 중 기록값과 정확히 같음).
- **(d) 두 시드**: A·B 모두 (a)·(b)·(c) 통과.
- **(e) 재개 재현**(시드마다, step 2001–2050의 50스텝을 원래 판과 비교):
  - **비트 동일**: 50스텝 모두 fm·dec·total·grad_norm·lr_heads·배치 색인(idx) 같음 → 통과(강).
  - **허용 통과**: 비트 동일이 아니면 다음을 모두 만족할 때 통과 — 50스텝 모두 idx·lr_heads 같음(데이터 순서·스케줄 복원), step 2001의 fm·dec·total 같음(가중치·RNG 복원), step 2002–2050 총손실 상대차 |Δ|/|원래|의 **중앙값 ≤ 1 %**, **최댓값 ≤ 5 %**(2절 비결정성 바닥).
  - 그 밖 → 불합격.
- **종합**: (d)와 두 시드의 (e)가 모두 통과면 "S-E2E 파이프라인 학습 통과". 하나라도 불합격이면 불합격 항목과 원인을 보고하고 문턱을 바꾸지 않는다(원인 수정 뒤 재학습은 새 사전 등록 판으로).
