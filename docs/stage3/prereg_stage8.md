## 1. 데이터 (빌드 `tools/teach_pt/stage8_build.py`, 결과 `/data/harvest/out/stage8/build.counts.json`)
- **기본**: L8-X b2 D d-min 78,745행(`/data/harvest/out/opratio/base_d-min.jsonl`).
- **공개 점**: E-VIEW8의 머리 시점 칸(`view8_build.classify`의 head)이다.
  - 37,490행. 광각·3인칭은 없고, Franka 행은 학습용 사본만 읽는다(작전T 753c9a1). 해시는 prereg_view8.md에 있다.
  - G 행은 먼저 빼고 가드를 통과시켰다.
- `train_mix.jsonl` = 기본 + 공개 75 %(59,059행, 칸 1.575배 반복, 시드 8) → 137,804행.
- `train_post.jsonl` = 기본 + 공개 15 % 재생(11,812행, 시드 9) → 90,557행.
- gsplit 검사: 두 파일 모두 G 0행.

## 2. 팔 (레시피는 E-OPRATIO8·E-VIEW8과 같음: Qwen3-VL-8B LoRA r16 α32, lr 1e-4 코사인 warmup 20, 미세 배치 8 × 누적 2, `--save-every 200`)
- **M_s0 / M_s1 (한 번에 섞기)**: `train_mix`로 2,856걸음(= 1,632 × 1.75, E-OPRATIO8 p75와 같은 계산).
- **S_s0 / S_s1 (2단계)**: 전체 걸음을 M과 같은 2,856걸음으로 맞춘다.
  - 1단계: `train_mix`로 1,904걸음(2/3). 끝나면 LoRA를 병합한다.
  - 2단계: 병합된 1단계 모델 위에 **새 LoRA**를 `train_post`로 952걸음(1/3) 학습한다. 레시피는 같다(lr 1e-4, warmup 20).
  - 평가 모델 = 1단계 병합 모델 + 2단계 LoRA 병합.
- 시드 0·1은 `--seed`만 다르다(LoRA 초기화·미세 배치 순서). 두 단계 모두 같은 시드를 쓴다.
- 기본 행 노출은 비슷하다: M은 약 26,100샘플, S는 약 17,400 + 13,200 = 30,600샘플.

## 3. 평가·판정 (E-VIEW8과 같은 기준, `tools/teach_pt/view8_compare.py S M`)
- **평가**:
  - G 1,577행(`/data/harvest/out/opratio/g_eval.jsonl`, 변경 2 채점기).
  - L8-X 7세트 d-min.
- **짝 부트스트랩**: 짝 = (시드, 상태/행)이다. 두 시드의 짝을 합쳐 10,000회(시드 0)를 한 번 돌린다.
- **나빠짐 없음**:
  - L8-X 7세트 모두 접근 3D 평균 차 95 % 상한 ≤ +2 mm.
  - G 하위 6세트 적중 하한 > −0.03(Where2Place만 > −0.10).
  - 라벨 세트 픽셀 오차 상한 ≤ +3 px.
- **좋아짐**: G 전체 적중 하한 > 0, 또는 가장 바깥 묶음(RefSpatial + Where2Place) 적중 하한 > 0.
- **결과**:
  - ADOPT → 2단계(S)를 35B 학습 방식으로 쓴다.
  - SAME·REJECT → 한 번에 섞기(M)를 쓴다(더 단순하고, 나빠질 위험이 없는 쪽).
- **보고만 하는 것**: 팔·시드별 L8-X 평균·중앙값·'내려가지 않음' 비율, G 하위 세트 적중률.
- 8B 한 크기의 결과이므로 35B에서 다시 확인한다고 적는다.
