## 0. 자체 검사
- **무엇을 결정하나**: (1) 데이터를 다양하게 하면(L8-X) 깊이 없는 R이 높이를 일반화하는가, 깊이 D와의 차가 줄어드는가; (2) 공개 픽셀 데이터를 섞으면 도움이 되는가(수준마다 짝); (3) H가 한 모델로 D(깊이 있을 때)와 R(없을 때)을 대신할 수 있는가; (4) 실물 같은 깊이 잡음에서 D·H가 얼마나 무너지는가.
- **이 표본으로 가를 수 있나**: 오프라인 DEV·OOD 세트마다 수백 스냅숏, 스냅숏 짝 부트스트랩 → 팔 사이 수 mm; 폐루프는 4판씩 방향만.
- **이미 본 것(P16)**: E-PT(`results/pt.md`: 옛 L8에서 D = pt BETTER 3.5 mm, R 계열 SAME/WORSE), E-STRIP8(`results/strip8.md`: S-min = 손정보 없는 R이 L8과 비열등, 넓은 OOD-H 판정 불가), E-TEACH-35B(`4925713`: 35B xyz도 OOD-H에서 8B와 SAME — 크기로는 높이가 안 풀림, 2에폭이면 충분). L8-X 데이터·공개 팩으로 학습한 답은 아직 없다.
- **성립 조건(P81)**: 세 줄기가 같은 상태·같은 최소 요청 본문을 본다(관문 G-same), 각 줄기 참값이 채점기로 ~0(G0), 공개 팩이 우리 기체 좌표를 새지 않는다(G-leak).

## 1. 팔
### 1.1 입력 형식 (세 줄기 공통, 잠정)
- **최소 요청** = E-STRIP8 S-min(`teach_strip8.strip.minimal`): 탁자 높이·격자·낙하선·물체 크기·요령 없음, 고리만 머리 영상. STRIP8의 L8-X 재검증(E-STRIP8b) 전까지 **잠정** — 재검증이 손정보를 KEEP으로 바꾸면 변경 기록으로 모든 L8-X 팔 요청을 바꾼다.
- 줄기별 차이는 명령·답 부분뿐(`harvest/teach_pt/min_format.py`):
  - **R** `r-min` = S-min 그대로, xyz 답.
  - **D** `d-min` = eef 줄 → point 줄 + POINT, THEN ACT 블록(높이 의도 정의 = 인터페이스), pt 답; 목표 = 머리 깊이 변환기(PT-0c + 로봇 자기 가림).
  - **H** `h-min` = R 요청 + `depth:` 줄 + 하이브리드 답(점 + 의도 **그리고** xyz) + (있으면) 깊이 영상(0.25–1.60 m 고정 회색조, 1/2 해상도). 실행 선택기 = 깊이 유효·점 해석 성공 → PT 변환기, 아니면 모델 xyz. 학습 = 깊이 빼기 p 0.5, 남긴 것 절반 zed_mini 잡음(행 id로 결정).
### 1.2 데이터 수준
- **A = 옛 L8**(300편, E-PT 수집 = L8과 요청 바이트 동일 상태).
- **B = L8-X**(L8D의 첫 동결 묶음, `tools/teach_l8d/freeze.py` 목록·해시를 결과에 적음; 편 수가 A와 다르면 **같은 걸음 816·같은 표본 13,056**으로 맞춤).
- **C = L8-X + 공개 3D**(작전T: BEHAVIOR m 3D QA + C′, 형식 태그 `source:`·`frame:`), B와 같은 걸음.
- **+px** = 해당 수준 + 작전T 공개 픽셀 흐름(P-점·그리퍼 픽셀; 깊이 없음 → H는 xyz 생략·손실 가림, D·H는 점 답, R은 점 QA만). 섞는 몫 = 표본의 25 %(나머지 75 %가 그 수준 데이터), 총 걸음 816 그대로.

## 4. 판정 (결과 전 고정)
- **Q1 D 대 R**(수준·px마다, 주 OOD 합동): 차(D − R) 95 % 구간 상한 < 0이고 D 중앙 ≤ 0.8 × R → D BETTER; 구간이 0 포함 → SAME; 하한 > 0 → WORSE.
- **Q2 데이터 효과**(줄기마다): B 대 A, C 대 B — 같은 규칙.
- **Q3 픽셀 효과**(수준·줄기마다): +px 대 −px — 같은 규칙, DEV 비열등(+2 mm) 조건 함께.
- **Q4 H**(B+px, A): H-on 대 D 상한 ≤ +2 mm → 비열등; H-noisy 대 D-noisy 상한 ≤ +2 mm; H-off 대 R 상한 ≤ max(5 mm, R 중앙의 10 %) → 비열등, 상한 < 0 → BETTER. 결론 칸 `H_REPLACES_BOTH` / `H_DEPTH_ONLY` / `H_NOT_NEEDED` — R·D는 결론과 무관하게 최종 35B까지 들고 간다(user-log 146·148), 교체는 사용자 결정.
- **Q5 깊이 잡음**: D-noisy − D-on 차를 보고(기술); D-noisy가 R보다 나쁘면 '실물 깊이 품질이 D의 전제'로 적고 H의 가치를 그 기준으로 판단.
- 옛 L8(A) 결과는 **예비**(user-log 151: 쉬운 장면) — 최종 결론은 B·C 수준과 L8-X OOD로만 내린다.
