### 4.3 지표
- **M4 (b)**: 스텝 끝 스냅샷(평가 분할)에서 술어별 균형 정확도·AUROC, 온도 뒤 ECE, conformal(α = 0.1) 경험 커버리지·원소 하나 비율, "{거짓} 판정 정밀도"(CONTRADICT/DEVIATE의 오경보), 단계(near/contact 대 먼 구간)·카메라 조건별. 로봇 쪽 술어는 P의 정확도를 따로.
- **자기 확인 맹점**: labels_v2 정답과 다른 결정을 한 스텝(단계 A 모델 재생)에서 V1h가 "일치"라 한 비율 대 P.
- **M7 critic**(FI-DEV 평가 분할, 오프라인 재생): 에피소드 FWER(명목 + 무해 편차) 5 %에서 고정 창 재현율(τ = 2 s, 정본 §23 판정 지표), 탐지 지연 중앙값, 주입 종류·단계별, 무해 편차 첫 개입률. 채널 구성은 M7 D5(AND, 같은 출처 1표).
- **지연**: 문맥 순전파 + 헤드 p95 증가분(H200, 실물 서버 RTX PRO 6000 측정은 뒤에).

### 4.4 판정 (실행 전 고정)
1. **PC1(세계 쪽 측정)**: V1h의 세계 쪽 술어 {`on/in_contact(target, place_ref)`, 쥐지 않은 `lifted`, `near`, `above`} 평균 균형 정확도 ≥ 0.90 **그리고** V0 + 0.15 이상 **그리고** 최빈 + 0.15 이상(부트스트랩 95 % 하한 기준), 온도 뒤 ECE ≤ 0.05, conformal 경험 커버리지 ∈ [0.88, 0.95]. 통과하면 V1h를 (b)(2) 세계 쪽 측정으로 채택. V1q가 V1h보다 +0.03 이상이고 지연 증가 ≤ 50 ms면 V1q로.
2. **PC2(로봇 쪽 T1)**: P의 `gripper_open`·`holding`/빈 집기·쥔 채 `lifted` 균형 정확도 ≥ 0.97 이고 명목 에피소드 FWER ≤ 1 %면 T1(하드 가능)로 등록. 미달 술어는 T2.
3. **PC3(critic)**: V1h+P가 FWER 5 %에서 고정 창 재현율 ≥ 0.80이고 V1h 단독·P 단독보다 각각 +0.05 이상이면 두 채널 구성 채택. 아니면 더 나은 단독 + 나머지는 기록만.
4. **PC4(지연)**: V1h 추가 p95 ≤ 20 ms. 넘으면 헤드를 결정 시퀀스 대신 lead 시퀀스에만.
5. **PC5(L)**: V1h+P에 L을 더했을 때 같은 FWER에서 재현율 +3 %p 이상이면 `C_lat`을 [결정 필요]로 올린다. 아니면 절제 결과로만 보고(M7 판정 2와 같은 규칙).
6. **PC6(실패 시 대체)**: PC1 미달이면 (b)(2) 세계 쪽 술어는 `unknown`으로 두고(로봇 쪽 P만 판정), 세계 쪽 확인은 Astra T_sub로 옮긴 판을 E-M4 비교 조건으로 올리고 논문 한계로 적는다. 결과를 보고 판정을 바꾸지 않는다.
7. 통계: 평가 시드 15–29 × P0–P2(POOL 평가 60편은 V1 계열 술어 정확도 보조), 에피소드 단위 짝 부트스트랩 95 %. 사후 변경은 시각과 함께 결과 문서에 적는다(R1 §3.0 방식).

### 1.2 시험 술어와 단계 기대표
- 세계 쪽 W = `on_tp`(on(o3,o5)), `contact_tp`(in_contact(o3,o5)), `lifted_t`(lifted(o3) — **D28의 "쥐지 않은 lifted"는 "그리퍼 상태가 아닌 물체 쪽 사실로 잰 lifted"로 읽는다**: 쥐지 않고 공중에 뜬 머그는 순간뿐이라 따로 두면 양성이 거의 없음), `near_tp`(near(o3,o5)), `above_tp`(above(o3,o5)). 로봇 쪽 R = `gripper_open`, `holding_t`(holding(o3)), `lifted_holding`(holding ∧ lifted), `contact_stall`(참값 = 그리퍼가 열린 채(폭 ≥ 8 cm) 물체와 접촉, 접촉 센서).
- 평가 분할에서 양성 또는 음성이 20개 미만인 술어는 평균 균형 정확도에서 빼고 이름을 적는다(예상: `near_tp`는 머그가 트레이 위에 있어도 중심 거리 ≥ 5.5 cm라 거의 늘 거짓).
- 단계 기대표(정책이 그 단계에서 기대하는 `expected_after`, critic이 확인): approach·descend = gripper_open ∧ ¬holding ∧ ¬contact_stall / close·open = 없음(전이 단계) / lift = holding ∧ ¬gripper_open / carry = lift 조건 + lifted_holding + lifted_t / place_descend = lift 조건 + (above_tp ∨ contact_tp) / retreat·done = on_tp ∧ ¬holding.

- **P**: 고유 감각 코드 규칙. 효과 측정값 = `applied_torque` + N(0, (0.02·한계)²) 잡음 [가정, R-noforce 잡음 모델이 문서에 수치로 없어 여기서 정함], 고정 시드. gripper_open = 폭 ≥ θ_w / holding = θ_lo < 폭 < θ_hi ∧ 그리퍼 토크 ≥ θ_I / lifted_holding = holding 규칙 ∧ TCP z(FK) ≥ θ_z / contact_stall = 폭 ≥ θ_w ∧ ‖τ − τ_grav‖ ≥ θ_τ. 문턱은 보정 0–14에서 술어별 균형 정확도 최대 격자 탐색. critic 점수 = 문턱까지의 정규화 여유(표준편차 단위)를 tanh로 [0, 1]에 올린 값.
- **V1h+P**: 로봇 쪽 = P, 세계 쪽 = V1h.
- **V0**: R1 파이프라인(`perception.run_r1`의 검출·융합·`est_line`, 이름 표 `r1/out/phrases.json` 동결, v2 접촉 문턱)을 FI-DEV 평가 시드 프레임·렌더러 깊이에 그대로. `unknown`은 R1처럼 틀림으로 센다(비율 따로). contact_stall은 V0에 없음.
- **L**: 실행하지 않는다(시간). PC5는 "미실행".
- **최빈**: 균형 정확도 정의상 0.5.

### 1.4 지표·판정 세부
- M4 (b): FI-DEV 평가 시드 15–29 전 조건의 모든 0.33 s 스냅샷(각 스냅샷 = 앞 결정 스텝의 끝). 균형 정확도(술어별, 평균 = W에서 §1.2 제외 규칙 적용), 에피소드 단위 부트스트랩 2,000회(시드 0) 95 % 구간, 짝 차이는 같은 에피소드 뽑기. ECE = 15구간 신뢰도 형식(`analysis.stats.ece`, 확률 max(p, 1−p) 대 맞음), **PC1의 ECE·커버리지는 W 술어를 합친 값으로 판정**(술어별도 보고). 풀 eval 60편은 V1 계열 보조 표.
- M7 critic: 스냅샷마다 위반 점수 v(t) = 그 단계 기대 술어(채널 범위 안) 중 max P(값 ≠ 기대)(OR 항목은 1 − max p). 지속 2스냅샷(min, 0.66 s). 에피소드 점수 = max v. 문턱 = 보정 비실패 성공 에피소드(명목 + 무해, `success = True`)의 에피소드 점수로 conformal(α = 0.05; 결합 조건은 채널마다 α/2, 경보 = OR). 재현율 = 실현된 실패 에피소드 중 **첫 경보가 [onset, onset + 2 s]** 안(onset 전 경보는 놓침으로 셈, 느슨판 병기). FWER = 평가 비실패 성공 에피소드 중 경보가 하나라도 난 비율.
- PC2의 "명목 에피소드 FWER ≤ 1 %" = P 하드 규칙(이진, 2틱 지속)을 평가 비실패 성공 에피소드(명목 + 무해) 전체에 적용(명목만 15편이라 1 %를 따로 판정할 수 없음).
- PC3: 각 조건을 자기 문턱(FWER 5 %)에 놓은 점추정 재현율로 비교.
- PC4: GPU(H200)에서 문맥 순전파 뒤 헤드 순전파 추가 시간 p95(배치 1, 200회, CUDA 동기). GPU 2는 다른 에이전트 작업과 공유 중이라 그 사실을 함께 적는다.
