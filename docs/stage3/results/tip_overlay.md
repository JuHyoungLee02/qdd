# E-8BABL2 결과 — 손끝 표시(tip_overlay) vs TCP 고리(ring)

작성: 통제자, 10-03. 데이터: gen2 1,381편 학습/300편 평가(right-arm 포함, but **이번 빌드는 code_l9_tipq 기반이라 min_format 왼팔 버그가 아직 안 고쳐진 상태 — 오른팔 편만 실제로 들어갔다**, 수정 전). rowcheck.py --write-common으로 ring/tip 두 판을 같은 행 id로 자름(표시 외 전부 동일). 바탕 이미지 L9_TIP_BASE=ring(고리 이미지 위에 손끝 고리 추가, 격자/글자 차이 없음).

## 판정 (사전등록: 손끝 표시가 기본, 주 지표가 뚜렷이 나쁘지 않으면 채택)

**TIP_WORSE — 손끝 표시 불채택, TCP 고리 유지(사용자 결정, 10-03 23시대 KST).**

- 주 지표(action_acc, point_px 중앙값) 모두 고리가 더 좋음: action 0.796(ring_s0)/0.770(ring_s2) vs 0.768(tip_s2) — 시드 분산 안에 들지만 더 나을 이유가 없고, point px는 ring_s0=35.1 vs tip_s2=37.2로 고리가 더 좋음(ring_s2=25.7은 더 좋지만 같은 ring 조건의 시드 분산이 10px 가까이 커서 애초 비교 신뢰도가 낮음 — A/A 느낌).
- G1(3지 손) 분해도 같은 방향: action 0.936(ring_s0)/0.890(ring_s2) vs 0.919(tip_s2), point px 14.7/11.8 vs 13.8 — 손끝 표시가 뚜렷이 더 낫다고 할 근거 없음.
- 결론: 손끝 표시를 넣을 이유가 없다. TCP 고리(ring)를 그대로 쓴다.

## 데이터 주의 (오른팔 전용)
