### 8.2 판정 (규칙 그대로)
- 적합(네 점, 최소제곱): **acc = 0.2944 + 0.0901 · log10 N**, NLL = 14.28 − 3.124 · log10 N(N = 1,000의 과적합 NLL 5.34가 지배, 참고만).
- b = 0.090 ≥ 0.05 이지만 **acc(100 %) − acc(25 %) = +0.0011 < 0.03** → "확인" 조건 불충족 → **"데이터 규모 레버 약함(같은 스텝 기준)"**.
- **acc(100 %) − acc(50 %) = −0.0022 < 0.01 → "포화"** 표시.
- 판정 문구: **"데이터 규모 레버 약함(같은 스텝 기준), 50 %→100 % 포화"**.
- **외삽(판정 밖, 외삽임)**: 적합이 맞는다면 acc(100 %)보다 +0.05에 필요한 N* = 37,484 · 10^(0.05 / 0.0901) ≈ **134,000**. 다만 기울기는 N = 1,000 한 점(16 에폭 과적합)이 만든 것이고 위 세 점(9k–37k)은 0.682–0.686으로 평평하다 → 이 외삽은 믿을 근거가 약하다.

### 8.3 D2 재판정 (3절 규칙 그대로)
- N = 1,000 판 step 2000: 학습 부분집합 정확도 **1.000** ≥ 0.95 그리고 검증 **0.552** ≤ 0.75 → **"라벨은 학습 가능, 일반화 간극 → 데이터 늘리기가 듣는다(데이터 규모 레버)"**. D2(4절)의 "불확정"은 이 판으로 해소된다.
- 주의: 스케줄이 원래 D2(상수 lr 1e-4, 50스텝 워밍업, 1,000스텝 = 8 에폭)와 다르다(코사인 → 0, 2,000스텝 = 16 에폭). 1,000스텝 시점(lr 아직 높음)에서 이미 0.944였다.
- D2 규칙의 "데이터 레버" 결론과 8.2의 "레버 약함"은 모순이 아니라 범위가 다르다: 1,000 → 9,371은 크게 오르고(+0.130), 9,371 → 37,484는 같은 2,000스텝에서 오르지 않는다(+0.001).

### 8.4 읽기 (판정 밖)
- 같은 계산(2,000스텝 × 8 = 16,000 표본)에서 서로 다른 표본이 약 9k를 넘으면 정확도는 약 0.68에서 멈춘다. N = 9,371 판은 학습 부분집합과 검증이 거의 같아(0.706 vs 0.682) **과소적합 영역**이다 — 이 계산량에서는 데이터가 아니라 **스텝(계산)**이 막고 있다.
- S-E2E 본 판(전체 데이터, 4,686스텝) 0.722와 비교하면: 2,000 → 4,686스텝에서 +0.04. D1(상수 lr로 더 돌림)은 개선이 없었으므로, 남은 이득은 "더 긴 감쇠 스케줄"에서 나올 수 있다(이 판들로는 분리 불가).
- 이 곡선은 "시간 맥락 부재(입력 한계)" 가설과 충돌하지 않는다: 데이터 다양성이 늘어도 0.68–0.72 근처에 머무는 것은 입력이 정하는 한계와도 맞는다. E-TC(메인 세션 진행 중)가 그 가설을 직접 잰다.
