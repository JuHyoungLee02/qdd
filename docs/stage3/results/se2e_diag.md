## 6. 종합 읽기와 추천 레버
- 사전 등록 표의 칸: **D1 아님 × D2 불확정 × D3 모호성 아님** → "**판정 불가 → 더 큰 과적합 시험(스텝 2배) 또는 시간 맥락 시험을 다음 사전 등록으로**". 규칙상 확정 레버는 없다.
- 판정 밖 읽기(다음 사전 등록을 고르는 근거, 결론 아님):
  1. **학습 부족 아님(상수 lr 기준)**: 남은 개선은 담금질에서 나왔고, 같은 데이터를 더 도는 것만으로는 내려가지 않았다.
  2. **라벨은 대체로 학습 가능**: 1,000개를 0.885까지 외웠고 아직 오르는 중. 인접 0.1 s 라벨 불일치로 잡은 대략 상한은 약 0.93 — 현재 0.72와 거리가 멀다.
  3. **오답의 모양은 "방향"이 아니라 "움직이느냐·얼마나"**: 부호 반대 8/155, 크기 오답은 거의 한 칸 차이. 경계 근처(밴드)에서 오답률이 2.4배지만 오답의 66 %는 경계에서 먼 항목이다 → 라벨 규칙을 넓히는 것만으로는 대부분 안 고쳐진다.
  4. 3의 "언제 움직이기 시작·멈추는가"는 단일 시점 이미지 + "gripper/arm" 문장만 보는 결정 프롬프트(관절 속도·이전 프레임 없음, `context_text`)로는 원리적으로 애매하다 → **시간 맥락 추가**(이전 프레임 또는 말단 속도 문장)가 가장 직접적인 후보, **데이터 늘리기**가 두 번째(1k→37k에서 0.56→0.72).
- 다음 사전 등록 제안(순서): (a) D2′ — 같은 1,000개로 2,000스텝, 규칙 그대로(0.95 도달 여부로 D2 불확정 해소, GPU 1장 약 70분). (b) E-TC — 결정 프롬프트에 직전 0.3 s 말단 변위(또는 이전 머리 이미지) 추가한 1 에폭 판 vs S-E2E A, 같은 검증 300. 단 (b)는 `stageb_data.py`/`se2e_data.py`(프롬프트 파일, §71 해시 보호)를 바꾸므로 새 `question_id@vN`·체크포인트 해시가 필요하다 — 메인 세션 결정 사항.
