# 결과 기반 라벨 점수식 선택 규칙 — 사전 등록 (2026-09-24T11:46Z, v2 장면 자체 점검 전)

배경: 옛 장면 스모크(DEV 0, 스냅샷 2개, 11개 질문)에서 계획서 점수식(10 s 안 성공 = 1)은 거의 모든 보기가 성공해 동점 → 판별력 없음(`docs/stage3/results/labeler.md`). 오라클 플래너가 한 스텝 어긋남을 대부분 회복하기 때문이다. 이 규칙은 v2 장면의 DEV 자체 점검 자료를 보기 **전에** 고정한다.

후보 정의(롤아웃은 같고 점수만 다름, 롤아웃마다 1·2·3·5 s 시점 단계·남은 거리와 성공·실패 시각 저장):
- **D-plan**: 계획서 그대로. 10 s 안 성공 = 1, 아니면 단계 진행 + 남은 거리 정규화. 실패(낙하·전도) = 0.
- **D-short(h)**: h ∈ {1, 2, 3} s 시점의 진행 점수 = 단계 번호 + (1 − 남은 거리/단계 시작 거리). 10 s 안 실패는 0(거부권).
- **D-time(τ)**: 10 s 안 성공한 보기끼리 성공 시각이 최선 + τ 안이면 동점, τ ∈ {0.33, 0.66} s. 실패 = 0.

선택 규칙(DEV 0–29, P0–P2, 결정 스냅샷 전부):
1. 적격: 오라클 답 ∈ best 집합 비율 ≥ 90 %. (계획서의 95 %는 오라클이 거의 최적이라는 전제의 값이었고, 판별력 있는 정의에서는 오라클보다 나은 보기가 정당하게 이길 수 있어 90 %로 둔다 — D4 F5 "플래너와 다르지만 똑같이 좋은 보기는 정답".)
2. 적격 정의 중 **판별력**(질문별 1 − |best|/|보기| 의 평균)이 가장 큰 것을 쓴다. 차이가 0.02 이하면 더 단순한 쪽(D-plan > D-time > D-short, h는 긴 쪽)을 쓴다.
3. 적격 정의가 없으면 E0.5의 결과 기반 정답률 판정을 보류하고 그 사실과 이유를 보고한다(문턱을 낮추지 않는다).
4. 고른 정의와 모든 후보의 두 수치를 `labeler.md`에 함께 적는다.
