## 3. 판정 (E-PT 5.2 규칙, 기준 = h2h_base)
- 각 팔 대 기준(`tools/teach_pt/compare.py <root> h2h_base <팔>`):
  - DEV 비열등: 접근 xy 중앙 ≤ 기준 + 5 mm 그리고 유효 ≥ 0.95.
  - OOD-H(주 지표 = 접근 3D 오차 중앙): 팔 ≤ 0.8 × 기준 그리고 스냅숏 짝 부트스트랩(10,000회, 시드 0) 평균 차 95 % 구간 상한 < 0 → **BETTER**; 구간이 0을 포함 → **SAME**; 하한 > 0 → **WORSE**.
- 두 후보 사이(`compare.py <root> h2h_cp h2h_t1t4`): 같은 규칙. 두 후보의 **주 비교**다.
- 누수 관문: DEV·OOD-H 누수 0건. 1건이라도 있으면 그 팔은 '누수'로 적고, 판정과 별개로 보고한다.
- 결정에 쓰는 법:
  - 한쪽이 상대에게 BETTER이고 누수 0 → 그쪽이 점수판 '학습 효과'에서 앞선다.
  - SAME → '학습 효과로는 가르지 못함'. 점수판의 다른 칸(관문·수율·위험)으로 결정한다.
  - 기준보다 WORSE인 묶음 → 그 묶음을 이 비율로 섞으면 안 된다고 적는다(묶음 폐기가 아님 — user-log 143).
- 12:53 전에 끝나지 않은 팔·세트는 '미완'.
