## 1. 팔 (우선순위 = 사용자·통제자 지시)
모두 Qwen3-VL-8B-Instruct, 같은 L8 TRAIN 상태(아래 2절), 같은 레시피·같은 걸음 수. **다른 것은 요청(글·머리 영상)과 답 형식뿐**이다.

| 팔 | 머리 영상 | 글에 있는 장면 거리 정보 | 답 | 거리를 누가 아나 |
|---|---|---|---|---|
| **ND-1 `nd-xyz`** (주) | TCP 고리만(격자·낙하선 없음) | 없음(탁자 높이 줄 삭제) | v2 xyz(eef/edit) | 모델이 영상에서 암묵적으로 |
| **ND-2 `nd-est`** (주) | TCP 고리만 | 없음 | 먼저 `estimates`(탁자 높이, 대상 밑면 xy·높이·폭, 놓을 곳 xy·윗면 높이) → v2 xyz | 모델이 명시 추정 후 명령 |
| **PT `pt`** (비교, F2 점) | v2 덧그림(격자·고리·낙하선) | v2 그대로 | 점(0–1000) + 높이 의도 | 코드가 머리 깊이 + 보정 + 평면 위 군집(PT-0c) |
| **ND-pt `nd-pt`** (선택) | TCP 고리만 | 없음 | `estimates` → 점(윗면 중심) + `top_z` 추정 + 높이 의도 | 모델 추정 높이로 코드가 광선을 내림(깊이 없음) |
| **기준 L8-xyz `xyz`** | v2 덧그림 | v2(탁자 높이 0.850 등) | v2 xyz | 격자(탁자 높이에 그려짐) + 학습 |

- 로봇 자기 정보(좌표계·그리퍼 형상·카메라 자세·TCP 측정값·실행 측정 이력)는 모든 팔에 그대로 둔다(정본 §97). 격자·낙하선은 코드가 **알고 있는 탁자 높이**에 그리므로 장면 거리 정보로 보고 ND 팔에서 뺀다.
- 실행기의 작업 상자 z 잘림은 모든 팔에서 시뮬 탁자 높이를 쓴다(코드 안전망, 모델에게는 안 보임) — 한계에 적는다.
- 기준 L8-xyz는 **L8 어댑터를 그대로 쓴다**(같은 L8 편에서 학습됨, G1이 같은 상태임을 확인). F0 영샷은 PT 인터페이스(0–1000, Qwen 고유 형식)가 주, 정수 픽셀 문구는 문구 흔들기(P90) 기술용.
- 선택 팔 PT-ID(물체 번호 고르기)는 시간이 남을 때만, 새 변경 기록으로.

  - DEV: L8과 같은 40편(DEV 0–19 × standard·dr, mug_tray).
  - **OOD-H**(학습 금지): DEV 0–9 × standard × 탁자 높이 **0.82·0.88 m**(학습은 0.85만; `diversity_plan` OOD-H 띠 [0.815, 0.835] ∪ [0.865, 0.885] 안), 같은 행동 정책 → 20편. 최소 구현 `make_env(table_z=…)`(탁자·물체 생성 높이만 옮김, standard만; 기본값 경로 바이트 동일 — 시험).

- **관문 G1(같은 상태)**: 새 수집의 `prompt_v2.txt`와 L8 수집의 `prompt.txt`가 바이트 동일, 머리 PNG 픽셀 동일, 라벨(단계·TCP) 동일인 호출 비율 ≥ 0.99(TRAIN·DEV 각각, `tools/teach_pt/identity.py`). 미달이면: 원인을 적고, L8-xyz 기준은 새 수집의 v2 요청으로 **다시 평가**하며(어댑터는 그대로), L8 편과 '같은 편'이라는 주장은 빼고 '같은 시드·정책'으로 적는다.
- **라벨**(전부 시뮬 참값, 무료):
  - xyz = L8 라벨 그대로. nd-est = `estimates`(시뮬 참값) + L8 라벨.
  - pt = L8 계획 단계를 점 명령으로: above_target → 대상·above, descend_close → 대상·grasp·close, carry_over → 놓을 곳·above, lower_open → 놓을 곳·place·open, lift_clear·carry_up → lift, retreat → edit +10 cm, reopen·done 그대로. 점 = 대상 윗면·몸통 후보를 투영해 **런타임 변환기(깊이)로 풀었을 때** 발자국 중심 ≤ 12 mm·윗면 ≤ 8 mm인 첫 후보; 없으면 그 행은 pt 팔에서 뺌(수를 적음).
  - nd-pt = 같은 단계 대응, 점 = 윗면 중심 투영(가려져도 기하 참값), `top_z` = 윗면 높이 참값; 영상 밖이면 뺌.
  - 보조 QA(행마다 1개, L8과 같은 수): pt = 점 찍기(대상·놓을 곳·다른 물체·TCP 고리), xyz·ND = 밑면 xy(m)(ND는 격자 언급 없음, TCP xy 포함).

## 5. 관문과 판정 (결과 전 고정)
### 5.0 관문 (본 평가 전)
- **G0 변환기·참값 상한**: (a) DEV의 pt 참값 답을 채점기로 → 접근 xy 중앙 ≤ 5 mm·p90 ≤ 10 mm, pt 라벨 빠짐 ≤ 10 %; (b) 참값 폐루프(DEV standard·dr × s0·s1)에서 pt·nd-xyz·nd-est·nd-pt 인터페이스 각각 성공 ≥ 3/4. 미달 → 멈추고 재설계(P18).
- **G-H**: OOD-H 두 높이에서 v2 참값과 pt 참값 폐루프(s0·s1) 성공 ≥ 3/4씩, 수집 참값 깨끗한 편이 성공. 미달 높이는 빼고 적는다(둘 다 미달이면 OOD-H 없이 DEV만, 결과에 '일반화 판정 없음').
- **G1**: 2절.
- 학습 자체 검사: 첫 20걸음 손실 하강, 로더 행 수 = 파일 행 수(P115).
### 5.1 F0 — 영샷 점 (Qwen3-VL-8B 원판, DEV)
- 비교: 같은 DEV 상태에서 L8 영샷 xyz 125.5 mm(편 중앙의 중앙 151.9).
- **POINT_HELPS**: pt 영샷 접근 xy 중앙 ≤ 62.8 mm(= 0.5 × 125.5) **그리고** 유효 JSON률 ≥ 0.90. **NO**: 그 밖. 픽셀 문구판은 기술만.
- 폐루프 영샷 pt 4판(DEV standard·dr × s0·s1, 조기 종료 20호출·60 s)은 판정과 무관하게 돌리고 영상을 남긴다(편 판정 WORKS / PERCEPTION / DOWNSTREAM, L8 5.2 규칙).
### 5.2 F2 — 미세조정 팔 비교 (주)
- **DEV 비열등**(천장 예상): 팔 접근 xy 중앙 ≤ L8-xyz + 5 mm **그리고** 유효 ≥ 0.95. 둘 다 ≤ 10 mm면 DEV는 '가르지 못함'으로 적는다.
- **OOD-H 일반화(주 지표 = OOD-H 접근 3D 오차 중앙)**: 팔 값 ≤ 0.8 × L8-xyz 값 **그리고** 스냅숏 짝 부트스트랩(10,000회, 시드 0) 스냅숏별 차(팔 − L8)의 평균 95 % 구간 상한 < 0 → **BETTER**; 구간이 0을 포함 → **SAME**; 하한 > 0 → **WORSE**. 두 높이 합동과 높이별을 모두 보고, 판정은 합동. 잡기 z 절댓값 중앙·≤ 15 mm 비율은 같이 보고(기술).
- 일반화 간격 = OOD-H 접근 3D 중앙 ÷ DEV 접근 3D 중앙(팔별).
- ND-1·ND-2 사이, ND 대 PT 사이도 같은 규칙으로 짝 비교(기술 — 주 판정은 각 팔 대 L8-xyz).
### 5.3 폐루프 (영상 필수)
- DEV 관문(유효 ≥ 0.95·접근 xy 중앙 ≤ 20 mm)을 넘은 팔만: OOD-H 4판(s0·s1 × 0.82·0.88) — L8-xyz도 같은 4판. 시간이 남으면 DEV 4판(standard·dr × s0·s1).
- 조기 종료 20호출·60 s, 프롬프트 한도 40호출·180 s. n = 4라 방향만(성공·잡고 들기·실패 단계·첫 닫기 xy).
- 영상: 편마다 연속 mp4 + 모델 시점 mp4, `/data/harvest/videos/pt/<단계>/<팔>/` + 색인(`tools/astra_solo/make_videos.py`, `/data/harvest/venv_train/bin/python`).

## 6. 결정 규칙
- F0 POINT_HELPS → 영샷 기준선에 점 인터페이스를 쓴다(유료 비교 제안의 근거). NO → 점만으로는 영샷이 안 풀린다고 적고 실패 원인(점 픽셀 오차 대 의도 오류)을 분해한다.
- F2: ND-1 또는 ND-2가 BETTER면 → 깊이 없는 길이 실물(깊이 없는 공개 데이터 사용)의 주 경로 후보, E-XEMB8 팔에 넣는다. 둘 다 SAME/WORSE이고 PT가 BETTER면 → 깊이 가정(§97) 유지, ND는 다양한 높이 데이터(§97 보충 1)와 함께 다시. 모두 SAME이면 → '탁자 ±3 cm는 가르지 못함'으로 적고 더 넓은 OOD-H(관문 G-H 뒤)로.
