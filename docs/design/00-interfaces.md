## 2. 한 번의 Jev 호출 (`JevCall`) — B1, B8
- 한 호출에 싣는 것: 결정 질문 H개(미래 결정 스텝 k..k+H-1) + 감시 질문(M7 진행 범주 1개, 필요 시 M8 T3b 1개).
- H는 **1과 3을 비교**한다(E-M4). M3 D-줌의 "한 요청 = 한 스텝"은 H=1 조건이다. H=1일 때 M4 (a)의 여러 표는 "같은 스텝을 시각을 당겨 여러 번 묻기"로 얻는다.
- 입력 길이 상한을 설정 표에 둔다. E0 지연 측정은 실제 `JevCall` 크기(결정 H개 + 감시 질문)로 잰다.

## 3. 예상 상태는 한 곳에서 — B2, B12
- M5가 계획 궤적 `ref(t)`(Ruckig 출력)를 공개한다. **M4 (b)의 예상 상태는 `ref(t)`다.** 추종 지연으로 인한 가짜 LAG를 막는다.
- M3가 보기마다 붙이는 "예상 결과 술어"는 `expected_after`로 M4와 **M7 모두**에 전달한다.
- M4 (b)는 (1) `ref(t)` 대비 연속 잔차와 (2) `expected_after` 술어 일치 여부를 따로 계산한다.

## 4. 실패 판정과 정지는 한 곳에서 — B3, B4, B10, C2
- **M4는 신호만 낸다.** CONTRADICT → M7 하드 채널. DEVIATE → M7 소프트 채널 `C_m4`. 호출 사이 불일치 급증(`flip_score`, TIDE 이산판) → 새 소프트 채널 `C_flip`.
- **FAIL은 M7만 낸다.** AND 결합(소프트 채널 2개 이상이면 FAIL, 1개면 WARN)은 M7에만 둔다.
- 정지가 허용되는 곳은 두 군데뿐: T0(첫 계획)과 M9의 안전 대기(L3). M4의 hold, M5의 NONE_ESCALATE 감속 정지는 **정지가 아니라 "직전 확정 행동 유지 + 감속"**으로 바꾼다. 완전 정지가 필요하면 M7 FAIL을 거친다.
- [결정 필요] 정밀 접촉 구간의 짧은 정지(동기 실행, WAM 72.5 증거)와 M9 안전 대기(L3)를 사용자 예외로 인정할지.
