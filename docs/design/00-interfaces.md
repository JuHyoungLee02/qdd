## 2. 한 번의 Jev 호출 (`JevCall`) — B1, B8
- 한 호출에 싣는 것: 결정 질문 H개(미래 결정 스텝 k..k+H-1) + 감시 질문(M7 진행 범주 1개, 필요 시 M8 T3b 1개).
- H는 **1과 3을 비교**한다(E-M4). M3 D-줌의 "한 요청 = 한 스텝"은 H=1 조건이다. H=1일 때 M4 (a)의 여러 표는 "같은 스텝을 시각을 당겨 여러 번 묻기"로 얻는다.
- 입력 길이 상한을 설정 표에 둔다. E0 지연 측정은 실제 `JevCall` 크기(결정 H개 + 감시 질문)로 잰다.

## 4. 실패 판정과 정지는 한 곳에서 — B3, B4, B10, C2
