# D6 모의 심사 (CVPR 2027 / ICRA 2027 가정 제출본)

작성: 2026-09-23 23:40 UTC, 모의 심사 에이전트(텍스트 반환 → 메인 세션 저장). **결과 수치는 하나도 지어내지 않았다. "결과"는 모두 계획된 실험이 바라던 방향으로 나왔다고 가정한 것이다.** 선행 연구는 `docs/`에 적힌 범위 안에서만 인용.

가정한 제출본 요지: Astra(느린 VLM 계획기, 실패 때마다 비동기 개입) + Jev(텍스트 전용 typed 객관식, 약 3Hz 계단식 겹침) + 스킬/제어기(100Hz+). 기여 (C1) M4 확정 규칙((a) 호출 사이 typed 합의 + (b) 코드 예상 상태 대 측정 상태 → commit/keep/replace/repair, 전제 epoch 무효화), (C2) 평가: RoboDojo Gen에서 같은 인식 앞단 위, 학습 없는 LLM 결정 층의 standard→random 상대 하락(RD)이 π0.5(B3b)와 같은 인식 위 학습 결정 층(B3c)보다 작다(H1, H2).

## Reviewer 1: 로봇 학습 / VLA — 점수 3 (Borderline Reject), 확신 4
- 강점: 인식을 통제한 비교 설계(H2 B3c, H3 규칙, H4 인식 몫 사전 등록) / 절대 성공률 대신 상대 하락, 정보 비대칭 공개 / 반대 증거 정면 인정(π0.5 새 집, DreamZero 62.2 대 27.4, 2512.02902 1-shot 적응, GR 1.5) / 판정 기준·부트스트랩 사전 등록.
- 약점
  1. B3c는 VLA가 아니다(인식 상태 위 DP/ACT). H2가 지지돼도 "소량 시연 모방 정책보다 강건"으로 좁아진다. B3b(π0.5)와의 H1은 인식·정보·행동 경계가 달라 결정 층 효과로 귀속 불가.
  2. 환경 강건성이 인식 앞단 몫일 가능성(random은 주로 인식을 때린다). H3 기각이면 LLM 몫이 없어진다. 이야기 준비가 없다.
  3. 적응 예산 비교 부재: 2512.02902(CVPR 2026) 4K 파라미터 1-shot 적응으로 시점 붕괴 48.5→87.1% 회복. VLA few-shot 적응 조건(B3b')이 없으면 불공정.
  4. 벤치마크 신뢰도: RoboDojo·Astra 평가 모두 미심사, Gen 12과제 중 5개는 Astra도 standard≈0(바닥), RD CI 약 2~22%로 넓음.
  5. 실물 없음(Slow Brain·DreamZero·π0.5는 실물 새 환경).
  6. "LLM"이 아니라 "Astra"의 결과일 수 있다(같은 틀 GPT-5.5 0.88%). Jev도 단일 공급자.
- 질문: B3c에 사전학습 VLA 기반 변형(동결 π0.5 표현 + 헤드)? H4 술어 정확도 하락이 RD 차이의 몇 %를 설명? π0.5에 random 시연 k=5, 20 적응 곡선? 바닥 과제 뺀 7과제에서도 유지? Open 축으로 주장 이동 의향?

## Reviewer 2: LLM 에이전트 / 추론 시스템 — 점수 4 (Borderline Accept), 확신 3
- 강점: 새로움 주장이 정밀(비정지·겹침·추측-확정은 선행으로 인정, (a)+(b) 결합만 주장) / 같은 모델 자기 합의 한계 인지((a) 흔들림 억제, (b) 외부 기준) / 절제 설계(C5', C3' 0.9 근거, C3'') / 보정 전 확률 게이트 끔.
- 약점
  1. (a)의 실익이 구조적으로 작을 위험(온도≈0, 0.33초 사이 변화 작음 → 합의 자명). flip≈0이면 기여는 "(b) + epoch"로 좁아지고 2512.17250·VLA-Corrector·SV-VLA의 블랙박스판으로 읽힌다. C5>C2의 원천을 (a)/(b)로 분해해 첫 그림에.
  2. Slow Brain 감쇠 융합(C2')이 강한 기준(지연 5초에서도 80%). 섭동 4종이 (b)에 유리하게 치우쳤다는 비판 가능.
  3. 단일 모델(jev-1.13.0)로만 E-M4 → 모델 일반성 불명. logprob 선택기(B8)는 EVAL에만.
  4. 검정력(섭동당 30회×3시드), "잘못 확정 비율"이 (b)로 사후 라벨링돼 순환 지표 위험.
  5. Astra 기여가 흐림(GPT-as-Policy, Critic in the Loop, CheckVLA, Harness VLA와 겹침). high 첫 토큰 약 73초라 실패 뒤 복구는 사실상 아래 층 → Astra 개입 실측 기여 따로 필요.
  6. M10은 Kintsugi 등 선행, 2606.15017 반대 증거 → 분량만 늘림.
- 질문: E0.5 flip rate, (a)가 확정을 늦춘 스텝 비율 / C5 대 C2' 섭동별 분해, P0 손해 여부 / 다른 결정 모델(B8, Astra low)에서도 C5>C2? / 잘못 확정 라벨을 결과 기반 라벨러로?

## Reviewer 3: 실시간 제어 / 시스템 — 점수 2 (Weak Reject), 확신 4
- 강점: 지연을 1급 변수로(E0) / C0·C1·C2·C2' 기준 선택 정확 / 정지·실패 책임 한 곳 / W+1 자기 인정 + 절제.
- 약점
  1. 실시간 주장을 실시간으로 안 잰다(RoboDojo가 동기면 이점이 점수에 안 드러남). 벽시계 트랙은 비교 기준이 없다. M4 이득은 자작 장면에서만.
  2. 실물 없음 → 지연·추종·인식 지연 이상화, 폐루프 conformal 교환성 붕괴(FIPER 부록 C.4.2) → DEVIATE 과다·epoch 잦은 교체·합의 불능 경로.
  3. 3Hz 결정 / 100Hz 제어 사이 안정성 분석 없음(p95 고정 구간이면 약 5% 호출은 늦게 도착), 지연 스윕 없음(Slow Brain은 1~5초 스윕).
  4. 처리량 제약(1,200 요청/분), Astra high 73초·xhigh 198초로 비정지 복구 구간이 성능을 좌우.
  5. RTC 차용은 비유 수준(접두 조건화에 해당하는 것을 보여야).
  6. 폐쇄형 API 두 개 → 재현성.
- 질문: 인공 지연 주입 스윕(p95 0.3/0.8/2/5초)에서 C1·C2·C2'·C5 곡선? 실물 단일 팔 섭동 2종 C2' 대 C5? 동기 루프면 벽시계 트랙의 비교 기준? epoch 교체 빈도·미확정 실행 비율·번복률 분포?

## 메타 리뷰 — 현재 형태면 Borderline Reject 쪽
세 심사자 모두 정직함(좁힌 새로움, 사전 등록, 반대 증거 인정)을 인정. 그러나 두 기여가 서로 다른 시험대에서 따로 검증돼 하나로 묶이지 않고, 각 기여의 가장 강한 반론(인식 귀속, Slow Brain 감쇠 융합, 실물·동기 시뮬)이 가정한 결과로도 완전히 해소되지 않는다.

### 탈락 사유 5개와 가장 싼 해소책
1. **기여가 두 논문으로 갈라짐 + 시스템 과대** → 본문 기여를 하나로 정하고 나머지는 구성 요소로. M8 비교·M10은 부록/후속(사용자 동의 필요). 하나로 묶으려면 **새 실험 E-link**(RoboDojo Gen 4과제 random 벽시계 트랙에서 C2' 대 C5).
2. **일반화가 LLM이 아니라 인식·정보 비대칭 몫** → EVAL S1.5를 본문 핵심 그림으로 / **2×2 표**(결정 층 {LLM, 규칙, B3c} × 상태 {정답, 인식}) / B3c에 **사전학습 VLA 기반 변형**, π0.5 **few-shot 적응 곡선** / "VLA" → "과제 데이터로 미세조정한 학습 정책" 문구.
3. **같은 술어 위 Jev > 규칙의 이유 불분명** → E2a 보류 섭동(P3·P4)을 본문 주장("규칙 작성자가 보지 못한 상황")으로 / 규칙 작성 예산과 템플릿 예산 동일 / H3 기각 시 Open 축(Astra 31.00% 대 VLA 약 2%)으로 LLM 몫 이동.
4. **M4 새로움이 점진적** → **E0.5를 가장 먼저**(flip≈0이면 주장을 미리 좁힘) / C5 대 C2'·C5 대 C5'를 주 그림, P0 무손해 / **모델 일반성 조건**(B8 logprob 선택기에 같은 확정기) / 잘못 확정을 결과 기반 라벨로도.
5. **실시간 주장을 실물·지연 스윕 없이** → **새 실험 E-M4-lat**(인공 지연 p95 0.3/0.8/2/5초 스윕, C1·C2·C2'·C5 곡선) / **E-real 최소판**(실물 단일 팔, 섭동 2종 × C2' 대 C5 × 약 20회, ICRA면 사실상 필수) / S0 동기 여부를 본문에 명시.
- 기타: 폐쇄형 모델 재현성(판본 고정, 로그·프롬프트·E0.5 재생 자료 공개), RoboDojo 미심사, 바닥 과제(7과제 부분집합 사전 등록 분석).
