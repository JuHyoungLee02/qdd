### 1.1 사용자 의도에서 기운 곳

**D-1 (중요) E2의 Astra 끔에 대칭 조건이 없다.** E §4.3은 "실행 중 Astra 개입(실패 시 호출)은 끈다"고 적고 E §8-1에 [결정 필요]로 올렸다(표시는 됐다). 그러나 조건 표에는 끈 쪽만 있다. 사용자가 만들려는 시스템은 "스킬 + Jev + 실패마다 Astra"이고, 사용자에게 필요한 질문은 "그 구조 안에서 Jev가 룰보다 값을 더하는가"다. Astra가 룰의 실패도 구해 주면 차이가 줄어들 수 있다(방향 모름, 확인 필요).
- 고칠 것: E2에 보조 쌍 **R0+A / J*+A**(최선 Jev 조건 하나 + Astra 실패 호출 켬, 룰에도 같은 Astra 실패 호출)를 TEST 부분집합(예: P3·P4 60쌍)으로 추가하고, 판정은 보조로만 쓴다. 결과 문장은 "Astra 없는 결정 층 비교"와 "사용자 구조 안 비교"를 나눠 적는다.

**D-2 (경미~중요) 논문 빨간 줄 축약.** `paper/sec/3_method.tex` M8 절 `\intent{처음 계획만 멈춤}`. 사용자 원문(user-log 11 정지)은 "그 이후는 웬만하면 멈추지 않는다. 실패로 생각해야 하는 경우만 어쩔 수 없다". 빨간 줄이 "실패 시 예외"를 지워 사용자 발언보다 강해졌다. 00 §4·M9 L3 설계는 이 예외에 기대므로 빨간 줄과 설계가 어긋나 보인다.
- 고칠 것: `\intent{처음 계획할 때만 멈춤. 이후는 웬만하면 안 멈춤(실패로 다시 생각할 때만 예외)}`로 원문 뜻을 살린다.

**D-3 (중요) 기간 밖 문헌이 사용자 허가 전에 정본을 정했다.** plan §5 [결정 필요] 4번은 Sentinel·LocalAgreement·Ruckig 등 기간 밖 문헌 사용을 사용자에게 묻는 항목이다. 그런데 00 §12는 Sentinel/STAC(CoRL 2024, 기간 밖) 절제를 근거로 `C_flip` 계산식을 "기술 결정, 메인 세션 채택"으로 바꿨다. M4 "가장 중요한 차용" 1순위 LocalAgreement, M5 L3 기본 Ruckig도 기간 밖이다. 이것들은 "아주 큰 주제를 포괄하는 기초 문헌"(사용자 예외 조건)이라기보다 **특정 방법**이다. 사용자 예외 문구에 들어맞는지 판단은 사용자 몫이다.
- 고칠 것: 00 §12 채택 문장 옆에 "[결정 필요 4] 승인 전 잠정"을 붙인다. 기간 밖 근거마다 **기간 안 대체 근거**를 나란히 적는다: LocalAgreement → CUNI IWSLT 2025(2506.17077, 기간 안, LA 사용), RALCP → MLLP-VRAIN IWSLT 2025(2506.18828, γ=0.5 채택). `C_flip` 계산식은 Sentinel 없이도 FIPER(NeurIPS 2025)·Xiong 외 §5.3 관찰로 설명되는지 적는다(Xiong 외도 ICLR 2024라 기간 밖이다, 확인 필요). 불허하면 무엇이 바뀌는지 한 줄씩 적는다(M9 §7이 이미 이 방식을 쓴다).

**D-4 (중요) effort 권장안이 한쪽으로 기울었다.** EVAL §8 Q2 권장 "주 비교는 medium(동등) + high 보조 1회". CLAUDE.md 규칙은 "Astra effort를 낮추는 것을 기본안으로 쓰지 않는다"이고, E2·E3는 high로 고정했다. medium을 주 비교로 권하는 것은 B1a와의 공정성 논리는 있지만 사용자 원칙 반대편에 기운 권장이다(draft-log 교훈: "1순위 제안이 한쪽으로 기울면 사실상 결정").
- 고칠 것: Q2를 대칭으로 다시 적는다. (i) 주 = high 이상(사용자 원칙), B1a는 공개 medium 결과 + 같은 layout high 재실행 일부로 판본·effort 차이 점검 / (ii) 주 = medium(B1a와 동등), high 보조. 각 안의 비용·에피소드 시간(F7)을 함께 적는다.

## 4. 가장 약한 고리 (새 마차)와 싸고 이른 시험

### W1 (치명, F1) "같은 인식 위에서 LLM 결정 층이 덜 무너진다"
- 왜 약한가: Jev는 텍스트만 본다. 조명·배경·바닥 재질·HDR(RoboDojo `_random` 5요소 중 4개, EVAL §2.1)은 **인식 앞단만** 때린다. 인식이 버티면 룰(B4a)·학습 결정 층(B3c)·Jev 모두 안 무너진다 → H2·H3 차이 없음. 인식이 무너지면 셋 다 무너진다. LLM 몫이 드러날 곳은 방해물(5요소 중 1개)과 Open 축, 복구뿐이다. EVAL H3·R5가 이 가능성을 정직하게 적었지만 **S4(주 실험)에서야 판정**된다.
- E2는 이것을 재지 않는다: 오라클 상태, 단일 과제, 섭동(이동·방해물·미끄러짐·가림)만 있고 환경 변화 축이 없다(E §4.5).
- 싸고 이른 시험 [제안] **W1-a 인식 귀속 선행 측정**(EVAL H4를 S1 직후로 당김): RoboDojo Gen 2~4과제 std/random 짝 layout에서 렌더 프레임만 모아 M1 술어 정확도를 시뮬 정답과 비교. Jev·정책 없음, GPU 몇 시간. 결과 해석을 사전 등록: 술어 정확도 하락이 작으면 "환경 강건성은 인식 몫, LLM 몫은 방해물·Open·복구에서 찾는다"로 주장 문구를 먼저 고친다([결정 필요 1] 자료). **W1-b 오프라인 룰 대 Jev**: 같은 random 스냅샷(인식 상태)에서 룰과 Jev가 같은 결정 질문에 답하게 하고 결과 기반 라벨(W5)로 비교. 약 $1~5.

### W2 (치명, F2) "시간차 Jev 표들 사이에 거를 가치가 있는 불일치가 있다"
- M4 §5 판정 2가 이미 "C4≈C5면 (b) 중심으로 좁힘", 판정 3이 "(b)는 그냥 MPC인가"를 둔다. 문제는 이것을 **폐루프 E-M4(수천 에피소드) 뒤에야** 안다는 것이다.
