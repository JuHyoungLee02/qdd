# 나중에 해결해야 하는 문제들

본 35B 학습에는 넣지 않고 뒤로 미룬 문제만 적는다. 해결하면 줄을 지우고, 결과 문서 링크를 남긴다.
새 데이터나 새 기능은 기존 규칙대로 채택한다. 사전등록한 8B 비교에서 모든 세트가 비열등일 때만 쓴다.

| # | 문제 | 지금 상태 | 해결 방향 | 주의 |
|---|---|---|---|---|
| 1 | **실패 인지·재시도** | 학습 데이터가 성공 편 위주라 회복 장면이 없다. 매 호출 현재 이미지를 보는 암묵적 재시도만 있다 | 시뮬에서 환경이 실패를 주입한다(밀기·그리퍼에서 빼기). 회복 구간만 학습하고 비중은 ≤5% | 실패 구간을 정답으로 넣으면 역효과다. 전환 순간의 모호한 프레임은 버린다 (user-log 187) |
| 2 | **장애물 회피** | 코드가 위에서 접근하고 높이를 유지해 옮기는 것만 한다. 시범2에서 접근 중 충돌 2편 | 실행 단계에서 깊이 점구름과 충돌 고려 경로 계획기(cuRobo 등)를 쓴다. 재학습 불필요 | 모델 쪽 경유점 의도는 새 어휘가 필요해 후순위 |
| 3 | **옆에서 잡기 방향(front_h)** | 어휘가 없다 | 냉장고 문 선반 넣기(B), 누운 막대에 고리 꽂기(H)와 함께 추가 | 준비물: l8x_articulated_tasks.md |
| 4 | **날개 연 상자 넣기(C)** | 0/13 성공. 날개를 뗀 낮은 상자 16/30이 CPU 점검 통과, 렌더 전 | 낮은 상자로 관문을 돌린 뒤 L8S에 추가 | |
| 5 | **관절 과제 전반**(서랍 열기·문 닫기 등 동작) | 쓸 수 있는 서랍장 2종뿐, 새 동작 어휘 없음 | 도달 범위에 맞는 관절 자산을 늘리고 어휘를 확장 | |
| 6 | **새 물체 폐루프 평가 세트** | 후보가 7편뿐이라 통계가 약하다 | ≥30편으로 늘린다(본 학습 평가 전까지) | |
| 7 | **AgiBot 같은 물체 여러 개인 행** | 이름·마스크 재검증 통과 41%. 같은 물체가 여러 개인 정상 행도 잃었다 | 개체를 구분하는 grounding(위치 표현 추가 등)으로 되살린다 | 정확도가 우선이다 (user-log 165) |
| 8 | **DROID 손목 카메라 변환** | 3인칭만 있어 폐기(수율 1.7%) | 손목캠 변환기를 새로 만들고 8B 비교 | user-log 185 |
| 9 | **렌더 불가 노드** | 78dc(노드 전체)와 x3 GPU0에서 Vulkan DEVICE_LOST | 드라이버·노드를 점검하거나 렌더 가능 노드를 요청 | 렌더 가능 여부는 시드 2개 시험으로 먼저 확인 |
| 10 | **HF 토큰 교체** | 내려받기가 끝날 때까지 보류 | 내려받기가 끝나면 교체 | |
